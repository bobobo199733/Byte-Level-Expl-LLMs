def binary_search_rotated(values, target):
    """
    Searches for a target value in a rotated sorted array using binary search.
    
    Args:
    values (List[int]): A rotated sorted array of integers.
    target (int): The integer to be searched in the array.
    
    Returns:
    int: The index of the target if found, otherwise -1.
    """
    if not values:
        return -1
    
    left, right = 0, len(values) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        # If we find the target at middle
        if values[mid] == target:
            return mid
        
        # Check which side is properly sorted
        if values[left] <= values[mid]:
            # Left half is sorted
            if values[left] <= target < values[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            # Right half is sorted
            if values[mid] < target <= values[right]:
                left = mid + 1
            else:
                right = mid - 1
    
    return -1

- **Binary Search Loop**: It uses a standard binary search approach with modifications to handle the rotation. 
- **Middle Check**: The middle element `mid` is checked against the target. If it matches, return the index `mid`.
- **Subarray Sorting**: Determine which half of the array (left or right) is sorted by comparing the first and last elements.
