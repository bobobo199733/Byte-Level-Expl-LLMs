```python
def merge_intervals(intervals):
    if not intervals or len(intervals) == 0:
        return []

    # Sort the list of intervals by their start times.
    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]

    for i in range(1, len(intervals)):
        last_interval = merged[-1]
        current_interval = intervals[i]

        # If the current interval overlaps with the last one, merge them.
        if last_interval[1] >= current_interval[0]:
            last_interval[1] = max(last_interval[1], current_interval[1])
        else:
            merged.append(current_interval)

    return merged
```

This function first sorts the intervals based on their start times, then iterates through them to merge overlapping ones. The merged intervals are stored in a list called `merged`, which is returned at the end.
