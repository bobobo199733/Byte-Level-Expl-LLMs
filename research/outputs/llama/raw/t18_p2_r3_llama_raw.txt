**Levenshtein Distance Calculation using Dynamic Programming**
===========================================================

The following Python function computes the Levenshtein distance between two input strings `word1` and `word2`. This distance metric is a measure of the minimum number of single-character edits (insertions, deletions or substitutions) required to change one word into the other.

```python
def edit_distance(word1: str, word2: str) -> int:
    """
    Calculate Levenshtein distance between two strings.

    Args:
        word1 (str): First input string.
        word2 (str): Second input string.

    Returns:
        int: Minimum number of single-character edits required to change word1 into word2.
    """

    # Initialize a matrix to store the edit distances for subproblems
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Handle edge case where one of the strings is empty
    if not word1:
        return n
    elif not word2:
        return m

    # Initialize base cases for dynamic programming
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Fill in the rest of the matrix using the recurrence relation
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if word1[i - 1] == word2[j - 1] else 1
            dp[i][j] = min(
                dp[i - 1][j] + 1,      # Deletion
                dp[i][j - 1] + 1,      # Insertion
                dp[i - 1][j - 1] + cost  # Substitution or no operation
            )

    # The Levenshtein distance is stored in the bottom-right corner of the matrix
    return dp[m][n]
```

**Example Use Cases:**

```python
print(edit_distance("kitten", "sitting"))  # Output: 3 (insertions)
print(edit_distance("", "hello"))  # Output: 5 (deletions)
print(edit_distance("hello", ""))  # Output: 5 (deletions)
print(edit_distance("apple", "banana"))  # Output: 3 (substitutions and insertions)
```

This implementation should be efficient for longer strings, as it uses a dynamic programming approach to break down the problem into smaller subproblems. The time complexity is O(m \* n), where m and n are the lengths of the input strings.
