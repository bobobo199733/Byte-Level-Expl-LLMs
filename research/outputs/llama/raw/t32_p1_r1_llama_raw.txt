**N-Queens Problem Solver**
=====================================

The `n_queens` function returns all valid solutions to the N-Queens problem, where a solution is an arrangement of n queens on an n x n chessboard such that no two queens attack each other.

```python
def n_queens(n):
    """
    Returns all valid board configurations for the N-Queens problem.
    
    Args:
        n (int): The size of the chessboard.
    
    Returns:
        list: A list of lists, where each inner list represents a solution and contains the row indices of the queens on that board configuration.
    """

    def is_safe(board, row, col):
        """
        Checks if it's safe to place a queen at position (row, col) on the current board configuration.
        
        Args:
            board (list): The current board configuration.
            row (int): The row index of the potential new queen.
            col (int): The column index of the potential new queen.
        
        Returns:
            bool: True if it's safe to place a queen at position (row, col), False otherwise.
        """
        for i in range(row):
            if board[i] == col or \
                board[i] - i == col - row or \
                board[i] + i == col + row:
                return False
        return True

    def solve(board, row):
        """
        Recursively tries to fill the current row with queens.
        
        Args:
            board (list): The current board configuration.
            row (int): The current row index.
        
        Returns:
            list: A list of lists, where each inner list represents a solution and contains the row indices of the queens on that board configuration.
        """
        if row == n:
            # If we've filled all rows, return the current board configuration as a solution
            solutions.append(board[:])
            return
        for col in range(n):
            if is_safe(board, row, col):
                # Place a queen at position (row, col) and recursively try to fill the next row
                board[row] = col
                solve(board, row + 1)
    
    solutions = []
    solve([-1]*n, 0)
    return [[i+1 for i in sol] for sol in solutions]
```

**Example Usage**
----------------

```python
>>> n_queens(4)
[[(1, 3), (2, 0), (3, 1), (4, 2)], 
 [(1, 2), (2, 3), (3, 1), (4, 0)], 
 [(1, 4), (2, 0), (3, 2), (4, 3)], 
 [(1, 3), (2, 2), (3, 4), (4, 1)]]
```

Note that this function uses a recursive approach to generate all valid solutions. The `is_safe` helper function checks if it's safe to place a queen at a given position on the current board configuration. The `solve` helper function recursively tries to fill each row with queens and returns a list of lists, where each inner list represents a solution and contains the row indices of the queens on that board configuration.
