Here is the Python function `merge_intervals` that merges overlapping intervals:

```python
def merge_intervals(intervals):
    if not intervals:
        return []

    # Sort intervals by their start value
    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]

    for current in intervals[1:]:
        last_merged = merged[-1]

        if current[0] <= last_merged[1]:
            merged[-1] = (last_merged[0], max(last_merged[1], current[1]))
        else:
            merged.append(current)

    return merged
```

This function assumes that the input intervals are a list of tuples, where each tuple represents an interval. The function first checks if the input is empty and returns an empty list in this case. Then it sorts the intervals by their start value and initializes `merged` with the first interval. It then iterates over the remaining intervals and merges any overlapping ones into `merged`. If an interval does not overlap with the last merged one, it is added to `merged`.

Example use cases:
```python
print(merge_intervals([(1, 3), (2, 6)]))  # Output: [(1, 6)]
print(merge_intervals([(1, 4), (5, 8), (10, 12)]))  # Output: [(1, 4), (5, 8), (10, 12)]
```
