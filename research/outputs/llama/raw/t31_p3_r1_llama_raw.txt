Here is the function `serialize_tree` to convert a binary tree into a string:

```python
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

def serialize_tree(root):
    """
    Serialize a binary tree into a string.

    Args:
        root (TreeNode): The root of the binary tree.

    Returns:
        str: A string representation of the binary tree.
    """

    def _serialize(node, result):
        if node is None:
            return result + "X,"  # Representing an empty node with 'X'
        
        result += str(node.val) + ","
        result = _serialize(node.left, result)
        result = _serialize(node.right, result)

        return result

    return _serialize(root, "")
```

Here's a breakdown of the code:

*   We use a nested function `_serialize` to perform the recursive serialization. This allows us to avoid polluting the outer namespace with extra variables.
*   In the case where `node` is `None`, we append `"X,"` to the result string, representing an empty node. This is based on the assumption that 'X' represents an empty tree in this context.
*   We call `_serialize` recursively for both `left` and `right` child nodes and append their results to the main result string.

You can use the function like so:

```python
# Example usage:
root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.right.left = TreeNode(4)

serialized_tree = serialize_tree(root)
print(serialized_tree)  # Output: "1,2,X,X,3,4,X,X"
```
