**Basic Calculator Function**
====================================

Here is a Python function that implements a basic calculator using a stack-based approach:
```python
def basic_calculator(s: str) -> int:
    """
    Evaluates a string math expression containing non-negative integers, +, -, (, ) and spaces.
    
    Args:
        s (str): The input math expression as a string.
    
    Returns:
        int: The result of the evaluated expression.
    """
    stack = []
    sign = 1
    num = 0

    for c in s:
        if c == ' ':
            continue
        
        if c.isdigit():
            num = num * 10 + int(c)
        
        elif c == '+':
            stack.append(sign * num)
            sign = 1
            num = 0
        
        elif c == '-':
            stack.append(sign * num)
            sign = -1
            num = 0
        
        elif c == '(':
            stack.append(num)
            num = 0
        
        elif c == ')':
            stack.append(sign * num)
            num = 0
            
            # Evaluate the expression inside the parentheses
            total = 0
            while stack and stack[-1] != '+':
                total += stack.pop()
            
            # Add the evaluated value to the top of the stack
            if stack:
                stack[-1] += total
            else:
                stack.append(total)
    
    # Evaluate any remaining numbers or parentheses at the end
    total = 0
    while stack:
        total += stack.pop()
    
    return total
```
**Explanation**
---------------

This function uses a stack to keep track of intermediate results. We iterate through each character in the input string, handling digits, operators, and parentheses accordingly.

*   When we encounter a digit, we accumulate it as part of the current number.
*   When we encounter an operator (+ or -), we push the current number (with its sign) onto the stack and reset the number to 0. We also update the sign for the next number.
*   When we encounter an open parenthesis, we push the current number onto the stack and reset it to 0.
*   When we encounter a close parenthesis, we evaluate the expression inside by adding up all numbers on the stack (excluding signs) until we reach a '+' or we're done. We then add this evaluated value to the top of the stack.

Finally, after processing the entire input string, we sum up any remaining numbers in the stack and return the result as an integer.

**Example Use Cases**
---------------------

```python
print(basic_calculator("1 + 2 + (3 + 4)"))  # Output: 10
print(basic_calculator("(5 - 6) + 7"))  # Output: 6
print(basic_calculator("8 + 9"))  # Output: 17
```
