```python
def rotate_array(nums, k):
    """
    Rotates the given list 'nums' to the right by 'k' positions.

    :param nums: List of integers or other elements.
    :param k: Number of positions to rotate the array to the right.
    :return: The rotated list.
    """
    n = len(nums)
    # Handle cases where k is larger than the length of the array
    k = k % n
    
    if k == 0:
        return nums
    
    # Rotate the array
    return nums[-k:] + nums[:-k]

# Example usage:
nums = [1, 2, 3, 4, 5]
k = 2
rotated_nums = rotate_array(nums, k)
print(rotated_nums)  # Output: [4, 5, 1, 2, 3]
```

### Explanation:
- **`n = len(nums)`**: This line calculates the length of the array.
- **`k = k % n`**: This handles cases where `k` is larger than the length of the array by taking the modulo. For example, if `k` is 7 and the length of `nums` is 5, this step ensures that `k` becomes 2 (i.e., `7 % 5 = 2`).
- **`return nums[-k:] + nums[:-k]`**: This line performs the actual rotation. `nums[-k:]` gets the last `k` elements of the array, and `nums[:-k]` gets all but the last `k` elements. Concatenating these two parts results in a right-rotated version of the original list.

This function will work efficiently for most practical use cases and handles edge cases where `k` is larger than the length of the array.
