Certainly! Below is a Python function named `dijkstra_shortest_path` that implements Dijkstra's algorithm to find the shortest path from a given start node to all other nodes in a weighted graph. The graph is represented as an adjacency list where each key is a node and its value is another dictionary representing the adjacent nodes with their corresponding edge weights.

```python
def dijkstra_shortest_path(graph, start):
    # Initialize distances to all nodes as infinity, except the start node which is 0
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    
    # Priority queue to hold (distance, node) pairs; using a list of tuples and sorting it manually
    priority_queue = [(0, start)]
    
    while priority_queue:
        current_distance, current_node = min(priority_queue, key=lambda x: x[0])
        
        # If the distance in the distances dictionary is smaller than the one we just found, skip
        if current_distance > distances[current_node]:
            continue
        
        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            
            # Only consider this new path if it's better
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                priority_queue.append((distance, neighbor))
        
        # Remove the node from the priority queue after processing
        priority_queue = [(d, n) for d, n in priority_queue if n != current_node]
    
    return distances

# Example usage:
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1}
}

start_node = 'A'
shortest_paths = dijkstra_shortest_path(graph, start_node)
print("Shortest paths from node", start_node, "to all other nodes:", shortest_paths)
```

This function initializes the distances to infinity and sets the distance of the start node to zero. It then uses a priority queue (implemented as a list) to always expand the nearest unvisited node until all reachable nodes have been processed. The shortest paths from the start node to each other node are returned in the `distances` dictionary.
