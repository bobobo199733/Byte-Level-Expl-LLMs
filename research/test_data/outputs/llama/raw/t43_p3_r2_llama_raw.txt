**Binary Tree Inorder Traversal**
================================

Here's a Python function to perform an in-order traversal of a binary tree:

```python
class Node:
    """Represents a node in the binary tree."""
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

def binary_tree_inorder(tree):
    """
    Returns the inorder traversal of a binary tree.

    :param tree: The root node of the binary tree.
    :return: A list containing the values in the order they were visited.
    """
    result = []
    _inorder_helper(tree, result)
    return result

def _inorder_helper(node, result):
    """Recursive helper function to perform inorder traversal."""
    if node:
        # Recursively visit left subtree
        _inorder_helper(node.left, result)
        
        # Visit current node
        result.append(node.value)
        
        # Recursively visit right subtree
        _inorder_helper(node.right, result)

# Example usage:
if __name__ == "__main__":
    # Create a sample binary tree:
    #       4
    #     /   \
    #    2     6
    #   / \   / \
    #  1   3 5   7

    root = Node(4)
    root.left = Node(2)
    root.right = Node(6)
    root.left.left = Node(1)
    root.left.right = Node(3)
    root.right.left = Node(5)
    root.right.right = Node(7)

    print(binary_tree_inorder(root))  # Output: [1, 2, 3, 4, 5, 6, 7]
```

In this implementation:

*   We define a `Node` class to represent each node in the binary tree.
*   The `binary_tree_inorder` function takes the root node of the binary tree as input and returns a list containing the values visited in order.
*   A recursive helper function `_inorder_helper` performs the actual inorder traversal. It visits nodes in the following order: left subtree, current node, right subtree.

This code is well-structured, readable, and concise. The example usage demonstrates how to create a binary tree and call `binary_tree_inorder` with it.
