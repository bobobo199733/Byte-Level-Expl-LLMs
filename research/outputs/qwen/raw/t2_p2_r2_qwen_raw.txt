```python
def is_balanced(s: str) -> bool:
    # Mapping of closing brackets to their corresponding opening brackets
    bracket_map = {')': '(', ']': '[', '}': '{'}
    
    # Stack to keep track of opening brackets
    stack = []
    
    for char in s:
        if char in bracket_map.values():
            # If it's an opening bracket, push onto the stack
            stack.append(char)
        elif char in bracket_map.keys():
            # If it's a closing bracket, check the top of the stack
            if not stack or stack.pop() != bracket_map[char]:
                return False
        else:
            # Ignore all other characters
            continue
    
    # Check if stack is empty (all opening brackets have been matched)
    return not stack

# Example usage:
print(is_balanced("{[()]}"))  # True
print(is_balanced("({[)]}"))  # False
print(is_balanced("a(b)c[d{e}]f"))  # True
```

### Explanation:

1. **Bracket Mapping**: We use a dictionary to map each closing bracket to its corresponding opening bracket.
2. **Stack for Tracking Brackets**: A stack is used to keep track of the opening brackets encountered as we iterate through the string.
3. **Iterate Through String**:
   - For every character, if it's an opening bracket, push it onto the stack.
   - If it's a closing bracket, check if the stack is empty or if the top element on the stack doesn't match the corresponding opening bracket (as per the mapping). If either condition is true, return `False`.
4. **Final Check**: After processing all characters, if the stack is empty, it means all brackets were correctly matched and nested.

This function will correctly handle strings containing `()`, `[]`, `{}` while ignoring other characters, and return `True` if the string's brackets are balanced and correctly nested, or `False` otherwise.
