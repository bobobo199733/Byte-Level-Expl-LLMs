```python
def is_balanced(s: str) -> bool:
    # Dictionary to hold matching pairs of brackets
    bracket_pairs = {')': '(', ']': '[', '}': '{'}
    
    # Stack to keep track of opening brackets
    stack = []
    
    for char in s:
        if char in bracket_pairs.values():  # If it's an opening bracket, push onto the stack
            stack.append(char)
        elif char in bracket_pairs.keys():  # If it's a closing bracket, check for balance
            if not stack or stack[-1] != bracket_pairs[char]:
                return False
            stack.pop()
    
    # If the stack is empty, all brackets were balanced and nested correctly
    return len(stack) == 0

# Example usage:
print(is_balanced("{[()]}"))  # True
print(is_balanced("({[)]}"))  # False
print(is_balanced("{[}"))     # False
```

### Explanation:

1. **Bracket Pairs**: We define a dictionary `bracket_pairs` that maps each closing bracket to its corresponding opening bracket.
2. **Stack Initialization**: A stack is initialized to keep track of the opening brackets as we iterate through the string.
3. **Iterate Through String**:
   - For each character in the string, if it's an opening bracket (found in `bracket_pairs.values()`), push it onto the stack.
   - If it's a closing bracket (found in `bracket_pairs.keys()`), check if the stack is empty or the top of the stack doesn't match the corresponding opening bracket. If either condition is true, return `False` because the brackets are not balanced.
4. **Final Check**: After processing all characters, if the stack is empty, it means all brackets were properly closed and nested; otherwise, they were not.

This function correctly handles the specified set of brackets `{`, `}`, `[`, `]`, and `(`, `)`.
