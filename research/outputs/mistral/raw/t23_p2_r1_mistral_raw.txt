Here's a simple recursive function implementation for fast power calculation:

```python
def fast_power(base, exponent):
    if exponent == 0:
        return 1
    elif exponent % 2 == 0:
        squared = fast_power(base * base, exponent // 2)
        return squared * squared if base >= 0 else (squared * squared) // (base ** 2)
    else:
        return base * fast_power(base * base, exponent - 1)
```

This function uses the method of squaring to perform efficient exponentiation for both positive and negative exponents. It checks if the exponent is even or odd, and adjusts the result accordingly for handling negatives bases.
