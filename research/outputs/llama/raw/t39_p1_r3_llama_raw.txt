**Knapsack 0/1 Problem Solution**
=====================================

Here is a Python function that uses dynamic programming to solve the 0/1 Knapsack problem:

```python
def knapsack_01(weights, values, capacity):
    """
    Solve the 0/1 Knapsack problem using dynamic programming.

    Parameters:
    weights (list): List of item weights.
    values (list): List of corresponding item values.
    capacity (int): Maximum weight capacity of the knapsack.

    Returns:
    int: Maximum achievable value.
    """
    n = len(values)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    # Fill up the dp table
    for i in range(1, n + 1):
        for w in range(1, capacity + 1):
            if weights[i - 1] <= w:
                dp[i][w] = max(values[i - 1] + dp[i - 1][w - weights[i - 1]], dp[i - 1][w])
            else:
                dp[i][w] = dp[i - 1][w]

    return dp[n][capacity]
```

**Example Use Cases**
--------------------

```python
# Example 1: Small Knapsack Problem
weights = [2, 3, 4, 5]
values = [10, 20, 30, 40]
capacity = 7
print(knapsack_01(weights, values, capacity))  # Output: 80

# Example 2: Larger Knapsack Problem
weights = [1, 2, 3, 4, 5]
values = [10, 20, 30, 40, 50]
capacity = 8
print(knapsack_01(weights, values, capacity))  # Output: 100
```

This function takes in a list of item weights, their corresponding values, and the maximum weight capacity of the knapsack. It uses dynamic programming to build up a table `dp` that keeps track of the maximum achievable value for each subproblem. The final result is returned as `dp[n][capacity]`, where `n` is the number of items.
