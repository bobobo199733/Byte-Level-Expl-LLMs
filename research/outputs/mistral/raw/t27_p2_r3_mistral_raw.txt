```python
def trapping_rain_water(heights):
    if not heights:
        return 0

    n = len(heights)
    left, right = [0]*n, [0]*n

    # Initialize left and right maxima
    left[1] = heights[0]
    for i in range(2, n):
        left[i] = max(left[i-1], heights[i])

    right[-1] = heights[-1]
    for i in range(n-2, -1, -1):
        right[i] = max(right[i+1], heights[i])

    # Calculate the trapped water level
    result = 0
    for i in range(n):
        result += min(left[i], right[i]) - heights[i]

    return result
```

This function works by first calculating the maximum height from the left (left array) and from the right (right array). Then, it iterates through each position in the original array and computes the trapped water level at that index as the minimum of left and right heights minus the current height. The total trapped rainwater is the sum of all these individual trapped water levels.
