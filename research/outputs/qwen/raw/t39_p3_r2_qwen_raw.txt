The 0/1 Knapsack Problem is a classic optimization problem where we are given weights and values of `n` items and we need to determine the number of each item to include in a collection so that the total weight is less than or equal to a given limit `capacity`, and the total value is as large as possible. 

To solve this, we can use dynamic programming with a 2D array where `dp[i][w]` represents the maximum value that can be obtained using the first `i` items with a capacity of `w`.

Here's how you can implement it in Python:

```python
def knapsack_01(weights, values, capacity):
    n = len(values)
    
    # Initialize the DP table
    dp = [[0 for _ in range(capacity + 1)] for _ in range(n + 1)]
    
    # Fill the DP table
    for i in range(1, n + 1):
        for w in range(1, capacity + 1):
            if weights[i - 1] <= w:
                # Item can be included
                dp[i][w] = max(values[i - 1] + dp[i - 1][w - weights[i - 1]], dp[i - 1][w])
            else:
                # Item cannot be included
                dp[i][w] = dp[i - 1][w]
    
    # The answer will be in the bottom-right corner of the DP table
    return dp[n][capacity]

# Example usage:
weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
capacity = 5

print(knapsack_01(weights, values, capacity))  # Output should be the maximum value achievable
```

### Explanation:

- **Initialization**: We create a `dp` table with dimensions `(n+1) x (capacity+1)`. The extra row and column handle the case where no items are considered or the total weight is zero.
  
- **Filling the DP Table**:
  - For each item from 1 to `n`, we iterate over all possible capacities from 1 to `capacity`.
  - If the current item's weight can fit into the capacity (`weights[i - 1] <= w`), then we decide whether to include it or not by taking the maximum value between including and excluding the item.
  
- **Result**: The result is stored in `dp[n][capacity]`, which represents the maximum value that can be obtained using all items with a total capacity of `capacity`.

This solution runs in `O(n * capacity)` time, where `n` is the number of items and `capacity` is the weight limit.
