Here is a Python solution using the `heapq` module to efficiently find the kth largest element:

```python
import heapq

def kth_largest(nums, k):
    """
    Returns the kth largest number in the list.

    Args:
        nums (list): A list of integers.
        k (int): The index of the desired number from the end (1-indexed).

    Returns:
        int: The kth largest number in the list.
    """
    return heapq.nlargest(k, nums)[-1]
```

This function uses `heapq.nlargest` to find the k largest elements in the list, and then returns the last one (`[-1]`) since Python lists are 0-indexed.
