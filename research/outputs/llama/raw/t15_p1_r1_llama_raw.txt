Here's an implementation of the topological sort algorithm using depth-first search (DFS). This function assumes that the input `graph` is represented as a dictionary where each key is a node and its corresponding value is a list of neighboring nodes.

```python
def topological_sort(graph):
    """
    Returns a valid topological ordering of a directed acyclic graph.
    
    Args:
        graph: A dictionary representing the graph, where each key is a node
            and its corresponding value is a list of neighboring nodes.
    
    Returns:
        A list representing a valid topological ordering of the graph. If the
        input graph contains cycles, an empty list is returned.
    """

    # Initialize the stack to keep track of visited nodes with no outgoing edges
    order = []

    # Initialize a set to keep track of visited nodes
    visited = set()

    # Initialize a dictionary to store the in-degree of each node
    in_degree = {node: 0 for node in graph}

    # Calculate the in-degree of each node
    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    # Define a helper function to perform DFS on a node
    def dfs(node):
        # Mark the current node as visited
        visited.add(node)

        # Visit all neighbors with no outgoing edges
        for neighbor in graph[node]:
            if neighbor not in visited:
                dfs(neighbor)

        # Add the current node to the order list
        order.append(node)

    # Perform DFS on all nodes with no incoming edges (i.e., those with in-degree 0)
    for node in in_degree:
        if in_degree[node] == 0:
            dfs(node)

    # If the order list contains all nodes and edges, it represents a valid topological ordering
    if len(order) != len(graph):
        return []

    # Reverse the order list to get the correct topological ordering (from left to right)
    return order[::-1]
```

Here's an example usage:

```python
graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D'],
    'D': []
}

print(topological_sort(graph))  # Output: ['D', 'C', 'B', 'A']
```

In this example, the function correctly returns a valid topological ordering of the graph. If you try to run it on a graph containing cycles (e.g., `graph = {'A': ['B'], 'B': ['A']}`), it will return an empty list as expected.
