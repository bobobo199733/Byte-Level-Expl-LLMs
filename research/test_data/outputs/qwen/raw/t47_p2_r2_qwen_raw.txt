```python
def basic_calculator(s):
    def calculate(stack, sign=1):
        # Helper function to calculate the result of numbers in the stack with the given sign
        res = 0
        num = 0
        while stack:
            item = stack.pop()
            if isinstance(item, int):
                num = (item * sign) + num
            elif item == '+':
                res += num
                num = 0
            elif item == '-':
                res += num
                num = 0
                sign *= -1
            elif item == '(':
                stack.append(res)
                stack.append(sign)
                break
        if num != 0:
            res += num * sign
        return res

    # Remove spaces from the input string
    s = s.replace(' ', '')

    stack = []
    current_number = None
    current_sign = 1

    i = 0
    while i < len(s):
        if s[i].isdigit():
            start = i
            while i + 1 < len(s) and s[i + 1].isdigit():
                i += 1
            current_number = int(s[start:i+1])
            stack.append(current_number)
        elif s[i] in '+-':
            # Handle sign changes
            if current_number is not None:
                stack.append(current_number)
                current_number = None
            stack.append(s[i])
            current_sign = 1 if s[i] == '+' else -1
        elif s[i] == '(':
            # Push the current state of the stack and sign onto the stack, then start a new sub-expression
            stack.append(current_number or 0)
            stack.append(current_sign)
            current_number = None
            current_sign = 1
            i += 1
            while s[i] != ')':
                if s[i].isdigit():
                    start = i
                    while i + 1 < len(s) and s[i + 1].isdigit():
                        i += 1
                    stack.append(int(s[start:i+1]))
                    current_number = None
                elif s[i] in '+-':
                    # Handle sign changes for sub-expression
                    if current_number is not None:
                        stack.append(current_number)
                        current_number = None
                    stack.append(s[i])
                    current_sign = 1 if s[i] == '+' else -1
                i += 1
            stack.pop()  # Pop the sign before (
            stack.append(calculate(stack, current_sign))
        i += 1

    if current_number is not None:
        stack.append(current_number)
    
    return calculate(stack)

# Example usage:
print(basic_calculator("1 + (2 - 3)"))  # Output: 0
print(basic_calculator("(1+(4+5+2)-3)+(6+8)"))  # Output: 23
```

### Explanation:

1. **Helper Function `calculate`**: This function is used to evaluate the current stack of numbers and signs, handling parentheses properly.
   - It iterates through the stack from right to left, processing each element as it encounters a number or an operator.

2. **Main Loop**: The main loop processes the input string character by character:
   - If the current character is a digit, it extracts the full integer value and pushes it onto the stack.
   - If the current character is `+` or `-`, it pushes this sign to the stack and updates the current sign for subsequent digits.
   - If the current character is `'('`, it saves the current state (current number and sign) by pushing them onto the stack, then starts evaluating the sub-expression inside the parentheses.

3. **Final Calculation**: After processing all characters in the string, any remaining numbers on the stack are pushed into the helper function for final evaluation.

This approach ensures that nested expressions within parentheses are evaluated correctly before being integrated back into the main calculation.
