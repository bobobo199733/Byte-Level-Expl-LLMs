Here is a Python solution for the problem:

```python
import heapq

def merge_k_sorted_lists(lists):
    """
    Combines multiple sorted lists into one sorted list.

    Args:
        lists (list): A list of lists, each containing integers that are already sorted.

    Returns:
        list: A new sorted list that contains all elements from the input lists.
    """

    # Initialize a min heap with the first element from each list
    min_heap = [(lst[0], i, 0) for i, lst in enumerate(lists) if lst]

    # Heapify the min heap to maintain the heap property
    heapq.heapify(min_heap)

    # Initialize an empty list to store the result
    merged_list = []

    while min_heap:
        # Extract the smallest element from the heap
        val, list_idx, elem_idx = heapq.heappop(min_heap)

        # Append the extracted element to the result list
        merged_list.append(val)

        # If there are more elements in the current list, push the next element into the heap
        if elem_idx + 1 < len(lists[list_idx]):
            heapq.heappush(min_heap, (lists[list_idx][elem_idx + 1], list_idx, elem_idx + 1))

    return merged_list

# Example usage:
list1 = [1, 3, 5]
list2 = [2, 4, 6]
list3 = [0, 7, 8]

print(merge_k_sorted_lists([list1, list2, list3]))  # Output: [0, 1, 2, 3, 4, 5, 6, 7, 8]
```

In this code:

*   We use a min heap to efficiently extract the smallest element from each of the input lists.
*   The `merge_k_sorted_lists` function combines multiple sorted lists into one sorted list. It iteratively extracts elements from the heaps and appends them to the result list in sorted order.

The time complexity is O(N log K), where N is the total number of elements across all input lists, and K is the number of input lists. The space complexity is O(K + N).
