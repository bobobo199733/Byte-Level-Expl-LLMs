Here is the required Python function for matrix multiplication:

```python
def matrix_multiply(A, B):
    if len(A) != len(B[0]):  # Check if number of columns in A matches the number of rows in B
        raise ValueError("Matrix dimensions are incompatible.")

    result = [[0]*len(B[0][0]) for _ in range(len(A))]

    for i in range(len(A)):
        for j in range(len(B[0])):
            for k in range(len(A[0])):
                result[i][j] += A[i][k]*B[k][j]

    return result
```

This function checks if the number of columns in matrix A matches the number of rows in matrix B, and raises a ValueError if they are not compatible. It then computes the matrix product of A and B using nested loops.
