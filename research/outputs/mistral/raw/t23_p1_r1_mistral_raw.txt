Here's a Python function named `fast_power` that computes `base` raised to the power of `exponent` using an optimized approach, specifically by avoiding repeated multiplications:

```python
def fast_power(base, exponent):
    result = 1
    while exponent > 0:
        if exponent % 2 == 1:
            result *= base
        base *= base
        exponent //= 2
    return result
```

This approach can significantly speed up the calculation for large exponents because it minimizes repeated multiplications.
