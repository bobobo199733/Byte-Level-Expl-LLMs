**Breadth-First Search (BFS) Shortest Path Function**
====================================================

Here's a Python function to calculate the length of the shortest path between two nodes in an unweighted graph using Breadth-First Search (BFS).

```python
from collections import deque

def bfs_shortest_path(graph, start, target):
    """
    Calculate the length of the shortest path between two nodes in an unweighted graph.

    Args:
        graph (dict): Adjacency list representation of the graph.
        start (node): Starting node for the search.
        target (node): Target node to find the shortest path to.

    Returns:
        int: Length of the shortest path, or -1 if no path exists.
    """
    # Check if start and target are in the graph
    if start not in graph or target not in graph:
        raise ValueError("Start or target node is not in the graph")

    # Initialize a queue for BFS with the starting node
    queue = deque([(start, 0)])  # (node, distance)

    # Initialize a set to keep track of visited nodes
    visited = {start}

    while queue:
        node, dist = queue.popleft()

        if node == target:
            return dist

        for neighbor in graph[node]:
            if neighbor not in visited:
                queue.append((neighbor, dist + 1))
                visited.add(neighbor)

    # If no path is found, return -1
    return -1
```

**Example Use Case**
--------------------

Let's consider a sample unweighted graph represented as an adjacency list:

```python
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}
```

To find the length of the shortest path from node `A` to node `F`, we can call the function like this:

```python
print(bfs_shortest_path(graph, 'A', 'F'))  # Output: 2 (e.g., A -> C -> F or A -> E -> F)
```

This function has a time complexity of O(|E| + |V|) due to its BFS traversal. It assumes that the input graph is represented as an adjacency list, where each key in the dictionary represents a node and its corresponding value is a list of neighboring nodes.
