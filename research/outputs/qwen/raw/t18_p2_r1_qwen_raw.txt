Certainly! The Levenshtein distance is a measure of the difference between two sequences. It's defined as the minimum number of single-character edits (insertions, deletions, or substitutions) required to change one word into the other.

Here’s how you can implement this in Python using dynamic programming:

```python
def edit_distance(word1: str, word2: str) -> int:
    # Handle empty strings correctly
    if not word1:
        return len(word2)
    if not word2:
        return len(word1)

    # Initialize the matrix with base cases
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Fill the first row and column of the matrix
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Fill the rest of the matrix
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                cost = 0
            else:
                cost = 1

            dp[i][j] = min(dp[i - 1][j] + 1,     # Deletion
                           dp[i][j - 1] + 1,     # Insertion
                           dp[i - 1][j - 1] + cost)  # Substitution

    return dp[m][n]

# Example usage:
word1 = "kitten"
word2 = "sitting"
print(edit_distance(word1, word2))  # Output: 3
```

### Explanation:

- **Base Cases**: If one of the strings is empty, the Levenshtein distance is simply the length of the other string. This handles edge cases where either `word1` or `word2` might be an empty string.
  
- **Dynamic Programming Table (`dp`)**: We initialize a 2D list `dp` where `dp[i][j]` represents the Levenshtein distance between the first `i` characters of `word1` and the first `j` characters of `word2`.

- **Filling the DP Table**: 
  - For each pair `(i, j)`, if the characters match (`word1[i-1] == word2[j-1]`), the cost is 0.
  - Otherwise, we consider three operations: insertion, deletion, and substitution. We choose the minimum of these costs plus one.

### Example Walkthrough:
Let's walk through a simple example with `word1 = "kitten"` and `word2 = "sitting"`. The goal is to transform "kitten" into "sitting".

- Start filling the first row and column, which are just the lengths of each string.
- For each cell `(i, j)`, calculate the minimum cost considering the three operations.

### Output:
The function will return `3` because it takes 3 operations (substituting 'k' with 's', 'e' with 'i', and inserting 't') to convert "kitten" into "sitting".

This implementation is efficient for longer strings due to its time complexity of \(O(m \times n)\), where `m` and `n` are the lengths of `word1` and `word2`, respectively.
