In Python, here's a recursive function that generates all valid parenthesis combinations for a given integer `n`. This function uses two variables `left` and `right` to keep track of the current number of opening and closing parentheses respectively.

```python
def generate_parentheses(n):
    result = []

    def backtrack(left, right, openings, closings):
        if left == 0 and right == 0:
            result.append(openings)

        if left > 0:
            new_openings = openings + '('
            new_closings = closings
            backtrack(left - 1, right, new_openings, new_closings)

        if left < right and right > 0:
            new_openings = openings
            new_closings = closings + ')'
            backtrack(left, right - 1, new_openings, new_closings)

    backtrack(n, n, '', '')
    return result
```

This function will generate all valid parentheses combinations for `n` pairs of matching parentheses. You can test the function with:

```python
print(generate_parentheses(3))  # Output: [('(())', '()))', '((())', '()())']
```
