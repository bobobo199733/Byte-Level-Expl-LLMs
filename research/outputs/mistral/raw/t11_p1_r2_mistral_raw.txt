Here's a Python function called `coin_change` that finds the minimum number of coins required to make up a given amount using dynamic programming approach. The function assumes that `coins` is a list containing unique positive integers and `amount` is the target amount.

```python
def coin_change(coins, amount):
    if not coins or amount < 1:
        return -1

    dp = [0] + [float('inf')] * amount  # Initialize a list for dynamic programming table
    for c in coins:
        for i in range(c, amount+1):
            dp[i] = min(dp[i], dp[i-c] + 1)

    if dp[-1] == float('inf'):
        return -1

    return dp[-1]
```

This function creates a dynamic programming table `dp`, and initializes it with `0` at the first index (representing no coins) and `float('inf')` for the rest of the indices. It then iterates through the `coins` list, checking each coin value `c` and updating the corresponding entries in the table from `c` to the target amount `amount`. The final result is returned from the last index of the table.

If it is not possible to make up the given amount using the provided coins, then the function returns `-1`.
