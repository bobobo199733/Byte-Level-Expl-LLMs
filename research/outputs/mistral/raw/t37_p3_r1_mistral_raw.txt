Here is a Python solution for the problem using Floyd's Cycle-Finding Algorithm, also known as the tortoise and hare algorithm. This method makes use of two pointers moving at different speeds through the linked list to detect whether there is a cycle.

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def get_length(head: ListNode) -> int:
    count = 0
    current = head
    while current is not None:
        count += 1
        current = current.next
    return count

def linked_list_cycle(head: ListNode) -> bool:
    if not head or not head.next:
        return False

    fast = head.next
    slow = head
    length = get_length(head)

    for _ in range(1, length + 1):
        if fast is None or fast.next is None:
            return False

        fast = fast.next.next
        slow = slow.next

        if fast == slow:
            return True

    return False
```

In this code, the `ListNode` class represents a node in the linked list. The `linked_list_cycle()` function takes a head node as input and checks whether there is a cycle by using Floyd's Cycle-Finding Algorithm. It returns `True` if the linked list contains a cycle and `False` otherwise.
