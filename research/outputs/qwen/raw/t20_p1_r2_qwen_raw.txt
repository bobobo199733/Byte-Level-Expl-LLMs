```python
import heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def merge_k_sorted_lists(lists):
    # Create an iterator for each list in the input lists
    iterators = [iter(lst) for lst in lists]
    
    # Use heapq to merge multiple sorted inputs into a single sorted output
    merged_list = []
    min_heap = [(next(it, None), i, it) for i, it in enumerate(iterators) if next(it, None) is not None]
    
    heapq.heapify(min_heap)
    
    while min_heap:
        # Get the smallest element from the heap
        val, index, iterator = heapq.heappop(min_heap)
        merged_list.append(val)
        
        try:
            # Advance to the next node in that list and push it onto the heap if there is one
            next_val = next(iterator)
            heapq.heappush(min_heap, (next_val, index, iterator))
        except StopIteration:
            pass
    
    return merged_list

# Helper function to create a linked list from a Python list
def create_linked_list(values):
    head = ListNode()
    current = head
    for value in values:
        current.next = ListNode(value)
        current = current.next
    return head.next if head else None

# Function to convert a linked list to a Python list
def linked_list_to_list(node):
    result = []
    while node is not None:
        result.append(node.val)
        node = node.next
    return result

# Example usage:
list1 = create_linked_list([1, 4, 5])
list2 = create_linked_list([1, 3, 4])
list3 = create_linked_list([2, 6])

lists = [list1, list2, list3]
merged_list = merge_k_sorted_lists(lists)

print(merged_list)  # Output: [1, 1, 2, 3, 4, 4, 5, 6]
```

### Explanation:
- **ListNode Class**: This class is used to define the structure of a node in the linked list.
- **merge_k_sorted_lists Function**:
  - Iterators for each input list are created and pushed into a min heap.
  - The smallest element from the top of the heap is popped, and its value is added to the result list. If there are more elements in that list, it gets pushed back onto the heap.
- **create_linked_list Function**: Converts a Python list into a linked list for testing purposes.
- **linked_list_to_list Function**: Converts a linked list back into a Python list for easy printing and verification.

This approach ensures that each element is added to the result exactly once, making it efficient with a time complexity of O(N log k), where N is the total number of elements across all lists and k is the number of lists.
