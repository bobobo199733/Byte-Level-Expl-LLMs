**N-Queens Problem Solution**
=====================================

Here's a Python function named `n_queens` that solves the N-Queens problem using backtracking.

```python
def n_queens(n):
    """
    Returns all valid solutions for the N-Queens problem where no queens attack each other.
    
    Args:
        n (int): The number of queens to place on an n x n chessboard.
    
    Returns:
        list: A list of lists, where each sublist represents a row of queens in a solution.
              Each queen is represented by her column index (0-based).
    """
    
    # Handle edge cases
    if n <= 1:
        return [[]]
    
    def solve(queens, xy_dif, xy_sum):
        # If we've placed all queens, add the current configuration to the solutions list
        if len(queens) == n:
            return [queens[:]]
        
        solutions = []
        
        for i in range(n):
            # Skip placements that would attack a queen
            if (i in queens) or ((xy_dif + i) in xy_dif) or ((xy_sum - i) in xy_sum):
                continue
            
            # Mark new positions as attacked
            solve(queens + [i], xy_dif + {i}, xy_sum | {n + i})
            
        return solutions
    
    # Start with an empty board and no attacked positions
    return solve([], set(), set())
```

**Example Usage**
-----------------

```python
for solution in n_queens(4):
    print(solution)
```

This will output all valid configurations for the 4-Queens problem.
