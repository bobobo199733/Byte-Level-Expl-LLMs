**Cycle Detection in Linked Lists**
=====================================

Here is the Python function `linked_list_cycle` that uses Floyd's Tortoise and Hare algorithm to efficiently detect cycles in linked lists.

```python
class Node:
    """Simple node class for the linked list."""
    def __init__(self, value):
        self.value = value
        self.next = None

def linked_list_cycle(head):
    """
    Detects whether a linked list contains a cycle.

    Args:
        head (Node): The head of the linked list.

    Returns:
        bool: True if a cycle exists, False otherwise.
    """
    if not head or not head.next:
        # Handle empty lists and lists with one node
        return False

    tortoise = head  # Moves one step at a time
    hare = head      # Moves two steps at a time

    while True:
        if not hare or not hare.next:
            # If the fast pointer reaches the end, no cycle exists
            return False

        tortoise = tortoise.next
        hare = hare.next.next

        if tortoise == hare:
            # If the slow and fast pointers meet, a cycle exists
            return True
```

**Explanation**
---------------

The `linked_list_cycle` function uses Floyd's Tortoise and Hare algorithm to detect cycles in linked lists. This algorithm is efficient because it only requires a single pass through the list, resulting in a time complexity of O(n).

Here's how the algorithm works:

1.  Initialize two pointers: `tortoise` (the slow pointer) and `hare` (the fast pointer). Both start at the head of the linked list.
2.  Move the `tortoise` one step at a time, while moving the `hare` two steps at a time.
3.  If the `hare` reaches the end of the list or if it becomes `None`, no cycle exists in the list.
4.  If the `tortoise` and `hare` pointers meet (i.e., they are pointing to the same node), a cycle exists in the list.

**Example Use Case**
--------------------

```python
# Create a linked list with a cycle
node1 = Node(1)
node2 = Node(2)
node3 = Node(3)

node1.next = node2
node2.next = node3
node3.next = node2  # Introduce the cycle

print(linked_list_cycle(node1))  # Output: True
```

This implementation is robust, readable, and efficient. It correctly handles empty lists and detects cycles of all sizes using Floyd's Tortoise and Hare algorithm.
