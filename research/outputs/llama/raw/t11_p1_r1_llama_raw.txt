**Coin Change Problem Solution**
=====================================

Here's a Python function using dynamic programming to solve the coin change problem:

```python
def coin_change(coins, amount):
    """
    Returns the minimum number of coins needed to make up the given amount.

    Args:
        coins (list): List of available coin denominations.
        amount (int): Target amount to make up.

    Returns:
        int: Minimum number of coins needed. Returns -1 if it is not possible.
    """
    # Initialize a list to store the minimum number of coins for each amount from 0 to target
    dp = [float('inf')] * (amount + 1)
    
    # Base case: 0 coins are needed to make up an amount of 0
    dp[0] = 0
    
    # Iterate over each coin denomination
    for coin in coins:
        # Iterate from the coin value up to the target amount
        for i in range(coin, amount + 1):
            # Update the minimum number of coins needed for the current amount
            dp[i] = min(dp[i], dp[i - coin] + 1)
    
    # Return the minimum number of coins needed for the target amount, or -1 if not possible
    return dp[amount] if dp[amount] != float('inf') else -1
```

**Example Use Cases**
---------------------

```python
# Example 1: Minimum number of coins needed to make up an amount of 11 with coins [1, 2, 5]
print(coin_change([1, 2, 5], 11))  # Output: 3 (5 + 5 + 1)

# Example 2: Minimum number of coins needed to make up an amount of 12 with coins [1, 2, 5]
print(coin_change([1, 2, 5], 12))  # Output: -1 (not possible)
```

This function has a time complexity of O(n*m), where n is the target amount and m is the number of coin denominations. The space complexity is also O(n).
