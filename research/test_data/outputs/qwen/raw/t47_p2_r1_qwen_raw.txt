def basic_calculator(s):

- **Current Number and Operator**: `current_number` keeps track of the current number being processed, and `current_operator` holds the last operator seen before encountering a new number or an operation.
- **Digit Accumulation**: When we encounter a digit, we accumulate it into `current_number`.
- **Operator Change**: When we encounter an operator (or reach the end of the string), we push the result based on the current operator onto the stack and update `current_operator` to the new one. We then reset `current_number` for the next number.
- **Final Summation**: After processing all characters, the final result is obtained by summing up all elements in the stack.
