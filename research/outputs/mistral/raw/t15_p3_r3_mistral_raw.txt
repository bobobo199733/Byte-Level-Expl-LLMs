To implement the topological sort algorithm, I'll use Depth-First Search (DFS) with a helper function `dfs()` to find the topological order. Here is a Python implementation using recursive DFS:

```python
from collections import defaultdict

def topological_sort(graph):
    indegree = defaultdict(int)
    for node in graph:
        for neighbor in graph[node]:
            indegree[neighbor] += 1

    queue = [node for node in graph if indegree[node] == 0]

    sorted_nodes = []

    while queue:
        current_node = queue.pop()
        sorted_nodes.append(current_node)

        for neighbor in graph[current_node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                queue.append(neighbor)

    if len(sorted_nodes) != len(graph):
        print("The given graph is not a Directed Acyclic Graph (DAG).")
        return None

    return sorted_nodes
```

The `topological_sort()` function first calculates the indegrees of each node in the given graph. It then initializes an empty queue with all nodes that have an indegree of 0. In the main loop, it pops a node from the queue, adds it to the sorted list and decrements the indegrees of its neighbors. If a neighbor's indegree becomes 0, it is added to the queue for further processing.

If all nodes are processed and the length of the sorted list matches the number of nodes in the graph, then the function returns the topological ordering. Otherwise, an error message is displayed because the given graph is not a Directed Acyclic Graph (DAG).
