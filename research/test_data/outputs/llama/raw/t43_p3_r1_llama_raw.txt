**Binary Tree Inorder Traversal**
=====================================

Here's an implementation of a Python function to perform an inorder traversal on a binary tree.

```python
class Node:
    """Represents a node in the binary tree."""
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


def binary_tree_inorder(tree):
    """
    Performs an inorder traversal of the binary tree and returns the result as a list.

    :param tree: The root node of the binary tree.
    :return: A list containing the values of the nodes in inorder.
    """
    def _inorder_helper(node, result):
        if node:
            # Recursively traverse left subtree
            _inorder_helper(node.left, result)
            
            # Append current node's value to result
            result.append(node.value)
            
            # Recursively traverse right subtree
            _inorder_helper(node.right, result)

    result = []
    _inorder_helper(tree, result)
    return result


# Example usage:

# Create a sample binary tree:
#      4
#     / \
#    2   5
#   / \   \
#  1   3   6

root = Node(4)
root.left = Node(2)
root.right = Node(5)
root.left.left = Node(1)
root.left.right = Node(3)
root.right.right = Node(6)

print(binary_tree_inorder(root))  # Output: [1, 2, 3, 4, 5, 6]
```

This implementation defines a `Node` class to represent each node in the binary tree. The `binary_tree_inorder` function uses a helper function `_inorder_helper` to recursively traverse the left subtree, visit the current node, and then recursively traverse the right subtree.
