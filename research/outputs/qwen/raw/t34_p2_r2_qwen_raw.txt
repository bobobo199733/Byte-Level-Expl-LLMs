```python
def binary_search_rotated(values, target):
    if not values:
        return -1

    left, right = 0, len(values) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        # If the middle element is the target value
        if values[mid] == target:
            return mid
        
        # Determine which side is properly sorted
        if values[left] <= values[mid]:  # Left side is sorted
            if values[left] <= target < values[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:  # Right side is sorted
            if values[mid] < target <= values[right]:
                left = mid + 1
            else:
                right = mid - 1
    
    return -1

# Example usage:
arr = [4, 5, 6, 7, 0, 1, 2]
target = 0

```

### Explanation:
- **Input Validation**: The function first checks if the array is empty and returns `-1` immediately.
- **Binary Search Loop**: The main loop uses binary search principles to narrow down the search space.
- **Determining Sorted Side**: For each midpoint, it determines which side of the array (`left` or `right`) is properly sorted by comparing the values at the `left`, `mid`, and `right` indices.
- **Target Comparison**:
  - If the middle element is equal to the target, return its index.
  - Otherwise, decide whether to search in the left half or right half of the array based on where the target might be.
  
This approach ensures that even with duplicates and rotated arrays, the function will work correctly.
