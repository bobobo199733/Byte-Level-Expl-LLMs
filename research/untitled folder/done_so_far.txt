6. Grote ontdekking

Je ontdekte dat belangrijke bytes:

* NIET letterlijk “betekenisvolle bytes” zijn
* maar vaak wijzen naar:
    * implementation styles
    * control flow
    * API usage
    * library preferences
    * coding idioms

Dat was een belangrijk moment.

Bijvoorbeeld:

word_frequency

Llama:

* regex
* dict comprehension

Mistral:

* handmatige dict counting

Qwen:

* Counter + translate

Dus SHAP leert eigenlijk:

* implementatiegedrag
* niet puur random byte-noise

Dat is een sterk inzicht.

7. Byte tracing scripts

Je bouwde scripts die:

* byte 106/107 terugmappen
* naar:
    * opcode

    * generated source code

Dat was extreem belangrijk.

Want nu kan je:

SHAP importance

Dat maakt je explainability geloofwaardig.

⸻

8. Wat je ook ontdekte

Een bytepositie is niet stabiel semantisch.

Bijvoorbeeld:

* byte 107 kan bij één model:
    * COMPARE_OP
* bij andere:
    * LOAD_ATTR
    * CALL

Dus:

dezelfde bytepositie ≠ dezelfde semantische betekenis

Dat wordt waarschijnlijk een belangrijke limitation/discussion sectie.
