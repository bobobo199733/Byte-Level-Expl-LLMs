```python
def wildcard_match(s: str, p: str) -> bool:
    m, n = len(s), len(p)
    
    # dp[i][j] will be True if first i characters of s match first j characters of p.
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    
    # Empty pattern matches empty string
    dp[0][0] = True
    
    # Handle patterns with '*' at the beginning
    for j in range(1, n + 1):
        if p[j - 1] == '*':
            dp[0][j] = dp[0][j - 1]
    
    # Fill dp table
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if p[j - 1] == '?' or s[i - 1] == p[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            elif p[j - 1] == '*':
                dp[i][j] = dp[i][j - 1] or dp[i - 1][j]
    
    return dp[m][n]

# Example usage:
print(wildcard_match("abc", "a*c"))  # True
print(wildcard_match("abcd", "*d"))  # True
print(wildcard_match("abefcdgiescdfimde", "ab*cd?i*m*de"))  # True
print(wildcard_match("mississippi", "mis*is*p*."))
```

### Explanation:
- **DP Table**: We use a 2D DP table `dp` where `dp[i][j]` is `True` if the first `i` characters of `s` match the first `j` characters of `p`.
- **Base Case**: An empty pattern matches an empty string, so `dp[0][0] = True`. A pattern with a leading `*` can potentially match an empty string, so we initialize the appropriate cells.
- **Filling DP Table**:
  - If `p[j-1] == '?'` or `s[i-1] == p[j-1]`, then `dp[i][j] = dp[i-1][j-1]`.
  - If `p[j-1] == '*'`, it can match zero or more characters. So, `dp[i][j] = dp[i][j-1]` (matching one or more characters) or `dp[i-1][j]` (matching zero characters).

This approach ensures that the function handles all cases of wildcard matching efficiently.
