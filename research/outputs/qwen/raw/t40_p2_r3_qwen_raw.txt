```python
def autocomplete_system(words, prefix):
    if not words or not prefix:
        return []

    # Filter out words that start with the given prefix
    matching_words = [word for word in words if word.startswith(prefix)]
    
    # Sort the list of matching words (though it's already implicitly sorted by how strings work)
    matching_words.sort()

    return matching_words

# Example usage:
words = ["apple", "appetite", "application", "banana", "bandage", "appetizer"]
prefix = "app"
print(autocomplete_system(words, prefix))  # Output: ['apple', 'appetite', 'application', 'appetizer']
```

1. **Empty Input Handling**: The function first checks if either `words` or `prefix` is empty and returns an empty list in such cases.

2. **Filtering Matching Words**: A list comprehension is used to filter out words that start with the given prefix using the `startswith` method.

3. **Sorting**: Although sorting is not strictly necessary since Python's slicing and comparison operations will already return a lexicographically sorted result, we include it for clarity.

4. **Returning Results**: The function returns the list of matching words in sorted order.
