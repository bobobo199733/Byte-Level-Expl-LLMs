```python
def autocomplete_system(words, prefix):
    # Filter words that start with the given prefix
    matching_words = [word for word in words if word.startswith(prefix)]
    
    # Return the sorted list of matching words
    return sorted(matching_words)

# Example usage:
words = ["apple", "appetite", "application", "app", "apricot"]
prefix = "app"
print(autocomplete_system(words, prefix))  # Output: ['app', 'application', 'appetite']
```

### Explanation:
1. **Filtering**: We use a list comprehension to filter out words that do not start with the given `prefix`.
2. **Sorting**: The filtered words are then sorted using Python's built-in `sorted()` function, which returns them in alphabetical order by default.
