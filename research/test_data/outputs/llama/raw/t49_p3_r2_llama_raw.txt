Here is a Python function that solves the problem using dynamic programming:
```python
def word_break(s: str, word_dict: list[str]) -> bool:
    """
    Return True if the string s can be built by concatenating words from word_dict,
    False otherwise.

    :param s: input string
    :type s: str
    :param word_dict: dictionary of valid words
    :type word_dict: list[str]
    :return: True if s can be formed, False otherwise
    :rtype: bool
    """
    n = len(s)
    dp = [False] * (n + 1)  # dp[i] means s[:i+1] can be segmented into words from word_dict

    dp[0] = True  # empty string is always a segmentation
    for i in range(1, n + 1):
        for j in range(i):
            if dp[j] and s[j:i] in word_dict:
                dp[i] = True
                break  # no need to check other substrings

    return dp[n]
```
Here's an explanation of the code:

* We create a dynamic programming array `dp` of length `n + 1`, where `dp[i]` means that the substring `s[:i+1]` can be segmented into words from `word_dict`.
* We initialize `dp[0] = True`, since an empty string is always a segmentation.
* We iterate over all substrings `s[j:i]` of length 1 to `n`. For each substring, we check if it's in the word dictionary and if the preceding substring `s[:j]` can be segmented. If both conditions are true, we set `dp[i] = True`.
* Finally, we return `dp[n]`, which means that the entire string `s` can be segmented into words from `word_dict`.

Example usage:
```python
s = "leetcode"
word_dict = ["leet", "code"]
print(word_break(s, word_dict))  # True

s = "applepenapple"
word_dict = ["apple", "pen"]
print(word_break(s, word_dict))  # True

s = "catsandog"
word_dict = ["cats", "dog", "sand", "and", "cat"]
print(word_break(s, word_dict))  # False
```
