To implement the Topological Sort algorithm, I'll use Depth-First Search (DFS) with a stack to build the topological ordering of a Directed Acyclic Graph (DAG). Here is the Python implementation:

```python
def topological_sort(graph):
    visited, indegree, order = set(), {node: 0 for node in graph}, []

    def dfs(node):
        if node not in visited:
            visited.add(node)
            for neighbor in graph[node]:
                indegree[neighbor] -= 1
                if indegree[neighbor] == 0:
                    dfs(neighbor)
                    order.append(neighbor)

    for node in graph:
        if indegree[node] == 0:
            dfs(node)

    return list(reversed(order))
```

In the provided code, `graph` is a dictionary where keys are nodes and values are lists of their adjacent nodes. This representation assumes that there are no self-loops or multiple edges between any pair of nodes. The function initializes an empty visited set, an indegree dictionary, and an order list to store the topological sort result.

The `dfs` function is a recursive helper function used during DFS traversal. It takes a node as input and performs the following actions:

1. Mark the current node as visited.
2. Decrease the indegree of each neighbor by 1.
3. If the indegree of any neighbor becomes 0, recursively call `dfs` on that neighbor and add it to the order list.
4. Add the current node to the order list at the end of the DFS traversal (since we visit nodes in reverse topological order during DFS).

The main function iterates through all nodes in the graph, checks if their indegree is 0, and performs a DFS on that node if so. The resulting `order` will be a list containing the topologically sorted nodes.
