Here's an implementation of the Sieve of Eratosthenes algorithm in Python:

```python
def sieve_primes(n):
    is_prime = [True] * (n + 1)
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            for multiple in range(i*i, n+1, i):
                is_prime[multiple] = False
    primes = [p for p in range(2, n+1) if is_prime[p]]
    return primes
```

This function initializes a boolean array `is_prime` with all numbers up to n as prime. Then it iterates through the smaller prime numbers and marks their multiples as non-prime in the `is_prime` list. At last, it returns the primes by filtering the `is_prime` list.

You can call the function like this:

```python
primes = sieve_primes(100)  # primes up to 100
```
