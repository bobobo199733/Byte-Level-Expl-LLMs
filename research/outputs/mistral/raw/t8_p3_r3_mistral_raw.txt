To create a function in Python that checks the strength of a password, you can use the following criteria:

1. Minimum length: The password must have at least 8 characters.
2. Uppercase letters: The password should contain at least one uppercase letter.
3. Lowercase letters: The password should contain at least one lowercase letter.
4. Digits: The password should contain at least one digit.
5. Special characters: The password should contain at least one special character (e.g., !, @, #, $, %, &, etc.).
6. No repeating characters: The password shouldn't have more than two consecutive identical characters.

Here is the implementation of the `validate_password` function that checks these conditions:

```python
import re

def validate_password(password):
    if len(password) < 8:
        return False

    has_uppercase = bool(re.search('[A-Z]', password))
    has_lowercase = bool(re.search('[a-z]', password))
    has_digit = bool(re.search('\d', password))
    has_special = bool(re.search('[!@#$%^&*()]', password))

    if not (has_uppercase and has_lowercase and has_digit and has_special):
        return False

    if any(char == next_char for char, next_char in zip(password, password[1:])):
        return False

    return True
```

With this function, you can validate the strength of a password like so:

```python
print(validate_password("Password123$"))  # Returns True
print(validate_password("abcdefgh"))     # Returns True
print(validate_password("aaaaaab"))      # Returns False (Consecutive identical characters)
print(validate_password("PassWord123$")) # Returns False (Mixed case consistency)
```
