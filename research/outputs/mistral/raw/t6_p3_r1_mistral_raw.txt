```python
def wildcard_match(s, p):
    def match(s, m):
        if not s and not m:
            return True
        if not s or not m:
            return False
        if m[0] == '*':
            return match(s, m[1:])
        elif m[0] == '?' or m[0] == s[0]:
            return match(s[1:], m[1:]) if m else True
        return False

    return match(s, p)
```

This function uses recursion to iterate through the pattern and the string. It checks each character in the pattern and compares it with the corresponding character from the string (if any), or a '?' wildcard. The '*' wildcard matches any sequence of characters, so it calls itself with the remaining parts of both the pattern and the string. If the pattern is empty, the function only returns True if the string is also empty.
