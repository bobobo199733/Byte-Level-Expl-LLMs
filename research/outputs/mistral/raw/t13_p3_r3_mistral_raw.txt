In Python, here's a function called `spiral_order` that takes a square matrix as input and returns its elements in spiral order:

```python
def spiral_order(matrix):
    if not matrix or not matrix:
        return []

    top = 0
    bottom = len(matrix) - 1
    left = 0
    right = len(matrix[0]) - 1
    direction = 'right'

    result = []

    while True:
        if direction == 'right':
            for i in range(left, right + 1):
                result.append(matrix[top][i])
            top += 1
            if top > bottom:
                break

            for i in range(top, bottom + 1):
                result.append(matrix[i][right])
            right -= 1
            if left > right:
                direction = 'down'

        elif direction == 'down':
            for i in range(right, left - 1, -1):
                result.append(matrix[bottom][i])
            bottom -= 1
            if top > bottom:
                direction = 'left'

            for i in range(bottom, top - 1, -1):
                result.append(matrix[i][left])
            left += 1
            if left > right:
                direction = 'right'

        elif direction == 'left':
            for i in range(left - 1, right, -1):
                result.append(matrix[top][i])
            top += 1
            if top > bottom:
                direction = 'up'

        elif direction == 'up':
            for i in range(top, bottom + 1):
                result.append(matrix[i][left])
            left += 1
            if left > right:
                direction = 'left'

    return result
```

This function uses a while loop to iterate through the matrix in spiral order, changing directions when it reaches the boundaries of the current section. It keeps track of the top, bottom, left, and right edges of the current section, as well as the current direction. The direction changes when the left or right edge is reached during a right or left traversal, and when the top or bottom edge is reached during an up or down traversal.

Example usage:

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(spiral_order(matrix)) # Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
```
