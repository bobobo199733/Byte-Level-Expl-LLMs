To find the median of two sorted arrays using binary search, we can implement an efficient algorithm that has a time complexity of \(O(\log(min(n, m)))\), where \(n\) and \(m\) are the lengths of the two arrays.

Here's a Python function to achieve this:

```python
def find_kth_element(nums1, nums2, k):
    len1, len2 = len(nums1), len(nums2)
    
    # Ensure that nums1 is the smaller array
    if len1 > len2:
        return find_kth_element(nums2, nums1, k)
    
    # Edge case: one of the arrays is empty
    if not nums1:
        return nums2[k]
    
    if k == 0:
        return min(nums1[0], nums2[0])
    
    # Binary search
    i = min(k // 2, len1 - 1)
    j = k - i
    
    if nums1[i] < nums2[j]:
        return find_kth_element(nums1[i + 1:], nums2[:j], k - (i + 1))
    else:
        return find_kth_element(nums1[:i], nums2[j:], k - i)

def median_of_two_sorted_arrays(nums1, nums2):
    total_length = len(nums1) + len(nums2)
    
    # If the total length is odd
    if total_length % 2 == 1:
        return find_kth_element(nums1, nums2, total_length // 2)
    else:
        # If the total length is even
        return (find_kth_element(nums1, nums2, total_length // 2 - 1) +
                find_kth_element(nums1, nums2, total_length // 2)) / 2.0

# Example usage:
nums1 = [1, 3]
nums2 = [2]
print(median_of_two_sorted_arrays(nums1, nums2))  # Output: 2.0

nums1 = [1, 2]
nums2 = [3, 4]
print(median_of_two_sorted_arrays(nums1, nums2))  # Output: 2.5
```

### Explanation:
1. **find_kth_element Function**:
   - This function finds the k-th smallest element in two sorted arrays.
   - It uses binary search to narrow down the search space by comparing elements from both arrays.

2. **median_of_two_sorted_arrays Function**:
   - Calculates the total length of both arrays.
   - If the combined length is odd, it returns the middle element directly.
   - If the combined length is even, it calculates the average of the two middle elements.

This approach ensures that the function runs efficiently and avoids merging or sorting the entire array.
