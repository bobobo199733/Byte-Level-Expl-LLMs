**Course Schedule Validation Function**
=====================================

The following Python function validates whether it's possible to complete all courses based on the given prerequisites.

```python
from collections import defaultdict, deque

def course_schedule(num_courses, prerequisites):
    """
    Validate if all courses can be completed based on prerequisites.

    Args:
        num_courses (int): Total number of courses.
        prerequisites (list[list[int]]): List of pairs (course, prerequisite).

    Returns:
        bool: True if all courses can be completed, False otherwise.
    """

    # Create an adjacency list to represent the graph
    graph = defaultdict(list)
    visited = set()
    for course, prereq in prerequisites:
        graph[prereq].append(course)

    # Perform DFS from each unvisited node
    for i in range(1, num_courses + 1):
        if i not in visited and not dfs(graph, i, visited, set()):
            return False

    return True


def dfs(graph, course, visited, current_path):
    """
    Perform Depth-First Search to detect cycles.

    Args:
        graph (dict): Adjacency list of the graph.
        course (int): Current course being visited.
        visited (set): Set of visited courses.
        current_path (set): Set of courses in the current path.

    Returns:
        bool: True if no cycle found, False otherwise.
    """

    # If already in the current path, a cycle is detected
    if course in current_path:
        return False

    # Mark as visited and add to current path
    visited.add(course)
    current_path.add(course)

    # Visit all neighbors of the current course
    for neighbor in graph[course]:
        if neighbor not in visited or not dfs(graph, neighbor, visited, current_path):
            return False

    # Remove from current path after visiting all neighbors
    current_path.remove(course)
    return True


# Example usage:
num_courses = 4
prerequisites = [[1,0],[2,0],[3,1],[3,2]]
print(course_schedule(num_courses, prerequisites))  # Output: True

num_courses = 2
prerequisites = [[1,0],[0,1]]
print(course_schedule(num_courses, prerequisites))  # Output: False
```

This solution uses a Depth-First Search (DFS) approach to traverse the graph represented by the adjacency list. The function `course_schedule` initializes the graph and visited set, then iterates over all courses to perform DFS from each unvisited node. If a cycle is detected during DFS, the function returns False; otherwise, it returns True if all courses can be completed.

The example usage demonstrates two scenarios: one where all courses can be completed (with prerequisites), and another where it's not possible due to circular dependencies.
