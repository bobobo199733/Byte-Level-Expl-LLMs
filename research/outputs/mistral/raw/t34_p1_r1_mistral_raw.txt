def binary_search_rotated(values, target):

        mid_value = values[mid]

        if mid_value == target:
            return mid

        elif values[left] <= mid_value <= values[right]:
            right = mid - 1  # Move to the left of the pivot.
        else:
            left = mid + 1  # Move to the right of the pivot.

    return -1  # If 'left' and 'right' overlap after iterations, the target is not found.

This function uses a binary search algorithm with some modifications to handle rotated sorted arrays. The main idea is to find the pivot (if it exists) by looking for an element that is greater than its following element, or smaller than its preceding element. If no such element is found within the array, then the array is not rotated and a regular binary search can be performed. The function returns the index of the target if found, or -1 if not found.
