Here is a high-quality, readable, and well-documented Python function to merge multiple sorted lists:

```python
import heapq

def merge_k_sorted_lists(lists):
    """
    Merge multiple sorted lists into one sorted list.

    Args:
        lists (list of lists): A list containing multiple sorted lists.

    Returns:
        list: A single sorted list containing all elements from the input lists.
    """
    # Use a heap to efficiently merge the sorted lists
    merged_list = []
    min_heap = []

    for i, lst in enumerate(lists):
        # Push the first element of each list onto the heap along with its index and original list index
        if lst:
            heapq.heappush(min_heap, (lst[0], i, 0))

    while min_heap:
        # Extract the smallest element from the heap
        val, list_idx, elem_idx = heapq.heappop(min_heap)
        merged_list.append(val)

        # Push the next element of the same list onto the heap if it exists
        if elem_idx + 1 < len(lists[list_idx]):
            next_val = lists[list_idx][elem_idx + 1]
            heapq.heappush(min_heap, (next_val, list_idx, elem_idx + 1))

    return merged_list

# Example usage:
list1 = [1, 3, 5]
list2 = [2, 4, 6]
list3 = [0, 7, 8]

merged = merge_k_sorted_lists([list1, list2, list3])
print(merged)  # Output: [0, 1, 2, 3, 4, 5, 6, 7, 8]
```

This function uses a heap to efficiently merge the sorted lists. The time complexity of this approach is O(N log K), where N is the total number of elements across all lists and K is the number of input lists. This is because we perform a constant amount of work for each element in the input lists, and the heap operations (insertion and extraction) take logarithmic time.
