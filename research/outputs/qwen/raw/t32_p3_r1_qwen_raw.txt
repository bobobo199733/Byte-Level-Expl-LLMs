Certainly! The N-Queens problem is a classic example of backtracking where we try to place `n` queens on an `n x n` chessboard such that no two queens threaten each other. Here's how you can implement the solution in Python:

```python
def n_queens(n):
    def is_safe(board, row, col):
        # Check this row on left side
        for i in range(col):
            if board[row][i] == 1:
                return False

        # Check upper diagonal on left side
        for i, j in zip(range(row, -1, -1), range(col, -1, -1)):
            if board[i][j] == 1:
                return False

        # Check lower diagonal on left side
        for i, j in zip(range(row, n, 1), range(col, -1, -1)):
            if board[i][j] == 1:
                return False

        return True

    def solve_n_queens_util(board, col):
        # base case: If all queens are placed then return true
        if col >= n:
            solution = []
            for i in range(n):
                temp = ''
                for j in range(n):
                    temp += 'Q' if board[i][j] == 1 else '.'
                solution.append(temp)
            solutions.append(solution)
            return True

        # Consider this column and try placing this queen in all rows one by one
        res = False
        for i in range(n):
            if is_safe(board, i, col):
                # Place this queen in board[i][col]
                board[i][col] = 1
                # Recur to place rest of the queens
                res = solve_n_queens_util(board, col + 1) or res
                # If placing queen in board[i][col] doesn't lead to a solution then remove queen from board[i][col]
                board[i][col] = 0

        return res

    def print_solutions(solutions):
        for sol in solutions:
            for row in sol:
                print(row)
            print()

    # Initialize the board with all zeros
    board = [[0 for _ in range(n)] for _ in range(n)]
    solutions = []
    
    if solve_n_queens_util(board, 0):
        print_solutions(solutions)
    else:
        print("No solution exists")

# Example usage:
n_queens(4)
```

### Explanation:

1. **`is_safe(board, row, col)`** - This function checks whether a queen can be placed at `board[row][col]`. It ensures that there are no queens in the same column or diagonals.
2. **`solve_n_queens_util(board, col)`** - This is the recursive utility function used to place queens one by one starting from the given column and returns true if a solution exists for all columns. If a queen cannot be placed in any row in this column, it backtracks and tries placing it in another row.
3. **`print_solutions(solutions)`** - This function prints each of the solutions found.

### Example:

When you call `n_queens(4)`, it will print all valid configurations for a 4x4 board where no two queens threaten each other.

This implementation uses backtracking to explore all possible configurations and only stores those that are valid.
