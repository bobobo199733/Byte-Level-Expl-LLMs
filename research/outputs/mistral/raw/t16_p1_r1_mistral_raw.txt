To create a Sudoku solver function, we'll use the Depth-First Search (DFS) algorithm along with some basic Sudoku rules:

1. Each row, column, and 3x3 grid must contain unique numbers from 1 to 9.
2. If all possible values have been filled in for a given cell, we can move on to the next one.
3. We'll check each cell in order from left to right, then top to bottom.

Here is an implementation of the Sudoku solver function:

```python
def is_valid(board, row, col, num):
    # Check the current row
    for i in range(9):
        if board[row][i] == num:
            return False

    # Check the current column
    for i in range(9):
        if board[i][col] == num:
            return False

    # Check the 3x3 grid (starting at the top-left cell)
    start_row = (row - row % 3)
    start_col = (col - col % 3)

    for i in range(3):
        for j in range(3):
            if board[start_row + i][start_col + j] == num:
                return False

    return True

def sudoku_solver(board):
    def solve_recursive(row, col):
        # Base case - no more empty cells to fill
        if row >= 9:
            return True

        for i in range(9):
            # Check if this number can be placed in the current cell
            if is_valid(board, row, col, i + 1):
                board[row][col] = i + 1

                # If we found a solution, try to find one for the next cell
                if solve_recursive(row + 1, col):
                    return True

                # If not, backtrack and try another number in the current cell
                board[row][col] = 0

        return False

    # Start solving from the top-left corner
    return solve_recursive(0, 0)
```

To use this function, simply call it with your Sudoku puzzle as a 2D list:

```python
board = [
    [5, 3, 0, 0, 7, 0, 0, 0, 0],
    [6, 0, 0, 1, 9, 5, 0, 0, 0],
    [0, 9, 8, 0, 0, 0, 0, 6, 0],
    [8, 0, 0, 0, 6, 0, 0, 0, 3],
    [4, 0, 0, 8, 0, 3, 0, 0, 1],
    [7, 0, 0, 0, 2, 0, 0, 0, 6],
    [0, 6, 0, 0, 0, 0, 2, 8, 0],
    [0, 0, 0, 4, 1, 9, 0, 3, 5],
    [0, 0, 0, 7, 0, 0, 0, 1, 9]
]

sudoku_solver(board)
print(board)
```
