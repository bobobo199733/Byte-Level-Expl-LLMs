```python
def heap_sort(values):
    def build_heap(arr, n, i=None):
        if i is None:
            i = len(arr) // 2 - 1
        if i > 0:
            build_heap(arr, n, i - 1)
        left = 2 * i + 1
        right = 2 * i + 2
        largest = i
        if left < n and arr[largest] < arr[left]:
            largest = left
        if right < n and arr[largest] < arr[right]:
            largest = right
        if largest != i:
            arr[i], arr[largest] = arr[largest], arr[i]
            build_heap(arr, n, largest)

    def heapify(arr):
        n = len(arr)
        build_heap(arr, n)

    if not values or len(values) <= 1:
        return values

    sorted_list = []
    heapify(values)

    while values:
        largest = values.pop()
        sorted_list.append(largest)
        heapify(values)

    return sorted_list
```

This function first builds a max-heap with the provided list using the `build_heap` helper function, then sorts the list by systematically removing the maximum element from the heap and appending it to the sorted list. The `heapify` function maintains the heap invariant after each insertion or removal of an element. The original input list is not modified during this process.
