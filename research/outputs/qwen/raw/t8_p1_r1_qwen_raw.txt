Certainly! Below is an example of a Python function `validate_password` that checks if a given password meets certain criteria:

1. The password must be at least 8 characters long.
2. The password must contain at least one uppercase letter.
3. The password must contain at least one lowercase letter.
4. The password must contain at least one digit.

Here is the implementation of this function:

```python
def validate_password(password):
    """
    Validates a given password according to specific criteria:
    
    - Password length should be at least 8 characters.
    - Password should contain at least one uppercase letter.
    - Password should contain at least one lowercase letter.
    - Password should contain at least one digit.

    Args:
        password (str): The password to validate.

    Returns:
        bool: True if the password is valid, False otherwise.
    """
    
    # Check for minimum length
    if len(password) < 8:
        return False
    
    # Check for presence of uppercase letter
    has_uppercase = any(c.isupper() for c in password)
    
    # Check for presence of lowercase letter
    has_lowercase = any(c.islower() for c in password)
    
    # Check for presence of digit
    has_digit = any(c.isdigit() for c in password)
    
    # Return True if all conditions are met, otherwise False
    return has_uppercase and has_lowercase and has_digit

# Example usage:
print(validate_password("StrongPass123"))  # Output: True
print(validate_password("weakpass"))       # Output: False
```

### Explanation:

- **Minimum Length Check**: The function first checks if the password is at least 8 characters long.
- **Uppercase Letter Check**: It uses a generator expression with `any()` to check if there is at least one uppercase letter in the password.
- **Lowercase Letter Check**: Similarly, it checks for the presence of at least one lowercase letter.
- **Digit Check**: It also checks for at least one digit.

The function returns `True` only if all these conditions are met. Otherwise, it returns `False`.
