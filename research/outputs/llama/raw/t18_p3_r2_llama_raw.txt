**Edit Distance Function**
=========================

The edit distance between two strings is the minimum number of operations (insertions, deletions, and substitutions) required to change one string into the other.

Here's a Python function that implements this using dynamic programming:
```python
def edit_distance(word1: str, word2: str) -> int:
    """
    Returns the minimum number of edits needed to transform word1 into word2.
    
    :param word1: The original string.
    :param word2: The target string.
    :return: The edit distance between word1 and word2.
    """

    # Initialize a matrix to store the edit distances
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Base cases
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Fill in the rest of the matrix
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if word1[i - 1] == word2[j - 1] else 1
            dp[i][j] = min(
                dp[i - 1][j] + 1,       # Deletion
                dp[i][j - 1] + 1,       # Insertion
                dp[i - 1][j - 1] + cost  # Substitution
            )

    return dp[m][n]
```
**Example Use Cases**
--------------------

```python
print(edit_distance("kitten", "sitting"))  # Output: 3
print(edit_distance("hello", "world"))  # Output: 4
print(edit_distance("", ""))  # Output: 0
```
This function uses a dynamic programming approach to build up the edit distance matrix. It starts by initializing the base cases (where one of the strings is empty) and then fills in the rest of the matrix using the minimum number of edits required for each position.

The time complexity is O(m \* n), where m and n are the lengths of the two input strings. The space complexity is also O(m \* n).
