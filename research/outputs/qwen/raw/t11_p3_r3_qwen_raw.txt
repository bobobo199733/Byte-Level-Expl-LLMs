Certainly! To solve this problem, we can use dynamic programming (DP). The idea is to build up a solution for the given `amount` using the provided `coins`. We'll maintain an array where each index represents an amount and its value at that index will be the minimum number of coins required to make that exact amount. If it's impossible to form that amount, we'll mark it with `-1`.

Here's how you can implement this:

```python
def coin_change(coins, amount):
    # Initialize a DP array where dp[i] represents the minimum number of coins needed to make up amount i.
    # We initialize all values to a large number (amount + 1) because we want to ensure that if no valid combination is found,
    # this will be replaced by -1. We also set dp[0] to 0 as it takes zero coins to make an amount of 0.
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    
    # Iterate over each possible amount from 1 to the given amount
    for i in range(1, amount + 1):
        # For each coin, check if it can be used to make up the current amount `i`
        for coin in coins:
            if i - coin >= 0 and dp[i - coin] != float('inf'):
                dp[i] = min(dp[i], dp[i - coin] + 1)
    
    # If dp[amount] is still infinity, it means we couldn't find a valid combination
    return dp[amount] if dp[amount] != float('inf') else -1

# Example usage:
coins = [1, 2, 5]
amount = 11
print(coin_change(coins, amount))  # Output: 3 (11 = 5 + 5 + 1)
```

### Explanation:

- **Initialization**: We initialize `dp` with a large value (`float('inf')`) for each possible amount up to the given `amount`. Setting `dp[0]` to 0 because zero coins are needed to make an amount of 0.
  
- **DP Table Filling**:
  - For every coin, we check if it can be used to form any amount from 1 to `amount`.
  - If a coin is less than or equal to the current amount and adding this coin forms a valid combination (i.e., `dp[i - coin]` has been computed), then update `dp[i]` with the minimum number of coins needed.

- **Result**: After filling the DP table, if `dp[amount]` contains a finite value, it means we've found a solution. Otherwise, return `-1`.

This approach ensures that we find the smallest number of coins or determine that no valid combination exists.
