**Knapsack 0/1 Problem Solution**
=====================================

The following Python function implements the optimal solution for the 0/1 knapsack problem using dynamic programming.

```python
def knapsack_01(weights, values, capacity):
    """
    Compute the maximum value that can be obtained without exceeding the capacity.
    
    Args:
        weights (list): List of item weights.
        values (list): List of item values corresponding to the weights.
        capacity (int): Maximum capacity of the knapsack.
        
    Returns:
        int: The optimal total value for the 0/1 knapsack problem.
    """
    
    # Handle empty input lists correctly
    if not weights or not values:
        return 0
    
    # Initialize a table to store the maximum value at each sub-capacity
    dp = [[0] * (capacity + 1) for _ in range(len(weights) + 1)]
    
    # Fill the table using bottom-up dynamic programming
    for i in range(1, len(weights) + 1):
        for j in range(1, capacity + 1):
            if weights[i - 1] <= j:
                dp[i][j] = max(values[i - 1] + dp[i - 1][j - weights[i - 1]],
                                dp[i - 1][j])
            else:
                dp[i][j] = dp[i - 1][j]
    
    # The maximum value is stored in the last cell of the table
    return dp[-1][-1]
```

**Example Usage**
-----------------

```python
weights = [2, 3, 4, 5]
values = [10, 20, 30, 40]
capacity = 10

max_value = knapsack_01(weights, values, capacity)
print("Maximum value:", max_value)  # Output: Maximum value: 60
```

This implementation uses dynamic programming to efficiently compute the optimal solution for the 0/1 knapsack problem. The function takes three arguments: `weights`, `values`, and `capacity`. It returns the maximum total value that can be obtained without exceeding the capacity.
