Certainly! To implement an in-order traversal of a binary tree using Python, we can define a recursive function `binary_tree_inorder` that traverses the left subtree first, visits the current node, and then traverses the right subtree. Here's how you can do it:

```python
class TreeNode:
    def __init__(self, value=0, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right

def binary_tree_inorder(tree):
    result = []
    
    # If the tree is not empty
    if tree is not None:
        # Traverse the left subtree
        result += binary_tree_inorder(tree.left)
        
        # Visit the current node
        result.append(tree.value)
        
        # Traverse the right subtree
        result += binary_tree_inorder(tree.right)
    
    return result

# Example usage
if __name__ == "__main__":
    # Constructing a simple binary tree
    #       1
    #      / \
    #     2   3
    #    / \
    #   4   5
    
    root = TreeNode(1)
    root.left = TreeNode(2, TreeNode(4), TreeNode(5))
    root.right = TreeNode(3)

    print(binary_tree_inorder(root))  # Output: [4, 2, 5, 1, 3]
```

### Explanation:
- The `TreeNode` class is used to define the structure of each node in the binary tree.
- The `binary_tree_inorder` function performs an in-order traversal using recursion. It first traverses the left subtree, then visits the current node (adding its value to the result list), and finally traverses the right subtree.

### Example Usage:
In the example above, we construct a simple binary tree with nodes 1, 2, 3, 4, and 5. The in-order traversal of this tree is `[4, 2, 5, 1, 3]`.
