**Coin Change Function**
========================

Here is a Python solution for the problem:

```python
def coin_change(coins, amount):
    """
    Finds the smallest number of coins needed to make the given amount.

    Args:
        coins (list): A list of available coin denominations.
        amount (int): The target amount to reach.

    Returns:
        int: The minimum number of coins required. -1 if impossible.
    """

    # Create a table to store the minimum number of coins for each amount
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0

    # Iterate over all possible amounts from 1 to target
    for i in range(1, amount + 1):
        # For each coin denomination, update the minimum number of coins if smaller
        for coin in coins:
            if coin <= i and dp[i - coin] + 1 < dp[i]:
                dp[i] = dp[i - coin] + 1

    # Return the minimum number of coins for the target amount, or -1 if impossible
    return dp[amount] if dp[amount] != float('inf') else -1
```

**Example Usage**
-----------------

```python
coins = [1, 2, 5]
amount = 11

print(coin_change(coins, amount))  # Output: 3 (because 5 + 5 + 1)
```

This function uses dynamic programming to find the minimum number of coins. It initializes a table `dp` with infinite values for each amount from 0 to target, then iterates over all possible amounts and coin denominations to update the minimum number of coins if smaller. Finally, it returns the minimum number of coins for the target amount or -1 if impossible.

Note that this function assumes that the input `coins` is a list of non-negative integers representing available coin denominations, and the input `amount` is a non-negative integer representing the target amount to reach.
