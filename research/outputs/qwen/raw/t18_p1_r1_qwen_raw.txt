Certainly! The Levenshtein distance (or edit distance) is a measure of the similarity between two strings, which can be calculated as the minimum number of single-character edits required to change one string into the other. These edits include insertions, deletions, and substitutions.

Here's a Python function that computes the edit distance using dynamic programming:

```python
def edit_distance(word1, word2):
    # Add 1 to both lengths to account for an empty string case
    m = len(word1) + 1
    n = len(word2) + 1
    
    # Create a matrix of size (m+1) x (n+1)
    dp = [[0] * n for _ in range(m)]
    
    # Initialize the first column values
    for i in range(m):
        dp[i][0] = i
    
    # Initialize the first row values
    for j in range(n):
        dp[0][j] = j
    
    # Fill the rest of the matrix
    for i in range(1, m):
        for j in range(1, n):
            cost = 0 if word1[i-1] == word2[j-1] else 1
            dp[i][j] = min(dp[i-1][j] + 1,      # Deletion
                           dp[i][j-1] + 1,      # Insertion
                           dp[i-1][j-1] + cost) # Substitution
    
    return dp[m-1][n-1]

# Example usage:
word1 = "kitten"
word2 = "sitting"
print(edit_distance(word1, word2))  # Output: 3
```

### Explanation:

1. **Matrix Initialization**: We initialize a matrix `dp` of size `(m+1) x (n+1)` where `m` and `n` are the lengths of `word1` and `word2`, respectively.

2. **Base Cases**:
   - The first column (`i=0`) represents the cost of transforming an empty string into a substring of `word2`.
   - The first row (`j=0`) represents the cost of transforming a substring of `word1` into an empty string.
   
3. **Filling the Matrix**: 
   - For each cell `(i, j)`, we calculate the minimum cost to transform the prefix of `word1` up to index `i-1` into the prefix of `word2` up to index `j-1`.
   - The cost is determined by comparing the last characters of the prefixes and applying the appropriate operation (substitution if they are different, otherwise no cost).

4. **Return Result**: The final value in `dp[m-1][n-1]` will be the minimum edit distance between the two strings.

This approach ensures that the function runs efficiently with a time complexity of O(m * n).
