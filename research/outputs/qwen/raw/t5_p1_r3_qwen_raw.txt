```python
def remove_k_digits(num: str, k: int) -> str:
    stack = []
    
    for digit in num:
        # While stack is not empty and we still need to remove digits
        # and the current digit is smaller than the last digit in the stack
        while k > 0 and stack and stack[-1] > digit:
            stack.pop()
            k -= 1
        stack.append(digit)
    
    # Remove the remaining excess digits if any
    while k > 0:
        stack.pop()
        k -= 1
    
    # Construct the resulting number from the stack
    result = ''.join(stack).lstrip('0')
    
    # If result is empty, return "0"
    return result if result else '0'

# Example usage:
print(remove_k_digits("1432219", 3))  # Output: "1219"
print(remove_k_digits("10200", 1))    # Output: "200"
print(remove_k_digits("10", 2))       # Output: "0"
```

This function uses a stack to ensure that when removing digits, the resulting number is as small as possible. It iterates through each digit in the input string and compares it with the last digit on the stack. If the current digit is smaller, it pops from the stack (removing the larger digit) until `k` becomes zero or the condition no longer holds. After processing all digits, any remaining removals are handled by popping from the stack. Finally, leading zeros are removed, and if the result string is empty, "0" is returned as specified.
