```python
def text_justification(words, max_width):
    """
    Takes a list of words and a maximum line width, 
    and returns a list of fully justified strings.

    :param words: List of words to be justified.
    :type words: list
    :param max_width: Maximum allowed width for each line.
    :type max_width: int
    :return: A list of justified lines as strings.
    :rtype: list
    """
    result = []
    current_line = []
    current_length = 0

    # Iterate over words and construct lines
    for word in words:
        if current_length + len(word) + len(current_line) > max_width:
            # Justify the current line with spaces between words
            justification_spaces = ' '.join([' ' * (max_width - len(''.join(current_line))) // len(current_line)] 
                                            + [' '] * (max_width - len(''.join(current_line)) % len(current_line)))
            
            if len(current_line) == 1:
                # Left-justify the last line with single spaces between words
                justification_spaces = ' ' * (max_width - len(''.join(current_line)))
            
            result.append(justification_spaces + ''.join(current_line))
            current_line = [word]
            current_length = len(word)
        else:
            current_line.append(word)
            current_length += len(word)

    # Add the last line
    justification_spaces = ' '.join([' ' * (max_width - len(''.join(current_line))) // len(current_line)] 
                                    + [' '] * (max_width - len(''.join(current_line)) % len(current_line)))
    
    if len(current_line) == 1:
        # Left-justify the last line with single spaces between words
        justification_spaces = ' ' * (max_width - len(''.join(current_line)))

    result.append(justification_spaces + ''.join(current_line))
    
    return result

# Example usage
words = ["This", "is", "an", "example", "of", "text", "justification."]
max_width = 16
print(text_justification(words, max_width))
```

In this function, we iterate over the list of words and construct each line. If adding a word to the current line would exceed the maximum width, we justify the current line with spaces between words and add it to the result list. We repeat this process until all words have been processed. Finally, we left-justify the last line with single spaces between words.

The function returns a list of justified strings, where each string represents a line in the output text. The last line is left-justified with single spaces between words and padded with trailing spaces.
