```python
def search_insert_position(nums, target):
    if len(nums) == 0:
        return 0

    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    # If the target is larger than all elements in the array, we will insert it at the end.
    if nums[-1] < target:
        return len(nums)

    # Otherwise, we find the first position where the target should be inserted
    for i in range(len(nums)):
        if nums[i] >= target:
            return i
```

This function uses a binary search to find the index of the target in a sorted array. If the target is not found, it will return the insertion position. The time complexity of this solution is O(log n), which makes it efficient for large arrays.
