To achieve an `O(log(m+n))` time complexity for finding the median of two sorted arrays, we can use a binary search approach. Here's how you can implement this in Python:

```python
def find_kth_element(arr1, arr2, k):
    if len(arr1) > len(arr2):
        arr1, arr2 = arr2, arr1

    m, n = len(arr1), len(arr2)
    imin, imax = 0, m

    while imin <= imax:
        i = (imin + imax) // 2
        j = k - i

        if i < m and arr2[j-1] > arr1[i]:
            # i is too small, must increase it
            imin = i + 1
        elif i > 0 and arr1[i-1] > arr2[j]:
            # i is too big, must decrease it
            imax = i - 1
        else:
            # i is perfect
            if i == 0: max_of_left = arr2[j-1]
            elif j == 0: max_of_left = arr1[i-1]
            else: max_of_left = max(arr1[i-1], arr2[j-1])

            if m + n % 2 == 1:
                return max_of_left

            if i == m: min_of_right = arr2[j]
            elif j == n: min_of_right = arr1[i]
            else: min_of_right = min(arr1[i], arr2[j])

            return (max_of_left + min_of_right) / 2.0

def median_of_two_sorted_arrays(nums1, nums2):
    total_length = len(nums1) + len(nums2)
    if total_length % 2 == 1:
        return find_kth_element(nums1, nums2, total_length // 2 + 1)
    else:
        return (find_kth_element(nums1, nums2, total_length // 2) +
                find_kth_element(nums1, nums2, total_length // 2 + 1)) / 2.0

# Example usage
nums1 = [1, 3]
nums2 = [2]
print(median_of_two_sorted_arrays(nums1, nums2))  # Output: 2.0

nums1 = [1, 2]
nums2 = [3, 4]
print(median_of_two_sorted_arrays(nums1, nums2))  # Output: 2.5
```

### Explanation:
- **find_kth_element**: This helper function finds the k-th smallest element in two sorted arrays using binary search.
- **median_of_two_sorted_arrays**: This function calculates the median of the combined length of both arrays by calling `find_kth_element` for the middle elements.

The key idea is to use binary search to split one array at a point such that there are approximately equal numbers of elements on either side, and then compare with the other array. This ensures that we can find the k-th element efficiently in logarithmic time.

This approach maintains the desired `O(log(m+n))` complexity for finding the median.
