Here's the Python code that uses Floyd's Cycle Detection Algorithm to determine whether a linked list contains a cycle.

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None


def linked_list_cycle(head):
    """
    Determines if a singly-linked list contains a cycle.
    
    Args:
        head (Node): The head node of the linked list.
        
    Returns:
        bool: True if the linked list has a cycle, False otherwise.
    """

    # Handle edge case where linked list is empty
    if not head or not head.next:
        return False

    # Initialize two pointers, one moving twice as fast as the other
    slow = head
    fast = head

    while True:
        # Move the 'slow' pointer one step at a time
        slow = slow.next
        
        # If there's a cycle and the fast pointer hasn't reached it yet,
        # then move both pointers two steps each iteration.
        if not fast or not fast.next:
            return False

        # Move the 'fast' pointer two steps at a time
        fast = fast.next.next

        # Check if the slow and fast pointers have converged (i.e., the cycle exists)
        if slow == fast:
            return True


# Example usage:

# Create linked list with cycle: 1 -> 2 -> 3 -> 4 -> 2 (cycle at node 2)
node1 = Node(1)
node2 = Node(2)
node3 = Node(3)
node4 = Node(4)

node1.next = node2
node2.next = node3
node3.next = node4
node4.next = node2  # Create the cycle

print(linked_list_cycle(node1))  # Output: True

# Example usage with an empty list:

empty_list_head = None
print(linked_list_cycle(empty_list_head))  # Output: False
```

This code defines a `Node` class to represent individual nodes within the linked list and implements Floyd's Cycle Detection Algorithm within the `linked_list_cycle` function. The function takes the head of the linked list as input, uses two pointers (the slow and fast pointer) to traverse the list, and returns True if it detects a cycle and False otherwise.
