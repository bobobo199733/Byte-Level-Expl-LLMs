```python
import re

def validate_password(password):
    # Minimum length requirement
    if len(password) < 8:
        return False
    
    # Regular expression to check for at least one uppercase letter, lowercase letter, digit, and special character
    pattern = r'^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*#?&])[A-Za-z\d@$!%*#?&]{8,}$'
    
    # Check if the password matches the pattern
    if re.match(pattern, password):
        return True
    else:
        return False

# Example usage:
print(validate_password("Abcdefg1"))  # Should return False (no special character)
print(validate_password("Abcdefg!"))  # Should return True
```

### Explanation:

- **Minimum Length Requirement**: The function first checks if the password is at least 8 characters long.
  
- **Regular Expression**:
  - `(?=.*[a-z])`: Ensures there is at least one lowercase letter.
  - `(?=.*[A-Z])`: Ensures there is at least one uppercase letter.
  - `(?=.*\d)`: Ensures there is at least one digit.
  - `(?=.*[@$!%*#?&])`: Ensures there is at least one special character (from the set `@$!%*#?&`).
  - `[A-Za-z\d@$!%*#?&]{8,}`: Matches any combination of letters, digits, and special characters that are at least 8 characters long.

- **Return Value**: The function returns `True` if all conditions are met, otherwise it returns `False`.
