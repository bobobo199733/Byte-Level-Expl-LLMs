To solve this problem with a time complexity of O(log(min(m, n))), we can use binary search on the smaller array to find the correct partition that ensures the median is correctly calculated. Here's how you can implement the `median_of_two_sorted_arrays` function:

```python
def median_of_two_sorted_arrays(nums1, nums2):
    # Ensure nums1 is the smaller array for efficiency
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    m, n = len(nums1), len(nums2)
    imin, imax, half_len = 0, m, (m + n + 1) // 2

    while imin <= imax:
        i = (imin + imax) // 2
        j = half_len - i

        if i < m and nums2[j-1] > nums1[i]:
            # i is too small, must increase it
            imin = i + 1
        elif i > 0 and nums1[i-1] > nums2[j]:
            # i is too big, must decrease it
            imax = i - 1
        else:
            # i is perfect
            if i == 0: max_of_left = nums2[j-1]
            elif j == 0: max_of_left = nums1[i-1]
            else: max_of_left = max(nums1[i-1], nums2[j-1])

            if (m + n) % 2 == 1:
                return float(max_of_left)

            if i == m: min_of_right = nums2[j]
            elif j == n: min_of_right = nums1[i]
            else: min_of_right = min(nums1[i], nums2[j])

            return (max_of_left + min_of_right) / 2.0
```

   - Adjust `imin` and `imax` based on whether the current partition point results in an invalid condition (i.e., elements from one half are greater than elements from the other half).

3. **Calculate Medians**:
   - Once the correct partition is found, determine the maximum of the left halves and the minimum of the right halves.
   - If the total number of elements is odd, return `max_of_left` as the median.
   - If the total number of elements is even, compute the average of `max_of_left` and `min_of_right`.
