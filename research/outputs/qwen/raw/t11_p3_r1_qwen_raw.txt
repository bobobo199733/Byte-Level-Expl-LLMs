Certainly! The problem you're describing is a classic example of a dynamic programming problem known as "Coin Change." Here's how we can implement it in Python:

```python
def coin_change(coins, amount):
    # Initialize a list to store the minimum number of coins needed for each amount from 0 to the target amount.
    dp = [float('inf')] * (amount + 1)
    
    # Base case: Zero coins are needed to make an amount of zero.
    dp[0] = 0
    
    # Fill in the DP table
    for i in range(1, amount + 1):
        for coin in coins:
            if i - coin >= 0:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    
    # If dp[amount] is still infinity, it means we couldn't make the amount with the given coins.
    return dp[amount] if dp[amount] != float('inf') else -1

# Example usage:
coins = [1, 2, 5]
amount = 11
print(coin_change(coins, amount))  # Output: 3 (as 11 can be made with 5 + 5 + 1)

coins = [2]
amount = 3
print(coin_change(coins, amount))  # Output: -1 (as it's impossible to make 3 with only coin of value 2)
```

### Explanation:
- **dp** is a list where `dp[i]` represents the minimum number of coins needed to make up the amount `i`.
- We initialize `dp[0] = 0` because zero coins are needed to make an amount of zero.
- For each amount from 1 to the target amount, we check if any coin can be used to make that amount. If so, we update the minimum number of coins needed for that amount by considering the minimum between the current value and `dp[i - coin] + 1`.
- Finally, if `dp[amount]` is still infinity (or `float('inf')`), it means the target amount cannot be made with the given coins.

This approach ensures an efficient solution to the problem using dynamic programming.
