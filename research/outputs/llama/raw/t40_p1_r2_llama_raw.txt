**Autocomplete System Function**
=====================================

```python
def autocomplete_system(words, prefix):
    """
    Returns a list of words from the given word list that match the provided prefix,
    sorted alphabetically.

    Args:
        words (list): A list of words to search through.
        prefix (str): The prefix to match against.

    Returns:
        list: A list of matching words in alphabetical order.
    """
    if not words or not prefix:
        return []

    # Filter the list of words for matches
    matching_words = [word for word in words if word.startswith(prefix)]

    # Sort the matching words alphabetically
    matching_words.sort()

    return matching_words
```

**Example Usage**
-----------------

```python
words = ["apple", "banana", "orange", "apricot"]
prefix = "app"

suggestions = autocomplete_system(words, prefix)
print(suggestions)  # Output: ['apple', 'apricot']
```

This function uses a list comprehension to filter the word list for matches, and then sorts the resulting list alphabetically. If either the input word list or prefix is empty, an empty list is returned.
