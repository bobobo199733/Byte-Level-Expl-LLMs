```python
def spiral_matrix(matrix):
    result = []
    
    # Define boundaries for the current layer
    top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1
    
    while top <= bottom and left <= right:
        # Traverse from left to right along the top boundary
        for i in range(left, right + 1):
            result.append(matrix[top][i])
        top += 1
        
        # Traverse from top to bottom along the right boundary
        for i in range(top, bottom + 1):
            result.append(matrix[i][right])
        right -= 1
        
        # Check if there are still rows left to process
        if top <= bottom:
            # Traverse from right to left along the bottom boundary
            for i in range(right, left - 1, -1):
                result.append(matrix[bottom][i])
            bottom -= 1
        
        # Check if there are still columns left to process
        if left <= right:
            # Traverse from bottom to top along the left boundary
            for i in range(bottom, top - 1, -1):
                result.append(matrix[i][left])
            left += 1
    
    return result

# Example usage:
matrix = [
    [ 1, 2, 3 ],
    [ 4, 5, 6 ],
    [ 7, 8, 9 ]
]

print(spiral_matrix(matrix))  # Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
```

### Explanation:
- **Initialization**: We start by setting the boundaries of the current layer (`top`, `bottom`, `left`, and `right`).
- **Traverse Top Boundary**: Traverse from left to right along the top boundary.
- **Traverse Right Boundary**: Traverse from top to bottom along the right boundary.
- **Traverse Bottom Boundary**: If there are still rows, traverse from right to left along the bottom boundary.
- **Traverse Left Boundary**: If there are still columns, traverse from bottom to top along the left boundary.

This process continues until all elements have been traversed in a spiral order. The function returns the resulting list of elements in spiral order.
