```python
def dijkstra_shortest_path(graph, start):
    import heapq

    # Initialize distances with infinity for all nodes except the start node which is 0.
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    
    # Priority queue to store (distance, node) pairs, starting with the start node.
    priority_queue = [(0, start)]
    
    while priority_queue:
        # Pop the node with the smallest distance value
        current_distance, current_node = heapq.heappop(priority_queue)
        
        # Skip if we've already found a shorter path to this node
        if current_distance > distances[current_node]:
            continue
        
        # Explore each neighbor of the current node
        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            
            # Only consider this new path if it's better (shorter)
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    
    return distances

# Example usage:
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'D': 2, 'E': 7},
    'C': {'A': 4, 'F': 3},
    'D': {'B': 2},
    'E': {'B': 7, 'F': 5},
    'F': {'C': 3, 'E': 5}
}

start_node = 'A'
print(dijkstra_shortest_path(graph, start_node))
```

This function works as follows:

1. **Initialization**: It initializes a dictionary `distances` to store the shortest distance from the start node to each node in the graph. Initially, all distances are set to infinity except for the start node, which is set to 0.

2. **Priority Queue**: A priority queue is used to always select the next unvisited node with the smallest known distance.

3. **Main Loop**: The main loop continues until the priority queue is empty. For each node, it updates the distances of its neighbors if a shorter path is found.

4. **Handling Disconnected Graphs**: If the graph is disconnected, some nodes will not be reachable from the start node and their distances will remain infinity in the `distances` dictionary.

5. **Return Value**: The function returns the `distances` dictionary containing the shortest distance from the start node to each reachable node.
