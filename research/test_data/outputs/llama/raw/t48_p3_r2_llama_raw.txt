def median_of_two_sorted_arrays(nums1, nums2):
    # Make sure that len(nums1) <= len(nums2)
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    
    # Calculate the total length of both arrays
    x, y = len(nums1), len(nums2)
    
    # Initialize the start and end pointers for binary search
    start = 0
    end = x
    
    while start <= end:
        partitionX = (start + end) // 2
        partitionY = (x + y + 1) // 2 - partitionX
        
        maxLeftX = float('-inf') if partitionX == 0 else nums1[partitionX-1]
        minRightX = float('inf') if partitionX == x else nums1[partitionX]
        
        maxLeftY = float('-inf') if partitionY == 0 else nums2[partitionY-1]
        minRightY = float('inf') if partitionY == y else nums2[partitionY]
        
        # Check the conditions for the correct partition
        if maxLeftX <= minRightY and maxLeftY <= minRightX:
            # If the total length is odd, return the max of maxLeftX and maxLeftY
            if (x + y) % 2 == 1:
                return max(maxLeftX, maxLeftY)
            
            # If the total length is even, return the average of maxLeftX, minRightX and maxLeftY, minRightY
            else:
                return (max(maxLeftX, maxLeftY) + min(minRightX, minRightY)) / 2
        
        elif maxLeftX > minRightY:
            end = partitionX - 1
        
        else:
            start = partitionX + 1

# Example usage:
nums1 = [1, 3]
nums2 = [2]

In this code:

*   We ensure that `len(nums1)` is less than or equal to `len(nums2)`, and adjust the pointers accordingly.
*   We use binary search to find the correct partition in both arrays.
*   At each step, we calculate the max of the left elements and the min of the right elements in both partitions.
*   If the conditions are met for the current partition, we return the median based on whether the total length is odd or even.
