Here's a Python function called `binary_search_rotated` that performs binary search on a rotated sorted list:

```python
def binary_search_rotated(values, target):
    low = 0
    high = len(values) - 1

    while low <= high:
        mid = (low + high) // 2
        if values[mid] == target:
            return mid

        # Check for rotated list cases:
        if values[low] <= values[mid]:  # Normal sorted subarray on the left of 'mid'
            if target < values[low] or target > values[mid]:
                low += 1
        else:  # Rotated subarray on the left of 'mid'
            if target >= values[high] and target < values[mid]:
                high -= 1
            elif target < values[low]:
                high = mid - 1
        # If the target is not found within the range, return -1
        if low > high:
            return -1

    return -1
```

This function works by performing a binary search on the list, but also accounting for rotated sorted lists where part of the array may be out of order. If the target is not found within the given range, it returns `-1`.
