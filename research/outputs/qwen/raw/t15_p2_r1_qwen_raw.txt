Certainly! To perform a topological sort on a directed acyclic graph (DAG), we can use Kahn's algorithm, which involves the following steps:

1. Identify all nodes with no incoming edges (i.e., nodes with an in-degree of zero).
2. Add these nodes to a queue.
3. Process each node by:
   - Removing it from the graph.
   - Decreasing the in-degree of its neighbors.
   - Adding any neighbor with an in-degree of zero to the queue.
4. If at any point we do not have enough nodes to process (i.e., the queue is empty but there are still unvisited nodes), this indicates a cycle, and we should raise a `ValueError`.

Here's how you can implement the function:

```python
def topological_sort(graph):
    # Step 1: Calculate in-degrees for all nodes
    in_degrees = {node: 0 for node in graph}
    
    # Initialize in-degrees
    for node, neighbors in graph.items():
        for neighbor in neighbors:
            in_degrees[neighbor] += 1
    
    # Step 2: Identify all nodes with zero in-degree and add them to the queue
    from collections import deque
    queue = deque([node for node, degree in in_degrees.items() if degree == 0])
    
    # Step 3: Process the queue until it's empty
    topological_order = []
    while queue:
        node = queue.popleft()
        topological_order.append(node)
        
        for neighbor in graph[node]:
            in_degrees[neighbor] -= 1
            
            if in_degrees[neighbor] == 0:
                queue.append(neighbor)
                
        # Step 4: Check for cycles
        # If we have processed all nodes but the queue is still not empty, it means there are unprocessed nodes with non-zero in-degrees
        if len(topological_order) < len(in_degrees):
            raise ValueError("Graph contains a cycle")
    
    return topological_order

# Example usage:
graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D', 'E'],
    'D': [],
    'E': []
}

try:
    result = topological_sort(graph)
    print(result)  # Expected output: ['A', 'B', 'C', 'E', 'D']
except ValueError as e:
    print(e)
```

### Explanation:

1. **In-Degree Calculation**: We first calculate the in-degree for each node, which counts how many edges are pointing to that node.
2. **Queue Initialization**: Nodes with zero in-degrees (i.e., no incoming edges) are added to a queue.
3. **Processing Queue**: We process nodes from the queue, adding their neighbors' in-degrees and removing them when their in-degree becomes zero.
4. **Cycle Detection**: If at any point we have processed all nodes but there are still unprocessed nodes (nodes with non-zero in-degrees), a cycle exists.

This approach ensures that all nodes are included in the result, and it correctly handles cycles by raising an appropriate error.
