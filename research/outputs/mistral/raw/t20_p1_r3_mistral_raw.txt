Here's a Python function that merges `k` sorted lists into one sorted list using a priority queue (heapq). This solution has a time complexity of O(n log k), where n is the total number of elements in all the lists.

```python
import heapq

def merge_k_sorted_lists(lists):
    if not lists:
        return []

    min_heap = []
    heapq.heapify(min_heap)

    for list_ in lists:
        if list_:
            heapq.heappush(min_heap, (list_[0], 0, list_))

    result = []
    while min_heap:
        _, index, current_list = heapq.heappop(min_heap)
        result.append(current_list[index])
        index += 1
        if index < len(current_list):
            heapq.heappush(min_heap, (current_list[index], index, current_list))

    return result
```

You can use the function like this:

```python
lists = [
    [1, 3, 5],
    [2, 4, 6, 8],
    [0]
]
merged_list = merge_k_sorted_lists(lists)
print(merged_list) # Output: [0, 1, 2, 3, 4, 5, 6, 8]
```
