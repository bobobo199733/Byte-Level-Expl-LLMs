Here's the Python function for trapping rainwater:

```python
def trapping_rain_water(heights):
    if not heights:
        return 0

    left, right = [0]*len(heights), [0]*len(heights)

    left[1] = max(0, heights[0])
    right[-1] = max(0, heights[-1])

    for i in range(1, len(heights)):
        left[i] = max(left[i-1], heights[i])

    for j in range(len(heights)-2, -1, -1):
        right[j] = max(right[j+1], heights[j])

    total = sum([min(left[i], right[i]) - heights[i] for i in range(len(heights))])
    return total
```

This function computes the amount of water trapped by buildings as rainfall occurs. It initializes two arrays, `left` and `right`, to store the maximum height on the left and right sides of each index, respectively. Then it calculates the heights on both sides and finally computes the total amount of trapped water by iterating through the list and subtracting the current height from the minimum between the heights on the left and right sides at that index. If the input list is empty, it returns 0.
