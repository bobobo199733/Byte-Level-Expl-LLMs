Here's a Python function called `edit_distance` that computes the Levenshtein distance between two strings using dynamic programming:

```python
def edit_distance(word1, word2):
    if not word1 and not word2:
        return 0

    matrix = []
    len1 = len(word1) + 1
    len2 = len(word2) + 1

    for i in range(len1):
        matrix.append([i] + [None] * len2)

    for j in range(len2):
        row = [None] * (len1 + 1)
        row[0] = j
        matrix[-1] = row

    for i in range(1, len1 + 1):
        for j in range(1, len2 + 1):
            if word1[i - 1] == word2[j - 1]:
                cost = 0
            else:
                cost = 1

            matrix[i][j] = min(matrix[i-1][j]+1,
                              matrix[i][j-1]+1,
                              matrix[i-1][j-1] + cost)

    return matrix[-1][-1]
```

The function creates a 2D matrix to store the distance between substrings of `word1` and `word2`. It then iterates through each character in both strings and fills up the matrix by considering the minimum operation needed (insertion, deletion, or substitution) at each step.

Finally, it returns the value stored in the bottom-right cell of the matrix, which represents the Levenshtein distance between `word1` and `word2`.

This implementation should be efficient for longer strings as it has a time complexity of O(m * n), where m and n are the lengths of the input strings.
