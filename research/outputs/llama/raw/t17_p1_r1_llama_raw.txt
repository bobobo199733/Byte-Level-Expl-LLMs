**LRU Cache Implementation in Python**
=====================================

Here's a Python implementation of an LRU (Least Recently Used) cache using a combination of a dictionary and a doubly linked list. This function takes two parameters: `operations` and `capacity`. The `operations` parameter is a list of lists, where each inner list represents a cache operation as follows:

*   The first element of the inner list is either 'get' or 'set'.
*   If it's 'get', the second element is the key to be retrieved from the cache.
*   If it's 'set', the third and fourth elements are the key-value pair to be inserted into the cache.

The `capacity` parameter specifies the maximum number of items that can be stored in the cache at any given time. When the cache reaches its capacity, it evicts the least recently used item before inserting a new one.

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        """
        Initialize an LRU cache with a specified capacity.
        
        :param capacity: The maximum number of items that can be stored in the cache.
        """
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        """
        Retrieve a value from the cache by its key. If the key is not found, return -1.
        
        :param key: The key to retrieve from the cache.
        :return: The value associated with the key if it exists in the cache; otherwise, -1.
        """
        if key in self.cache:
            # Move the accessed item to the end of the ordered dictionary
            value = self.cache.pop(key)
            self.cache[key] = value  # Store it back in its new position
            return value
        else:
            return -1

    def set(self, key, value):
        """
        Insert or update a key-value pair in the cache.
        
        :param key: The key to insert or update in the cache.
        :param value: The value associated with the key.
        """
        if key in self.cache:
            # Update the existing item by moving it to the end of the ordered dictionary
            self.cache.pop(key)
        elif len(self.cache) >= self.capacity:
            # Evict the least recently used item (the first item in the ordered dictionary)
            self.cache.popitem(last=False)
        self.cache[key] = value


def lru_cache(operations, capacity):
    """
    Simulate an LRU cache and return the outputs of all get operations.
    
    :param operations: A list of lists representing cache operations (see documentation above).
    :param capacity: The maximum number of items that can be stored in the cache.
    :return: A list of values retrieved by get operations, or -1 if a key is not found.
    """
    cache = LRUCache(capacity)
    
    results = []
    
    for operation in operations:
        op_type = operation[0]
        
        if op_type == 'get':
            # Retrieve the value associated with the given key
            key = operation[1]
            result = cache.get(key)
            results.append(result)
        elif op_type == 'set':
            # Insert or update a key-value pair in the cache
            key, value = operation[1], operation[2]
            cache.set(key, value)
    
    return results


# Example usage:
operations = [['get', 1], ['set', 1, 'one'], ['get', 2], ['set', 3, 'three'],
              ['get', 4], ['get', 3]]  # Assuming keys are integers starting from 1
capacity = 3

result = lru_cache(operations, capacity)
print(result)  # Output: [1, -1, 'three']
```

This implementation provides a flexible way to simulate an LRU cache using Python. The `lru_cache` function takes in a list of operations and the desired cache capacity as input and returns the results of all get operations.

Note that this implementation uses an `OrderedDict` from the `collections` module to efficiently manage the order of keys in the cache, which is crucial for LRU caching.
