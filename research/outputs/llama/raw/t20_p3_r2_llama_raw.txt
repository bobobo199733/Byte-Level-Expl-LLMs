**Merge K Sorted Lists Function**
=====================================

The following is an implementation of the `merge_k_sorted_lists` function in Python, which takes a list of sorted lists as input and returns a single sorted list.

```python
import heapq

def merge_k_sorted_lists(lists):
    """
    Combines multiple sorted lists into one sorted list.

    Args:
        lists (list): A list of sorted lists.

    Returns:
        list: A single sorted list containing all elements from the input lists.
    """
    # Use a heap to store the smallest element from each list
    min_heap = []
    
    # Initialize the heap with the first element from each list, along with its index and list it came from
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(min_heap, (lst[0], i, 0))  # (value, list_index, element_index)

    # Initialize the result list
    merged_list = []

    # While there are still elements in the heap
    while min_heap:
        # Get the smallest element from the heap
        value, list_index, element_index = heapq.heappop(min_heap)
        
        # Add it to the result list
        merged_list.append(value)

        # If there are more elements in this list, add the next one to the heap
        if element_index + 1 < len(lists[list_index]):
            heapq.heappush(min_heap, (lists[list_index][element_index + 1], list_index, element_index + 1))

    return merged_list
```

**Example Use Case**
--------------------

```python
list1 = [1, 3, 5]
list2 = [2, 4, 6]
list3 = [0, 7, 8]

merged_list = merge_k_sorted_lists([list1, list2, list3])
print(merged_list)  # Output: [0, 1, 2, 3, 4, 5, 6, 7, 8]
```

This function uses a heap to efficiently find the smallest element from each of the input lists. It maintains a balance between adding new elements to the result list and updating the heap with the next smallest element from each list.

Note: This implementation assumes that the input lists are sorted in ascending order. If they are sorted in descending order, you can modify the comparison operator accordingly.
