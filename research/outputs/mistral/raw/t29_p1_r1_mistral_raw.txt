Here's the Python function definition for `parse_csv_line`:

```python
import csv

def parse_csv_line(line):
    reader = csv.reader(line.split(","))
    return list(next(reader))
```

This function uses the built-in `csv` module to parse a CSV line. The `split(",")` method is used first to separate the line into individual parts based on commas, and then these parts are read by the `csv.reader`. Finally, the resulting list of fields is returned.
