```python
def max_subarray_sum(nums):
    if not nums:
        raise ValueError("Input list cannot be empty.")

    max_so_far = nums[0]
    current_max = nums[0]

    for num in nums[1:]:
        current_max = max(num, current_max + num)
        max_so_far = max(max_so_far, current_max)

    return max_so_far
```

This function uses the Kadane's algorithm to find the maximum sum of a contiguous subarray. It starts by initializing `max_so_far` and `current_max` with the first element of the input list, then iterates through the remaining elements, updating `current_max` as the maximum between the current number and the previous sum plus the current number (to allow for both positive and negative numbers). The `max_so_far` is updated whenever a larger sum is found. If the input list is empty, it raises a ValueError.
