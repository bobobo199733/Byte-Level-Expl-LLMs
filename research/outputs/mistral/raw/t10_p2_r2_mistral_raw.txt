```python
def longest_palindrome(s):
    if not s:
        return ''

    max_length = 1
    start = 0
    for i in range(len(s)):
        # Checking for single characters
        odd_half = s[i:i+max_length+1]
        if len(odd_half) > max_length and all(ch == odd_half[0] for ch in odd_half[1:]):
            start = i
            max_length += 2

        # Checking for substrings of length greater than one
        for j in range(i-max_length, i):
            even_half = s[j:i+1][::-1] + s[i:i+max_length+1]
            if len(even_half) > max_length and all(ch == ch2 for ch, ch2 in zip(even_half, even_half[1:])):
                start = j
                max_length += 2

    return s[start:start+max_length]
```

This function checks every substring of the input string `s`, both odd and even length ones, to find the longest palindrome. It uses two variables, `max_length` and `start`, to keep track of the longest found palindrome and its starting index in the original string.
