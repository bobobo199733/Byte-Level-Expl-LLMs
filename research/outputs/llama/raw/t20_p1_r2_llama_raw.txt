**Merging Multiple Sorted Lists**
=====================================

Here's a Python function to merge multiple sorted lists into one sorted list:

```python
import heapq

def merge_k_sorted_lists(lists):
    """
    Merge multiple sorted lists into one sorted list.

    Args:
        lists (list): A list of sorted lists.

    Returns:
        list: A single sorted list containing all elements from the input lists.
    """
    # Use a heap to store the current smallest element from each list
    min_heap = []
    
    # Add the first element from each list to the heap, along with its index and list number
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(min_heap, (lst[0], i, 0))

    # Initialize the result list
    merged_list = []

    while min_heap:
        # Extract the smallest element from the heap
        val, list_idx, elem_idx = heapq.heappop(min_heap)
        
        # Add it to the result list
        merged_list.append(val)

        # If there are more elements in this list, add the next one to the heap
        if elem_idx + 1 < len(lists[list_idx]):
            next_val = lists[list_idx][elem_idx + 1]
            heapq.heappush(min_heap, (next_val, list_idx, elem_idx + 1))

    return merged_list
```

**Example Use Cases**
-----------------------

```python
# Example 1: Merging two sorted lists
list1 = [1, 3, 5]
list2 = [2, 4, 6]

merged = merge_k_sorted_lists([list1, list2])
print(merged)  # Output: [1, 2, 3, 4, 5, 6]

# Example 2: Merging three sorted lists
list1 = [1, 3, 5]
list2 = [2, 4, 6]
list3 = [0, 7, 8]

merged = merge_k_sorted_lists([list1, list2, list3])
print(merged)  # Output: [0, 1, 2, 3, 4, 5, 6, 7, 8]
```

This function uses a heap to efficiently select the smallest element from each list at each step. It has a time complexity of O(N log k), where N is the total number of elements and k is the number of lists being merged.
