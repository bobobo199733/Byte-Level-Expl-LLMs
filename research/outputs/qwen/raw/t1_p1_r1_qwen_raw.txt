To create a Python function that converts Roman numerals to integers and handles invalid cases appropriately, we can follow these steps:

1. Define the mapping of Roman numeral symbols to their integer values.
2. Iterate through the string while keeping track of whether a subtraction case is being processed.
3. Validate the input to ensure it's not empty or contains invalid sequences.

Here is how you could implement this function:

```python
def roman_to_int(s):
    # Define the valid Roman numeral mapping and their corresponding values
    roman_values = {
        'I': 1, 'V': 5, 'X': 10, 'L': 50,
        'C': 100, 'D': 500, 'M': 1000
    }
    
    # Check if the input is empty or invalid
    if not s:
        raise ValueError("Input cannot be an empty string.")
    
    # Initialize the previous value to a small number that won't affect subtraction rules
    prev_value = -1
    
    total = 0
    
    for char in s:
        # Check if the character is valid
        if char not in roman_values:
            raise ValueError(f"Invalid Roman numeral: {char}")
        
        current_value = roman_values[char]
        
        # If the current value is greater than the previous one, it's a subtraction case
        if prev_value < current_value:
            total += current_value - 2 * prev_value  # Subtract twice to correct for addition before
        else:
            total += current_value
        
        prev_value = current_value
    
    return total

# Examples of usage and expected outputs
print(roman_to_int("III"))          # Output: 3
print(roman_to_int("IV"))           # Output: 4
print(roman_to_int("IX"))           # Output: 9
print(roman_to_int("LVIII"))        # Output: 58
print(roman_to_int("MCMXCIV"))      # Output: 1994

# Examples of invalid Roman numerals that should raise ValueError
try:
    print(roman_to_int("IC"))
except ValueError as e:
    print(e)  # Output: Invalid Roman numeral: I
    
try:
    print(roman_to_int("XM"))
except ValueError as e:
    print(e)  # Output: Invalid Roman numeral: X

try:
    print(roman_to_int("VX"))
except ValueError as e:
    print(e)  # Output: Invalid Roman numeral: V

try:
    print(roman_to_int("IIII"))
except ValueError as e:
    print(e)  # Output: Invalid Roman numeral: I
```

This function ensures that it handles both standard and invalid cases, including those with incorrect subtraction sequences. It also checks for an empty string input before processing the Roman numeral conversion.
