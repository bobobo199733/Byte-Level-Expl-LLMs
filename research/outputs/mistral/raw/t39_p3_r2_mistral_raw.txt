Here's a Python implementation of the 0/1 Knapsack problem using dynamic programming approach:

```python
def knapsack_01(weights, values, capacity):
    n = len(weights)

    # Create a table to store the maximum value for each subset of items (including empty set)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    # Base case: if no items, then only an empty knapsack has a value of 0
    for i in range(n + 1):
        dp[i][0] = 0

    # Fill the table using bottom-up approach
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            if weights[i - 1] <= w:
                dp[i][w] = max(values[i - 1] + dp[i - 1][w - weights[i - 1]], dp[i - 1][w])
            else:
                dp[i][w] = dp[i - 1][w]

    # The maximum value in the last row of the table is the answer
    return dp[n][capacity]
```

This function takes three arguments: `weights`, `values`, and `capacity`. `weights` and `values` are lists representing the weights and values of items, respectively. `capacity` represents the maximum weight the knapsack can hold. The function returns the best possible value that can be obtained by including or excluding items in the knapsack while not exceeding its capacity.
