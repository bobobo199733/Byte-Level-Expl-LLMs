**Merging Multiple Sorted Lists in Python**
====================================================

Here is a high-quality, readable, and well-documented Python function to merge multiple sorted lists:

```python
import heapq

def merge_k_sorted_lists(lists):
    """
    Merge multiple sorted lists into one sorted list.

    Args:
        lists (list of lists): A list containing multiple sorted lists.

    Returns:
        list: A single sorted list containing all elements from the input lists.
    """
    # Use a heap to efficiently merge the lists
    merged_list = []
    min_heap = []

    # Iterate over each list and its index
    for i, lst in enumerate(lists):
        # Push the first element of each list into the heap along with its index
        if lst:
            heapq.heappush(min_heap, (lst[0], i, 0))

    # Merge lists from the heap
    while min_heap:
        # Get the smallest element from the heap
        val, list_index, elem_index = heapq.heappop(min_heap)
        
        # Add it to the merged list
        merged_list.append(val)

        # If there are more elements in the current list, push them into the heap
        if elem_index + 1 < len(lists[list_index]):
            next_val = lists[list_index][elem_index + 1]
            heapq.heappush(min_heap, (next_val, list_index, elem_index + 1))

    return merged_list
```

**Example Use Case**
--------------------

```python
# Create multiple sorted lists
list1 = [1, 3, 5]
list2 = [2, 4, 6]
list3 = [0, 7, 8]

lists = [list1, list2, list3]

merged_list = merge_k_sorted_lists(lists)
print(merged_list)  # Output: [0, 1, 2, 3, 4, 5, 6, 7, 8]
```

This function uses a heap to efficiently merge the sorted lists. It has a time complexity of O(N log k), where N is the total number of elements and k is the number of input lists.
