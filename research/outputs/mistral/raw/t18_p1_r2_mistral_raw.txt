The Edit Distance problem is a classic algorithmic problem where you find the number of minimum operations (insertions, deletions, or substitutions) required to transform one string into another. Here's a Python function implementing the dynamic programming solution:

```python
def edit_distance(word1, word2):
    if not word1 or not word2:
        return len(word1) + len(word2)

    dp = [[0] * (len(word2) + 1) for _ in range(len(word1) + 1)]

    for i in range(len(word1) + 1):
        dp[i][0] = i

    for j in range(len(word2) + 1):
        dp[0][j] = j

    for i in range(1, len(word1) + 1):
        for j in range(1, len(word2) + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1

    return dp[-1][-1]
```

You can use this function to calculate the edit distance between two strings:

```python
word1 = "kitten"
word2 = "sitting"
print(edit_distance(word1, word2))  # Output: 3 (one substitution, one deletion and one insertion)
```
