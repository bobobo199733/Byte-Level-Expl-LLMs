```python
def search_insert_position(nums, target):
    """
    Returns the index of the target in a sorted array. 
    If the target does not exist, returns the index where it should be inserted.

    Args:
        nums (list): A sorted list of integers.
        target (int): The number to be searched for.

    Returns:
        int: The index of the target or its insertion position.
    """

    # Start at both ends of the array and move towards each other
    left, right = 0, len(nums) - 1

    # Continue searching until the two pointers meet
    while left <= right:
        mid = (left + right) // 2

        if nums[mid] == target:
            return mid  # If found, return its index
        elif nums[mid] < target:
            left = mid + 1  # Move right pointer to search in the right half
        else:
            right = mid - 1  # Move left pointer to search in the left half

    return left  # If not found, return where it should be inserted
```

```python
nums = [1,3,5,6]
print(search_insert_position(nums, 5))  # Output: 2
print(search_insert_position(nums, 2))  # Output: 1
print(search_insert_position(nums, 7))  # Output: 4
```

This function uses a binary search algorithm to find the target in the sorted array. It starts by considering two pointers at both ends of the array and moves them towards each other until they meet or cross over. This way, it ensures that if the target is not found in the array, the returned index will be where the target should be inserted to maintain the array's sorted order.
