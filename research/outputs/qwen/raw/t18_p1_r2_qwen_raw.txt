Certainly! The Levenshtein distance (also known as edit distance) is a measure of the similarity between two strings, which can be defined as the minimum number of single-character edits required to change one string into the other. These edits can include insertions, deletions, or substitutions.

Here's a Python function that calculates the edit distance using dynamic programming:

```python
def edit_distance(word1, word2):
    m = len(word1)
    n = len(word2)

    # Create a 2D array to store the distances between substrings of word1 and word2
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Initialize the first row and column of the matrix
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Fill up the rest of the table
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                cost = 0
            else:
                cost = 1

            dp[i][j] = min(
                dp[i - 1][j] + 1,     # Deletion
                dp[i][j - 1] + 1,     # Insertion
                dp[i - 1][j - 1] + cost  # Substitution
            )

    return dp[m][n]

# Example usage:
word1 = "kitten"
word2 = "sitting"
print(edit_distance(word1, word2))  # Output: 3
```

### Explanation:
- **Matrix Initialization**: We initialize a matrix `dp` where `dp[i][j]` represents the edit distance between the first `i` characters of `word1` and the first `j` characters of `word2`.
- **Base Cases**: The base cases are set to handle the scenarios where one or both strings are empty.
- **Filling the Matrix**: For each cell in the matrix, we calculate the minimum cost based on three possible operations: insertion, deletion, and substitution.

This function will correctly compute the edit distance between two given words.
