```python
def search_insert_position(nums, target):
    """
    Searches for the target in a sorted array and returns its index. 
    If the target does not exist, it returns the index where it should be inserted.

    Args:
        nums (list): A sorted list of numbers.
        target (int): The number to be searched.

    Returns:
        int: The index of the target in the array or the index where it should be inserted.

    Example:
        >>> search_insert_position([1, 3, 5, 6], 5)
        2
        >>> search_insert_position([1, 3, 5, 6], 2)
        1
        >>> search_insert_position([1, 3, 5, 6], 7)
        4
    """
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return left

# Example use case
numbers = [1, 3, 5, 6]
target_number = 7
index = search_insert_position(numbers, target_number)
print(f"The {target_number} should be inserted at index: {index}")
```

This function uses a binary search approach to find the target in the array. If the `nums[mid]` is equal to `target`, it returns `mid`. If `nums[mid]` is less than `target`, it moves the left pointer to `mid + 1`. If `nums[mid]` is greater than `target`, it moves the right pointer to `mid - 1`.

When the binary search is over, and the target does not exist in the array, the function returns the left index where the target should be inserted.
