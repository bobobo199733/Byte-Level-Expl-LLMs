Certainly! The Levenshtein distance is a measure of the difference between two sequences. It can be computed using dynamic programming to efficiently handle insertions, deletions, and substitutions. Below is a Python function that implements this:

```python
def edit_distance(word1: str, word2: str) -> int:
    # Ensure word1 is always the shorter string for efficiency
    if len(word1) > len(word2):
        word1, word2 = word2, word1

    m, n = len(word1), len(word2)
    
    # Initialize the distance matrix
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Initialize the base cases
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Fill in the distance matrix
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                cost = 0
            else:
                cost = 1

            # Minimum of three possible operations: insertion, deletion, substitution
            dp[i][j] = min(dp[i - 1][j] + 1,          # Deletion
                           dp[i][j - 1] + 1,          # Insertion
                           dp[i - 1][j - 1] + cost)   # Substitution

    return dp[m][n]

# Example usage:
word1 = "kitten"
word2 = "sitting"
print(edit_distance(word1, word2))  # Output: 3
```

### Explanation:

- **Initialization**: We initialize a 2D list `dp` where `dp[i][j]` will hold the Levenshtein distance between the first `i` characters of `word1` and the first `j` characters of `word2`.
  
- **Base Cases**: For an empty string, the distance to match it with any other string is simply the length of that string. Hence, we initialize the first row and column of the matrix accordingly.

- **Filling the Matrix**: We iterate through each character in both strings. If characters at `word1[i - 1]` and `word2[j - 1]` are the same, no operation is needed; otherwise, a substitution cost is considered. The minimum of three possible operations (deletion, insertion, substitution) is chosen for updating `dp[i][j]`.

- **Result**: The final value in `dp[m][n]` gives us the Levenshtein distance between `word1` and `word2`.

This implementation efficiently handles longer strings by leveraging dynamic programming to avoid redundant calculations.
