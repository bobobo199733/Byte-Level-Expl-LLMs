Here's a Python implementation of the `merge_k_sorted_lists` function using a heapq data structure:

```python
import heapq

def merge_k_sorted_lists(lists):
    merged = []
    min_heap = []

    for list_ in lists:
        if len(list_) > 0:
            heapq.heappush(min_heap, (list_[0], 0, list_))

    while min_heap:
        _, index, current_list = heapq.heappop(min_heap)
        value = current_list[index]
        merged.append(value)
        index += 1
        if len(current_list) > index < len(current_list):
            heapq.heappush(min_heap, (current_list[index], index, current_list))

    return merged
```

The function takes a list of sorted lists as an argument and returns a single sorted list containing the elements from the input lists. It uses a min-heap to efficiently manage the minimum element across all the input lists and appends them one by one to the `merged` list. The min-heap is initialized with the smallest elements (the first element of each list) and their respective list indices, and then it's continuously popping the minimum element and updating its index when there are more elements in the same list.

Here's an example usage:

```python
lists = [
    [1, 3, 5],
    [2, 4, 6, 8],
    [0]
]
print(merge_k_sorted_lists(lists))  # Output: [0, 1, 2, 3, 4, 5, 6, 8]
```
