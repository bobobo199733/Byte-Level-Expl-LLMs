```python
def merge_intervals(intervals):
    if not intervals:
        return []

    # Sort the intervals based on their start times
    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]

    for interval in intervals:
        last_merged = merged[-1]

        # If the current interval doesn't overlap with the last merged interval, append it
        if last_merged[1] < interval[0]:
            merged.append(interval)
        else:
            last_merged[1] = max(last_merged[1], interval[1])

    return merged
```

This function assumes that the intervals are given as a list of nested tuples, where each tuple represents an interval with its start and end times (e.g., `[(1, 3), (6, 9)]`).
