To create a function `is_balanced` that checks if the input string `s` contains balanced and correctly nested brackets, we can use a stack to keep track of opening brackets as we encounter them. When we see a closing bracket, we check it against the top of the stack to ensure they match.

Here's how you can implement this:

```python
def is_balanced(s: str) -> bool:
    # Mapping of opening and closing brackets
    bracket_map = {')': '(', ']': '[', '}': '{'}
    open_brackets = set(bracket_map.values())
    
    stack = []
    
    for char in s:
        if char in open_brackets:
            stack.append(char)
        elif char in bracket_map:
            if not stack or stack.pop() != bracket_map[char]:
                return False
        # Ignore all other characters
    
    return len(stack) == 0

# Test cases to verify the function works as expected
test_cases = [

    ("", True),  # An empty string is considered balanced
```

### Explanation:

1. **Mapping of Brackets**: We use a dictionary `bracket_map` to map each closing bracket to its corresponding opening bracket.
2. **Stack for Tracking**: A stack is used to keep track of the opening brackets as we iterate through the string.
3. **Processing Each Character**:
   - If the character is an opening bracket, it's pushed onto the stack.
   - If the character is a closing bracket, we check if the stack is empty or if the top of the stack doesn't match the corresponding opening bracket. If either condition is true, the string is not balanced.
4. **Return Condition**: After processing all characters, the string is balanced only if the stack is empty.
