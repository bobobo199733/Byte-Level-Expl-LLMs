def binary_search_rotated(values, target):
    if not values:
        return -1

    left, right = 0, len(values) - 1

    while left <= right:
        mid = (left + right) // 2

        # Check for the case when the rotated array is sorted in ascending order and we've found the target
        if values[mid] == target:
            return mid

        # Determine which half of the array the target should be in, based on the current middle element being greater or less than its predecessor
        if (mid > 0 and values[mid] < values[mid - 1]) or (mid == 0):
            right = mid - 1
        else:
            left = mid + 1

    # If the target is not found after searching both halves, return -1
    return -1

Depending on the case, it updates either the left or right pointer to continue searching the appropriate half of the array.

When both pointers converge on a value that is not the target, the function returns -1 indicating that the target was not found in the array.
