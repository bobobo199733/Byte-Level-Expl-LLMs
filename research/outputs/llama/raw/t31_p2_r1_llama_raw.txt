```python
def serialize_tree(root):
    """
    Serialize a binary tree into a string representation.
    
    This function performs a pre-order traversal of the binary tree, 
    where each node's value is appended to the result string along with its children (null or empty if not present).
    
    The resulting string can be used to reconstruct the original tree using deserialize_tree().

    Args:
        root: The root of the binary tree.

    Returns:
        A string representation of the binary tree.
    """

    def helper(node):
        """
        Helper function for serialization.
        
        This recursive function appends each node's value and its children (null or empty if not present) 
        to the result string in a pre-order manner.
        """
        if node is None:
            # If null, append 'X' to indicate no child
            helper_str += 'X'
        else:
            # Pre-order: root -> left -> right
            helper_str += str(node.val)
            
            # Append 'null' for null children and ',#' for empty children
            if node.left is not None:
                helper_str += ',' + str(node.left.val)
            else:
                helper_str += ',#'
            
            if node.right is not None:
                helper_str += ',' + str(node.right.val)
            else:
                helper_str += '#'
        
        # Use comma as delimiter between children, but no comma at the end
        return helper_str

    result = ''
    if root:
        result = helper(root)
    
    # Remove trailing comma after serialization
    if len(result) > 0 and result[-1] == ',':
        result = result[:-1]
    
    return result
```

Example usage:

```python
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None

# Create a sample binary tree:       1
#                                  / \
#                                 2   3
#                                /
#                               4

root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.left = TreeNode(4)

serialized_tree = serialize_tree(root)
print(serialized_tree) # Output: "1,2,#,#,#,4"
```

This code provides a robust and readable solution for serializing binary trees in Python. It utilizes a pre-order traversal strategy to ensure correct preservation of all node values and tree structure. The output string can be used to reconstruct the original tree using a corresponding deserialization function (not shown here).
