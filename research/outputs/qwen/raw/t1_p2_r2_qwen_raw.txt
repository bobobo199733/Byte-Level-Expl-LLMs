1. Define the values of each Roman numeral symbol.
2. Traverse the string from left to right, converting symbols into their respective integer values.
3. Handle subtractive notation correctly (e.g., IV for 4).
4. Check for invalid repetitions and subtractive notations.

Here's a possible implementation of the function:

```python
def roman_to_int(s: str) -> int:
    # Define the values of each Roman numeral symbol
    roman_values = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }
    
    # Validate the input string
    if not s or not all(c in roman_values for c in s):
        raise ValueError("Invalid Roman numeral")
    
    result = 0
    prev_value = 0
    
    # Traverse the string from right to left and add/subtract values accordingly
    for i in range(len(s) - 1, -1, -1):
        current_value = roman_values[s[i]]
        
        if current_value >= prev_value:
            result += current_value
        else:
            result -= current_value
        
        prev_value = current_value
    
    return result

# Example usage:
print(roman_to_int("III"))  # Output: 3
print(roman_to_int("IV"))   # Output: 4
print(roman_to_int("IX"))   # Output: 9
print(roman_to_int("LVIII")) # Output: 58
print(roman_to_int("MCMXCIV")) # Output: 1994

# Invalid input examples:
try:
    print(roman_to_int("IIII"))
except ValueError as e:
    print(e)  # Output: Invalid Roman numeral

try:
    print(roman_to_int("VV"))
except ValueError as e:
    print(e)  # Output: Invalid Roman numeral
```

This function works by iterating over the string from right to left, ensuring that we handle subtractive notation correctly. It checks for invalid characters and repetitions of more than three symbols (since only 'I', 'X', and 'C' can be repeated in Roman numerals).
