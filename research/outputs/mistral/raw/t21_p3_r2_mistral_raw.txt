Here's a Python function for matrix multiplication:

```python
def matrix_multiply(A, B):
    if len(A[0]) != len(B):
        return None  # Matrices cannot be multiplied if the number of columns in A is not equal to the number of rows in B.

    result = [[0 for _ in range(len(B[0]))] for _ in range(len(A))]

    for i in range(len(A)):
        for j in range(len(B[0])):
            for k in range(len(B)):
                result[i][j] += A[i][k] * B[k][j]

    return result
```

This function first checks if the number of columns in matrix A is equal to the number of rows in matrix B, which is a precondition for matrix multiplication. If it's not the case, it returns `None`. Otherwise, it initializes an empty result matrix with the appropriate dimensions and performs the multiplication using nested loops. The function then returns the resulting matrix.
