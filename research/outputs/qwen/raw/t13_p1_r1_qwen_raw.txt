```python
def spiral_matrix(matrix):
    result = []
    
    if not matrix or not matrix[0]:
        return result
    
    rows, cols = len(matrix), len(matrix[0])
    top, bottom, left, right = 0, rows - 1, 0, cols - 1
    
    while top <= bottom and left <= right:
        # Traverse from left to right along the top row
        for i in range(left, right + 1):
            result.append(matrix[top][i])
        top += 1
        
        # Traverse from top to bottom along the right column
        for i in range(top, bottom + 1):
            result.append(matrix[i][right])
        right -= 1
        
        if top <= bottom:
            # Traverse from right to left along the bottom row
            for i in range(right, left - 1, -1):
                result.append(matrix[bottom][i])
            bottom -= 1
        
        if left <= right:
            # Traverse from bottom to top along the left column
            for i in range(bottom, top - 1, -1):
                result.append(matrix[i][left])
            left += 1
    
    return result

# Example usage:
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(spiral_matrix(matrix))  # Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
```

This function works as follows:

1. It initializes an empty list `result` to store the elements in spiral order.
2. It checks if the matrix is empty and returns an empty result if it is.
3. It sets up boundaries for traversal: `top`, `bottom`, `left`, and `right`.
4. It traverses the matrix layer by layer, moving right along the top row, down along the right column, left along the bottom row, and up along the left column until there are no more layers to traverse.
5. Finally, it returns the result list containing all elements in spiral order.
