```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def serialize_tree(root):
    if root is None:
        return "None,"  # Represent the null node
    
    result = str(root.val) + ","  # Start with the current node's value
    
    # Serialize the left subtree
    if root.left is not None:
        result += serialize_tree(root.left)
    else:
        result += "None,"
    
    # Serialize the right subtree
    if root.right is not None:
        result += serialize_tree(root.right)
    else:
        result += "None,"
    
    return result

# Example usage:
# Constructing a simple binary tree:
#       1
#      / \
#     2   3
#        /
#       4

root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3, TreeNode(4))

serialized_tree = serialize_tree(root)
print(serialized_tree)  # Expected output: "1,2,None,3,4,None,None,"
```

### Explanation:
- **TreeNode Class**: This is a helper class used to define the structure of nodes in the binary tree.
- **serialize_tree Function**:
  - If the current node (`root`) is `None`, it returns `"None,"` which represents a null child.
  - Otherwise, it appends the value of the current node followed by commas to separate the values.
  - It then recursively serializes the left and right subtrees. If a subtree is empty (i.e., the child node is `None`), it adds `"None,"` to indicate that absence.

This approach ensures that all nodes are preserved, including null children, which helps in reconstructing the tree accurately from the serialized string.
