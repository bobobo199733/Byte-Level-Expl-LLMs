Here is a Python function called `edit_distance` that computes the Levenshtein distance between two strings using dynamic programming:

```python
def edit_distance(word1, word2):
    if not word1 and not word2:
        return 0

    len1 = len(word1)
    len2 = len(word2)

    # Create matrix of size (len1+1) x (len2+1) to store the Levenshtein distances.
    dp = [[0] * (len2 + 1) for _ in range(len1 + 1)]

    # Initialize first row and column with their respective lengths
    for i in range(len1 + 1):
        dp[i][0] = i
    for j in range(len2 + 1):
        dp[0][j] = j

    # Fill the rest of the matrix using dynamic programming.
    for i in range(1, len1 + 1):
        for j in range(1, len2 + 1):
            if word1[i - 1] == word2[j - 1]:
                cost = 0
            else:
                cost = 1
            dp[i][j] = min(dp[i - 1][j] + 1,     # deletion of char in word1
                           dp[i][j - 1] + 1,     # deletion of char in word2
                           dp[i - 1][j - 1] + cost) # substitution

    return dp[-1][-1]
```

This implementation follows the dynamic programming approach for computing Levenshtein distance. It handles empty strings correctly and is efficient for longer strings. The time complexity of this algorithm is O(m * n), where m and n are the lengths of the two input strings.
