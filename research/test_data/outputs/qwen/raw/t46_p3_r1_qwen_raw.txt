```python
def text_justification(words, max_width):
    def justify_line(line_words, width, last=False):
        if len(line_words) == 1 or last:
            return " ".join(line_words).ljust(width)
        
        num_gaps = len(line_words) - 1
        spaces = (width - sum(len(word) for word in line_words)) // num_gaps
        extra_spaces = (width - sum(len(word) for word in line_words)) % num_gaps
        
        justified_line = ""
        for i, word in enumerate(line_words):
            justified_line += word + " "
            if i < extra_spaces:
                justified_line += " " * (spaces + 1)
            else:
                justified_line += " " * spaces
        
        return justified_line.strip()
    
    result = []
    current_line = []
    current_width = 0
    
    for word in words:
        # Check if adding the next word exceeds max width
        if len(current_line) == 0:
            current_width = len(word)
        else:
            current_width += len(word) + 1
        
        if current_width > max_width:
            result.append(justify_line(current_line, max_width))
            current_line = [word]
            current_width = len(word) + 1
        else:
            current_line.append(word)
    
    # Handle the last line
    result.append(" ".join(current_line).ljust(max_width))
    
    return result

# Example usage:
words = ["This", "is", "an", "example", "of", "text", "justification."]
max_width = 16
print(text_justification(words, max_width))
```

### Explanation:

- **justify_line Function**: This helper function justifies a line of words. It takes the list of words in the current line (`line_words`), the maximum width for the line (`width`), and a boolean `last` indicating if it's the last line.
  - If there's only one word or it's the last line, it simply left-aligns the words to fill up to the max width.
  - Otherwise, it calculates the number of gaps between words, distributes spaces evenly among these gaps (plus any extra spaces), and constructs the justified line.

- **Main Function**:
  - It initializes an empty list `result` to store each line.
  - Loops through the `words`, building lines that fit within `max_width`.
  - When adding a word would exceed the max width, it justifies the current line and starts a new one.
  - After processing all words, it handles the last line which is left-aligned.

- **Example Usage**: The example provided in the comments demonstrates how to use this function with a list of words and `max_width`.

This approach ensures that each line except the last is fully justified, with spaces evenly distributed. The last line is left-aligned with trailing spaces.
