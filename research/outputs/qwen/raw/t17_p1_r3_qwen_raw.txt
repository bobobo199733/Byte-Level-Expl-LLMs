Certainly! The LRUCache can be implemented in Python using the `OrderedDict` from the collections module, which helps maintain the order of elements based on their usage. Below is a Python function called `lru_cache(operations, capacity)` that simulates an LRU cache and returns the outputs of all get operations.

```python
from collections import OrderedDict

def lru_cache(operations, capacity):
    class LRUCache:
        def __init__(self, capacity):
            self.cache = OrderedDict()
            self.capacity = capacity
        
        def get(self, key):
            if key not in self.cache:
                return -1
            else:
                # Move the accessed item to the end to show that it was recently used
                self.cache.move_to_end(key)
                return self.cache[key]
        
        def put(self, key, value):
            if key in self.cache:
                # If the key is already present, move it to the end (recently used) and update its value
                self.cache.move_to_end(key)
            self.cache[key] = value
            if len(self.cache) > self.capacity:
                # Pop the first item (least recently used) from the cache
                self.cache.popitem(last=False)
    
    result = []
    cache = LRUCache(capacity)

    for operation in operations:
        if operation[0] == 'get':
            result.append(cache.get(operation[1]))
        elif operation[0] == 'put':
            cache.put(operation[1], operation[2])

    return result

# Example usage:
operations = [
    ('put', 1, 1),
    ('put', 2, 2),
    ('get', 1),
    ('put', 3, 3),
    ('get', 2),
    ('get', 3)
]
capacity = 2
print(lru_cache(operations, capacity))  # Output: [1, -1, 3]
```

### Explanation:
- **LRUCache Class**:
  - `__init__(self, capacity)`: Initializes the cache with a given capacity.
  - `get(self, key)`: Retrieves the value of the specified key from the cache. If the key is not present, returns `-1`. The accessed item is moved to the end to indicate recent usage.
  - `put(self, key, value)`: Adds or updates an entry in the cache. If the cache exceeds its capacity after adding a new item, the least recently used item (the first one in the OrderedDict) is removed.

- **lru_cache Function**:
  - Takes two arguments: `operations` and `capacity`.
  - Initializes an instance of the `LRUCache` class.
  - Iterates through each operation. For each `get` operation, appends the result to the `result` list.
  - Returns the final results after processing all operations.

### Example Usage:
- The example provided simulates a cache with a capacity of 2 and performs various get and put operations on it. The output `[1, -1, 3]` indicates that:
  - After putting keys 1 and 2, getting key 1 returns `1`.
  - Putting key 3 evicts the least recently used item (key 2) because the cache is full.
  - Getting key 2 returns `-1` since it was removed by the put operation for key 3.
  - Getting key 3 returns `3`.

This function can be extended and modified as needed to handle different scenarios or additional operations.
