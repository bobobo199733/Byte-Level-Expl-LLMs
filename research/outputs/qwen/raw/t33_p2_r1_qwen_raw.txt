```python
def heapify(arr, n, i):
    largest = i  # Initialize largest as root
    left_child = 2 * i + 1     # Left child index
    right_child = 2 * i + 2    # Right child index

    # See if left child of root exists and is greater than root
    if left_child < n and arr[i] < arr[left_child]:
        largest = left_child

    # See if right child of root exists and is greater than the current largest
    if right_child < n and arr[largest] < arr[right_child]:
        largest = right_child

    # Change root, if needed
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]  # Swap

        # Heapify the affected sub-tree
        heapify(arr, n, largest)

def heap_sort(values):
    # Create a copy of the input list to avoid modifying it directly
    arr = values[:]
    
    n = len(arr)
    
    # Build a max-heap
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
        
    # Extract elements one by one from the heap
    for i in range(n - 1, 0, -1):
        arr[i], arr[0] = arr[0], arr[i]  # Swap
        heapify(arr, i, 0)  # Heapify the root element

    return arr
```

### Explanation:
1. **heapify Function**:
   - This function is used to maintain the heap property after a swap or modification.
   - It takes an array `arr`, the size of the heap `n`, and the index `i` from which the heapification starts.

2. **heap_sort Function**:
   - A copy of the input list is created to preserve the original list.
   - The function first builds a max-heap by calling `heapify` for each non-leaf node in reverse order.
   - Then, it repeatedly extracts the maximum element (root) and heapifies the reduced heap.

### Usage:

