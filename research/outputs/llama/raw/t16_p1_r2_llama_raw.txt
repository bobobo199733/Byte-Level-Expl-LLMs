**Sudoku Solver Function**
=========================

The following is a Python function named `sudoku_solver` that solves a Sudoku puzzle in-place. This function uses a backtracking algorithm to fill the board with valid values.

```python
def sudoku_solver(board):
    """
    Solves a Sudoku puzzle in-place using a backtracking algorithm.

    Args:
        board (list): A 2D list representing the Sudoku board, where each cell is a number from 0-9 or an empty string.

    Returns:
        bool: True if the puzzle was successfully solved, False otherwise.
    """

    def is_valid(board, row, col, num):
        """
        Checks whether it's possible to place a number in a given position on the board.

        Args:
            board (list): A 2D list representing the Sudoku board.
            row (int): The current row index.
            col (int): The current column index.
            num (int): The number to be placed in the cell at (row, col).

        Returns:
            bool: True if it's possible to place the number, False otherwise.
        """
        # Check the row
        for x in range(9):
            if board[row][x] == num and x != col:
                return False

        # Check the column
        for x in range(9):
            if board[x][col] == num and x != row:
                return False

        # Check the 3x3 box
        start_row = row - row % 3
        start_col = col - col % 3
        for i in range(3):
            for j in range(3):
                if board[i + start_row][j + start_col] == num and (i + start_row != row or j + start_col != col):
                    return False

        return True

    def solve(board):
        """
        Recursively attempts to fill the Sudoku board with valid numbers.

        Args:
            board (list): A 2D list representing the Sudoku board.
        """
        for i in range(9):
            for j in range(9):
                if board[i][j] == 0:  # If this cell is empty
                    for num in range(1, 10):
                        if is_valid(board, i, j, num):  # Check if the number can be placed here
                            board[i][j] = num  # Place the number
                            if solve(board):  # Recursively attempt to fill the rest of the board
                                return True
                            board[i][j] = 0  # If we couldn't place any other numbers, reset this cell and try a different branch
                    return False  # If no valid number can be placed here, return False
        return True

    solve(board)
```

**Example Usage**
---------------

Here's how you can use the `sudoku_solver` function:

```python
board = [
    [5, 3, 0, 0, 7, 0, 0, 0, 0],
    [6, 0, 0, 1, 9, 5, 0, 0, 0],
    [0, 9, 8, 0, 0, 0, 0, 6, 0],
    [8, 0, 0, 0, 6, 0, 0, 0, 3],
    [4, 0, 0, 8, 0, 3, 0, 0, 1],
    [7, 0, 0, 0, 2, 0, 0, 0, 6],
    [0, 6, 0, 0, 0, 0, 2, 8, 0],
    [0, 0, 0, 4, 1, 9, 0, 0, 5],
    [0, 0, 0, 0, 8, 0, 0, 7, 9]
]

sudoku_solver(board)
print(board)
```

This will print the solved Sudoku board.
