Certainly! To traverse a matrix in a spiral order, we can follow these steps:

1. Check if the matrix is empty and return an empty list if it is.
2. Initialize variables to keep track of the boundaries (top, bottom, left, right) of the current section of the matrix that needs to be traversed.
3. Traverse the matrix in layers by moving right, then down, then left, and finally up, while updating the boundaries as we go.
4. Append each visited element to a result list.

Here's how you can implement this:

```python
def spiral_matrix(matrix):
    if not matrix:
        return []
    
    # Initialize the boundaries of the matrix
    top = 0
    bottom = len(matrix) - 1
    left = 0
    right = len(matrix[0]) - 1
    
    result = []
    
    while top <= bottom and left <= right:
        # Traverse from left to right along the top boundary
        for i in range(left, right + 1):
            result.append(matrix[top][i])
        top += 1
        
        # Traverse from top to bottom along the right boundary
        for i in range(top, bottom + 1):
            result.append(matrix[i][right])
        right -= 1
        
        if top <= bottom:
            # Traverse from right to left along the bottom boundary
            for i in range(right, left - 1, -1):
                result.append(matrix[bottom][i])
            bottom -= 1
        
        if left <= right:
            # Traverse from bottom to top along the left boundary
            for i in range(bottom, top - 1, -1):
                result.append(matrix[i][left])
            left += 1
    
    return result

# Example usage:
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(spiral_matrix(matrix))  # Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
```

This function works as follows:

1. **Boundary Initialization**: We initialize the boundaries of the matrix to traverse.
2. **Traversal**:
   - Traverse from left to right along the top boundary.
   - Move down by updating `top` and continue traversing from top to bottom along the right boundary.
   - If there are still rows to process, move up by updating `bottom` and traverse from right to left along the bottom boundary.
   - Finally, if there are still columns to process, move left by updating `left` and traverse from bottom to top along the left boundary.
3. **Result List**: Each element is appended to a result list which is returned at the end.

This approach ensures that we visit each element exactly once in a spiral order without revisiting any elements.
