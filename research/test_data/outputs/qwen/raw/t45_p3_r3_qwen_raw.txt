def search_insert_position(nums, target):
    """
    Finds the index or insertion position in a sorted array where the target should be placed.
    
    :param nums: List[int] - A list of integers that is already sorted in ascending order.
    :param target: int - The target integer to find the insertion position for.
    :return: int - The index at which the target should be inserted.
    """
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    # At this point, `left` is the correct insertion position.
    return left

# Example usage:
nums = [1, 3, 5, 6]

### Explanation:
- **Binary Search**: The function uses binary search to find the correct position for `target` in the sorted array.
- **Loop Invariants**:
  - `left` and `right` are used to narrow down the range where the target might fit.
  - If `nums[mid] == target`, we return `mid`.
  - If `nums[mid] < target`, we adjust `left = mid + 1` to search in the right half.
  - If `nums[mid] > target`, we adjust `right = mid - 1` to search in the left half.
- **Return Value**: When the loop exits, `left` will be the correct index where the target should be inserted.

This approach ensures that the function runs efficiently with a time complexity of O(log n).
