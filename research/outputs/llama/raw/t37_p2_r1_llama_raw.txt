**Linked List Cycle Detection Function**
======================================

Here is a Python function named `linked_list_cycle` that uses Floyd's Tortoise and Hare algorithm to detect cycles in linked lists efficiently.

```python
class Node:
    """Node class representing a node in the linked list."""
    def __init__(self, value):
        self.value = value
        self.next = None

def linked_list_cycle(head):
    """
    Determines whether a linked list contains a cycle.

    Args:
    head (Node): The head of the linked list.

    Returns:
    bool: True if a cycle exists, False otherwise.
    """

    # Handle empty lists correctly by returning False
    if head is None or head.next is None:
        return False

    tortoise = head  # Move at 1 node interval (slow pace)
    hare = head  # Move at 2 nodes intervals (fast pace)

    while True:  # Infinite loop, will break on cycle detection
        if hare is None or hare.next is None:
            return False  # If we reach end of list without finding cycle

        tortoise = tortoise.next
        hare = hare.next.next

        # Check if tortoise and hare have met (cycle detected)
        if tortoise == hare:
            return True
```

**Explanation:**

*   The `Node` class is used to represent each node in the linked list.
*   The `linked_list_cycle` function takes the head of the linked list as input and returns a boolean indicating whether a cycle exists.
*   Floyd's Tortoise and Hare algorithm is employed, where we move two pointers at different speeds: `tortoise` (1 node interval) and `hare` (2 nodes intervals).
*   If there is no cycle, `hare` will reach the end of the list. Otherwise, it will meet `tortoise`, indicating a cycle.
*   The function correctly handles empty lists by returning False immediately.

**Example Use Case:**

```python
# Create linked list with cycle
node1 = Node(1)
node2 = Node(2)
node3 = Node(3)

node1.next = node2
node2.next = node3
node3.next = node2  # Create cycle

print(linked_list_cycle(node1))  # Output: True

# Create linked list without cycle
node4 = Node(4)
node5 = Node(5)
node6 = Node(6)

node4.next = node5
node5.next = node6

print(linked_list_cycle(node4))  # Output: False
```

This implementation efficiently detects cycles in linked lists of any size, handling empty lists correctly. The provided example demonstrates the function's usage and behavior with both cyclic and acyclic linked lists.
