```python
def text_justification(words, max_width):
    def justify_line(line_words, line_length, is_last=False):
        if len(line_words) == 1 or is_last:
            return ' '.join(line_words).ljust(max_width)
        
        num_gaps = len(line_words) - 1
        spaces_per_gap = (max_width - line_length) // num_gaps
        extra_spaces = (max_width - line_length) % num_gaps
        
        justified_line = ''
        for i in range(num_gaps):
            justified_line += line_words[i] + ' ' * (spaces_per_gap + 1)
            if i < extra_spaces:
                justified_line += ' '
        
        justified_line += line_words[-1]
        return justified_line.ljust(max_width)

    result = []
    current_line = []
    current_length = 0

    for word in words:
        # Check if adding the next word would exceed max_width
        if current_length + len(word) + len(current_line) > max_width:
            result.append(justify_line(current_line, current_length))
            current_line = [word]
            current_length = len(word)
        else:
            current_line.append(word)
            current_length += len(word)

    # Handle the last line
    result.append(' '.join(current_line).ljust(max_width))

    return result

# Example usage:
words = ["This", "is", "an", "example", "of", "text", "justification."]
max_width = 16
print(text_justification(words, max_width))
```

### Explanation:
- **`justify_line(line_words, line_length, is_last=False)`**: This helper function formats a single line of text based on the provided words and length. It handles both justified lines (for non-last lines) and left-aligned lines for the last line.
  - If there's only one word or it’s the last line, we simply left-align with padding.
  - For other cases, spaces are distributed evenly between words, with any extra spaces added to the first few gaps.

- **`text_justification(words, max_width)`**: The main function iterates through each word and decides when to split lines. It uses `justify_line` to format each line appropriately.
