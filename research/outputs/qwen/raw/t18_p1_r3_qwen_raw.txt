Certainly! The Levenshtein distance (also known as edit distance) is a measure of the difference between two sequences. It's defined as the minimum number of single-character edits (insertions, deletions, or substitutions) required to change one word into another.

Here's a Python function that implements the edit distance algorithm using dynamic programming:

```python
def edit_distance(word1, word2):
    m = len(word1)
    n = len(word2)

    # Create a 2D array to store results of subproblems
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Initialize the matrix
    for i in range(m + 1):
        dp[i][0] = i  # Cost of deleting all characters from word1
    for j in range(n + 1):
        dp[0][j] = j  # Cost of deleting all characters from word2

    # Fill the matrix
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = min(dp[i - 1][j],      # Delete
                               dp[i][j - 1],      # Insert
                               dp[i - 1][j - 1])  # Replace
                dp[i][j] += 1

    return dp[m][n]

# Example usage:
word1 = "kitten"
word2 = "sitting"
print(edit_distance(word1, word2))  # Output: 3
```

### Explanation:

- **`dp[i][j]`**: Represents the minimum number of edits required to convert the first `i` characters of `word1` into the first `j` characters of `word2`.
  
- **Initialization**:
  - If one string is empty, the edit distance is simply the length of the other string (all insertions or deletions).
  
- **Filling the matrix**:
  - For each character in both strings, if they are equal, no additional cost is added.
  - Otherwise, we take the minimum of three possible operations: delete a character from `word1`, insert a character into `word1`, or replace a character in `word1` with the corresponding character in `word2`.

- **Result**: The value at `dp[m][n]` will be the edit distance between the two strings.

This function efficiently computes the Levenshtein distance using dynamic programming, ensuring that the solution is both correct and optimal.
