```python
def merge_intervals(intervals):
    if not intervals:
        return []
    
    # Sort intervals based on the start time
    intervals.sort(key=lambda x: x[0])
    
    merged = [intervals[0]]
    
    for current_interval in intervals[1:]:
        last_merged_interval = merged[-1]
        
        # Check for overlapping intervals
        if current_interval[0] <= last_merged_interval[1]:
            # Merge the intervals
            merged[-1] = [last_merged_interval[0], max(last_merged_interval[1], current_interval[1])]
        else:
            # No overlap, add the current interval to the list
            merged.append(current_interval)
    
    return merged
```
This function takes a list of intervals (each represented as a list `[start, end]`) and merges all overlapping intervals. It returns a new list of non-overlapping intervals that cover all the input intervals' ranges.
