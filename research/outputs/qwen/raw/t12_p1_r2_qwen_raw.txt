Certainly! To implement the `bfs_shortest_path` function, we can use Breadth-First Search (BFS), which is well-suited for finding the shortest paths in unweighted graphs. BFS explores all vertices at a given distance from the source vertex before moving on to vertices further away.

Here's how you can write this function:

```python
from collections import deque

def bfs_shortest_path(graph, start, target):
    if start not in graph or target not in graph:
        return -1  # Return -1 if either node is not present in the graph
    
    visited = set()
    queue = deque([(start, 0)])  # (node, distance) tuple
    visited.add(start)
    
    while queue:
        current_node, distance = queue.popleft()
        
        if current_node == target:
            return distance
        
        for neighbor in graph[current_node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, distance + 1))
                
    return -1  # Return -1 if no path is found

# Example usage
if __name__ == "__main__":
    graph = {
        'A': ['B', 'C'],
        'B': ['A', 'D', 'E'],
        'C': ['A', 'F'],
        'D': ['B'],
        'E': ['B', 'F'],
        'F': ['C', 'E']
    }
    
    start_node = 'A'
    target_node = 'F'
    print(f"The shortest path length from {start_node} to {target_node} is: {bfs_shortest_path(graph, start_node, target_node)}")
```

### Explanation:

1. **Graph Representation**: The graph is represented as a dictionary where each key is a node and its value is a list of adjacent nodes.

2. **BFS Initialization**:
   - We use a `deque` to implement the BFS queue.
   - Each element in the queue is a tuple `(node, distance)`, where `distance` represents the shortest distance from the start node.

3. **Visited Set**: A set is used to keep track of visited nodes to avoid cycles and redundant work.

4. **BFS Execution**:
   - We process each node by popping it from the queue.
   - If the current node matches the target, we return its distance.
   - Otherwise, for each unvisited neighbor, we add it to the queue with an incremented distance.

5. **Return Value**: If no path is found (i.e., `target` is not reachable), the function returns `-1`.
