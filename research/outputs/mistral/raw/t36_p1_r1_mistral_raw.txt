I will provide you with a Python function implementing Dijkstra's algorithm for finding the shortest path from a starting node in an unweighted graph. In this case, I'm assuming that the input `graph` is represented as an adjacency list and the nodes are numbered from 0 to `n-1`.

```python
def dijkstra_shortest_path(graph, start):
    n = len(graph)
    dist = [float('inf')] * n
    visited = [False] * n
    dist[start] = 0

    for _ in range(n - 1):
        min_distance = float('inf')
        u = -1
        for node in range(n):
            if not visited[node] and dist[node] < min_distance:
                min_distance = dist[node]
                u = node

        visited[u] = True
        for neighbor in graph[u]:
            if not visited[neighbor]:
                new_dist = dist[u] + 1
                if new_dist < dist[neighbor]:
                    dist[neighbor] = new_dist

    return dist
```

This function computes the shortest distances to all reachable nodes in the graph using Dijkstra's algorithm. Here is a sample usage:

```python
graph = [
    [],
    [1, 3],
    [0, 2, 4],
    [0, 3, 5],
    [1, 2, 4, 5]
]
print(dijkstra_shortest_path(graph, 0))
# Output: [0, 1, 2, 3, 2]
```

The output corresponds to the shortest distances from node 0 to each of the other nodes in the graph. In this case, node 0 has a distance of 0, node 1 has a distance of 1, node 2 and node 4 have a distance of 2, and both node 3 and node 5 have a distance of 3 from node 0.
