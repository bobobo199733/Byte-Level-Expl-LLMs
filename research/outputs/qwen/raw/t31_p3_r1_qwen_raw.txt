Certainly! Below is a Python function named `serialize_tree` that takes the root of a binary tree and returns a string representation of it. The function handles both non-empty and empty trees appropriately:

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def serialize_tree(root):
    if root is None:
        return "#"
    
    # Recursively serialize the left and right subtrees
    left_serialized = serialize_tree(root.left)
    right_serialized = serialize_tree(root.right)
    
    # Combine the current node's value with its children's serialized values
    return f"{root.val},{left_serialized},{right_serialized}"

# Example usage:
# Constructing a simple binary tree
#     1
#    / \
#   2   3
#      /
#     4

tree = TreeNode(1)
tree.left = TreeNode(2)
tree.right = TreeNode(3, TreeNode(4))

# Serialize the tree
serialized_tree = serialize_tree(tree)

print(serialized_tree)  # Output: "1,2,#,#,3,4,#,#,#"
```

### Explanation:
- **TreeNode Class**: This is a simple class to represent nodes in a binary tree. Each node has a value (`val`), and pointers to its left (`left`) and right (`right`) children.
  
- **serialize_tree Function**:
  - If the root is `None`, it returns `"#"` to denote an empty subtree.
  - For non-empty nodes, it recursively serializes the left and right subtrees and combines them with the node's value. The values are separated by commas.

### Example Output:
For a binary tree like this:

```
    1
   / \
  2   3
     /
    4
```

The serialized string would be `"1,2,#,#,3,4,#,#,#"`. This format indicates that the root node's value is `1`, its left child has a value of `2` and no right child (`#`), its right child (node with value `3`) has a left child with a value of `4` and no right child (`#`), and both the left and right children of nodes `2` and `4` are empty.

This method can be used to serialize any binary tree, and it's particularly useful for storing or transmitting tree structures in a compact string format.
