Here's a Python function called `edit_distance` that computes the Levenshtein distance between two strings using dynamic programming. This function handles empty strings and is optimized for longer strings.

```python
def edit_distance(word1, word2):
    len1 = len(word1)
    len2 = len(word2)

    # Create a matrix to store the distances between substrings of both words
    matrix = [[0 for _ in range(len2 + 1)] for _ in range(len1 + 1)]

    # Initialize the first row and column with their corresponding indices
    for i in range(len1 + 1):
        matrix[i][0] = i
    for j in range(len2 + 1):
        matrix[0][j] = j

    # Fill in the rest of the matrix using dynamic programming
    for i in range(1, len1 + 1):
        for j in range(1, len2 + 1):
            if word1[i - 1] == word2[j - 1]:
                cost = 0
            else:
                cost = 1

            # Minimum of replacing current characters, inserting character from word1 at i, or inserting character from word2 at j
            matrix[i][j] = min(
                matrix[i - 1][j] + 1,
                matrix[i][j - 1] + 1,
                matrix[i - 1][j - 1] + cost
            )

    # The bottom-right cell contains the final result (the Levenshtein distance)
    return matrix[-1][-1]
```

You can test this function with some examples:

```python
print(edit_distance("kitten", "sitting"))  # Output: 3
print(edit_distance("dog", "dog"))  # Output: 0
print(edit_distance("", "world"))  # Output: 4
print(edit_distance("hello", "halo"))  # Output: 1
```
