Here's a Python function that generates all valid parentheses combinations using backtracking:

```python
def generate_parentheses(n):
    result = []
    def backtrack(left, right, paren=""):
        if left == right and left == n:
            result.append(paren)

        if left > 0:
            backtrack(left - 1, right, paren + "(")

        if left < right:
            backtrack(left, right + 1, paren + ")")

    backtrack(n, 0, "")
    return result
```

This function uses recursion and backtracking to generate valid parentheses combinations. It defines a helper function `backtrack` that takes three parameters: the number of remaining opening parentheses (`left`), the number of remaining closing parentheses (`right`), and an optional string `paren` to keep track of the current combination.

The base case is when both `left` and `right` equal `n`, in which case a valid combination has been found, and it's appended to the `result` list. If there are remaining opening parentheses (i.e., `left > 0`), we recursively call the function with decreased `left` and incremented `paren`. Similarly, if there are remaining closing parentheses (i.e., `left < right`) and the current combination is balanced so far, we recursively call the function with incremented `right` and appended ")" to `paren`.

This solution ensures that invalid intermediate states are not generated unnecessarily by checking the balance of parentheses at each step before making further recursive calls. It also handles the case when n = 0 correctly (since no valid combinations exist in this case).
