To solve the N-Queens problem without using external libraries, we can create a recursive function named `n_queens()`. This function will generate all possible solutions for the given value of `n`. Here is the code:

```python
def n_queens(n):
    def is_safe(board, row, col):
        for i in range(row):
            if board[i] == col or abs(board[i] - col) == abs(i - row):
                return False
        return True

    def solve_nqueens(n, board=[]):
        if len(board) == n:
            yield board
            return

        for i in range(n):
            if is_safe(board, len(board), i):
                board_copy = board[:]
                board_copy.append(i)
                solve_nqueens(n, board_copy)

    solve_nqueens(n)

def print_solutions(n_queens_solutions):
    for solution in n_queens_solutions:
        print(*solution)

if __name__ == "__main__":
    solutions = set()
    for sol in n_queens(4):
        key = ''.join(str(x) for x in sol)
        if key not in solutions:
            solutions.add(key)
            print_solutions([sol])
            print()
``

In the provided code, we have defined the `n_queens` function which internally uses helper functions `is_safe` and `solve_nqueens`. The `is_safe` function checks if it is safe to place a queen at a given position on the board. The `solve_nqueens` function performs the actual recursion, generating all possible solutions for the given N.

The main part of the code initializes an empty set called `solutions` and iterates through all solutions generated by `n_queens`. It removes duplicate solutions (since there can only be one arrangement of queens per solution) and prints each unique solution as a row of four integers representing the column numbers.
