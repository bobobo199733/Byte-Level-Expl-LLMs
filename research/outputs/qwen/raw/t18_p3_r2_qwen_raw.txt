To solve the problem of finding the minimum number of edits required to transform one string into another, we can use dynamic programming. The problem is commonly known as the "Edit Distance" or "Levenshtein Distance" problem.

Here's a Python function that implements this approach:

```python
def edit_distance(word1: str, word2: str) -> int:
    # Initialize a 2D array to store the edit distances
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # Base case initialization
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    
    # Compute the edit distance
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j],      # Deletion
                                   dp[i][j - 1],      # Insertion
                                   dp[i - 1][j - 1])  # Substitution
    
    return dp[m][n]

# Example usage:
word1 = "kitten"
word2 = "sitting"
print(edit_distance(word1, word2))  # Output: 3
```

### Explanation:

- **Initialization**: 
  - `dp` is a 2D list where `dp[i][j]` represents the minimum number of edits to transform the first `i` characters of `word1` into the first `j` characters of `word2`.
  - The base cases initialize the first row and column, representing the cost of transforming an empty string into a substring of `word1` or `word2`.

- **Filling the DP Table**:
  - For each character in both strings, if they match (`word1[i-1] == word2[j-1]`), the cost is the same as the previous diagonal cell.
  - If they don't match, the cost increases by one due to a possible operation (insertion, deletion, or substitution).

- **Result**:
  - The value at `dp[m][n]` will be the minimum number of edits required to transform `word1` into `word2`.

This function has a time complexity of O(m * n) and space complexity of O(m * n), where `m` is the length of `word1` and `n` is the length of `word2`.
