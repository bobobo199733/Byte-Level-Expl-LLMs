To create a function that checks the strength of a password in Python, we'll consider a few criteria:

1. Password length should be at least 8 characters.
2. The password should contain at least one lowercase letter, one uppercase letter, one digit, and one special character.
3. Repeat these four types of characters at least twice in the password (excluding spaces).

Here's a Python function named `validate_password` that fulfills these criteria:

```python
import re

def validate_password(password):
    if len(password) < 8:
        return False

    lowercase = re.search('[a-z]', password)
    uppercase = re.search('[A-Z]', password)
    digit = re.search('[0-9]', password)
    special_char = re.search('[!@#$%^&*(),.?/:;{}|<>]', password)

    if not (lowercase and uppercase and digit and special_char):
        return False

    for char in password:
        if char.isalpha() or char.isdigit() or char.isalnum(char) or char.isspace():
            continue
        count = password.count(char)
        if count < 2:
            return False

    return True
```

The function takes a string as input, checks each character type requirement, and verifies that each character type is repeated at least twice in the password (excluding spaces). If all criteria are met, the function returns `True`, indicating a strong password. Otherwise, it returns `False`.
