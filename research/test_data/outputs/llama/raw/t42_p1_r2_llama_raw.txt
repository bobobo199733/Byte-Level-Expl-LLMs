Here is a Python function to solve the problem using Depth-First Search (DFS):

```python
from collections import defaultdict

def course_schedule(num_courses, prerequisites):
    """
    Determines whether all courses can be completed.

    Args:
        num_courses (int): The total number of courses.
        prerequisites (list): A list of prerequisite pairs [a, b] where a depends on b.

    Returns:
        bool: True if all courses can be completed, otherwise False.
    """

    # Create an adjacency list to represent the graph
    graph = defaultdict(list)
    
    # Initialize the in-degree of each node (course) to 0
    in_degree = {i: 0 for i in range(num_courses)}

    # Build the graph and update in-degrees
    for prerequisite in prerequisites:
        a, b = prerequisite
        graph[b].append(a)
        in_degree[a] += 1

    # Initialize a queue with nodes having in-degree 0 (no dependencies)
    queue = [i for i in range(num_courses) if in_degree[i] == 0]

    # Perform DFS to detect cycles
    while queue:
        course = queue.pop(0)

        # For each neighbor of the current node, decrease its in-degree by 1
        for neighbor in graph[course]:
            in_degree[neighbor] -= 1

            # If the in-degree becomes 0, add it to the queue
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    # If there are remaining nodes with non-zero in-degrees, then a cycle exists
    for degree in in_degree.values():
        if degree != 0:
            return False

    return True
```

**Example Usage:**

```python
num_courses = 4
prerequisites = [[1, 0], [2, 0], [3, 1], [3, 2]]
print(course_schedule(num_courses, prerequisites))  # Output: True

num_courses = 2
prerequisites = [[1, 0]]
print(course_schedule(num_courses, prerequisites))  # Output: False
```

This function works by first building an adjacency list representation of the graph and updating in-degrees. Then it uses DFS to traverse the graph and detect cycles (i.e., courses with dependencies that cannot be completed). If no cycles are found and all nodes have been visited, then all courses can be completed.
