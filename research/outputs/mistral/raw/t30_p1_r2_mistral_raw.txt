Here's the Python function definition for finding the maximum sum of a contiguous subarray in an array:

```python
def max_subarray_sum(nums):
    if len(nums) == 0:
        return 0

    current_max = nums[0]
    global_max = nums[0]

    for i in range(1, len(nums)):
        current_max = max(nums[i], current_max + nums[i])
        global_max = max(global_max, current_max)

    return global_max
```
This function uses the Kadane's algorithm to find the maximum sum of a contiguous subarray. The time complexity is O(n), where n is the length of the array.
