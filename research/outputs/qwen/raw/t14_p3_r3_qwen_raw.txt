```python
def generate_parentheses(n):
    def backtrack(s='', left=0, right=0):
        # If the length of s is 2 * n, it means we have used up all pairs and reached a valid combination.
        if len(s) == 2 * n:
            combinations.append(s)
            return
        
        # We can add '(' only if there are less than n left parentheses
        if left < n:
            backtrack(s + '(', left + 1, right)
        
        # We can add ')' only if there are more left parentheses than right ones
        if right < left:
            backtrack(s + ')', left, right + 1)

    combinations = []
    backtrack()
    return combinations

# Example usage:
n = 3
print(generate_parentheses(n))
```

### Explanation:

1. **Backtracking Function**: The `backtrack` function is defined to generate valid combinations by adding either '(' or ')' at each step.
   - `s`: The current combination of parentheses being built.
   - `left`: Number of left parentheses used so far.
   - `right`: Number of right parentheses used so far.

2. **Base Case**: When the length of `s` equals `2 * n`, it means we have used up all pairs and a valid combination is found, which is added to the `combinations` list.

3. **Recursive Steps**:
   - If there are fewer left parentheses than `n`, we can add a '('.
   - We can only add a ')' if there are more left parentheses than right ones.

4. **Initialization**: The `generate_parentheses` function initializes an empty list `combinations` and calls the `backtrack` function starting with an empty string.

5. **Return Value**: Finally, the function returns the list of all valid combinations.
