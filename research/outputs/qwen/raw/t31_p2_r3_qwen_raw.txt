Certainly! Below is a Python function named `serialize_tree` that serializes a binary tree into a string representation. This function uses a breadth-first traversal (level-order) to ensure all nodes are visited in the correct order, and it handles null or empty child nodes explicitly.

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def serialize_tree(root):
    if root is None:
        return "None,"
    
    queue = [root]
    result = ""
    
    while queue:
        node = queue.pop(0)
        
        if node is not None:
            result += str(node.val) + ","
            queue.append(node.left if node.left else None)
            queue.append(node.right if node.right else None)
        else:
            result += "None,"
    
    return result
```

### Explanation

1. **TreeNode Class**: A simple `TreeNode` class is defined to represent nodes in the binary tree.
2. **serialize_tree Function**:
   - If the root is `None`, it returns `"None,"` indicating an empty tree.
   - A queue is initialized with the root node.
   - The function uses a while loop to process each node in the queue.
     - For each node, its value (if not `None`) and its left and right children are appended to the result string.
     - If a child node is `None`, it's represented as `"None,"` in the output.

### Example Usage

```python

#       1
```
