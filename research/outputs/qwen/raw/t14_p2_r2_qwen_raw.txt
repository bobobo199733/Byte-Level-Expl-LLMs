The function ensures that at no point during the process do we have more closing parentheses than opening ones, and it handles the case where `n = 0` correctly.

```python
def generate_parentheses(n):
    def backtrack(s='', left=0, right=0):
        # If the length of s is 2 * n, add to the result list
        if len(s) == 2 * n:
            result.append(s)
            return
        
        # Add an opening parenthesis if we have not used up all the openings
        if left < n:
            backtrack(s + '(', left + 1, right)
        
        # Add a closing parenthesis only if there are more openings than closings
        if right < left:
            backtrack(s + ')', left, right + 1)
    
    result = []
    backtrack()
    return result

# Example usage:
print(generate_parentheses(3))
```

### Explanation:
- **Backtracking Function (`backtrack`)**: This function is the core of our solution. It takes three parameters: `s` (the current string being formed), `left` (count of remaining open parentheses to use), and `right` (count of remaining close parentheses to use).
  - If the length of `s` equals `2 * n`, it means we have used up all the pairs, so we add `s` to the result list.
  - We can add an opening parenthesis only if there are still some left. This ensures that we don't go into invalid states where more closing parentheses than opening ones would occur.
  - We can add a closing parenthesis only if the number of open parentheses is greater than the number of close ones, ensuring that the string remains valid.

- **Initial Call (`generate_parentheses`)**: The initial call to `backtrack()` starts with an empty string and no used parentheses yet.

- **Result List**: This list collects all valid combinations generated by the backtracking function.

This approach ensures that we only generate valid strings and avoid unnecessary intermediate states. It correctly handles the case when `n = 0` by returning an empty list, as there are no valid combinations for zero pairs of parentheses.
