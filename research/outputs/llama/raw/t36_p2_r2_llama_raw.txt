**Dijkstra's Shortest Path Function**
====================================

Here is a Python function implementing Dijkstra's shortest path algorithm:

```python
import sys

def dijkstra_shortest_path(graph, start):
    """
    Compute the shortest distances from a start node to all other reachable nodes in a weighted graph.

    Args:
        graph (dict): A dictionary representing the adjacency list of the graph.
            Each key is a node and its corresponding value is another dictionary with neighboring nodes as keys
            and edge weights as values.
        start (node): The node from which to compute shortest distances.

    Returns:
        dict: A dictionary containing the shortest distance from the start node to every reachable node.
    """

    # Initialize the distance dictionary with infinite values for all nodes except the start node, which is 0
    distances = {node: float('inf') for node in graph}
    distances[start] = 0

    # Create a set of unvisited nodes
    unvisited_nodes = set(graph.keys())

    while unvisited_nodes:
        # Select the unvisited node with the smallest distance value (i.e., the current node)
        current_node = min(unvisited_nodes, key=lambda node: distances[node])

        # Remove the current node from the unvisited set
        unvisited_nodes.remove(current_node)

        # Iterate over neighboring nodes of the current node
        for neighbor, weight in graph[current_node].items():
            # Calculate the tentative distance to the neighbor through the current node
            new_distance = distances[current_node] + weight

            # If this path is shorter than the previously known shortest path, update the distance and predecessor
            if new_distance < distances[neighbor]:
                distances[neighbor] = new_distance

    return distances
```

**Example Usage:**
```python
# Define a sample graph with weighted edges
graph = {
    'A': {'B': 3, 'C': 4},
    'B': {'A': 3, 'D': 2, 'E': 5},
    'C': {'A': 4, 'F': 1},
    'D': {'B': 2, 'E': 7},
    'E': {'B': 5, 'D': 7, 'F': 6},
    'F': {'C': 1, 'E': 6}
}

# Compute the shortest distances from node 'A' to all other nodes
distances = dijkstra_shortest_path(graph, 'A')
print(distances)  # Output: {'A': 0, 'B': 3, 'C': 4, 'D': 5, 'E': 8, 'F': 5}
```

This implementation uses a priority queue (based on the `min` function with a lambda key) to efficiently select the next node with the smallest distance value. It also correctly handles disconnected graphs by returning infinite distances for unreachable nodes. The code is robust and readable, following standard Python naming conventions and docstring guidelines.
