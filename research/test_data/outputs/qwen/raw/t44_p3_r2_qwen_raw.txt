Certainly! To create a `rotate_array` function in Python that rotates an array (list) to the right by `k` positions, you can follow these steps:

1. **Understand the Problem**: Rotating an array to the right means moving each element of the list by `k` positions to the right, and the elements at the end wrap around to the beginning.

2. **Implement the Logic**:
   - If `k` is greater than the length of the array, it can be optimized by taking `k % len(nums)` since rotating an array by its own length will result in the same array.
   - Use Python's slicing and concatenation features to achieve this.

Here’s a simple implementation:

```python
def rotate_array(nums, k):
    n = len(nums)
    # Normalize k to be within the bounds of the array length
    k %= n
    
    # Perform the rotation
    nums[:] = nums[-k:] + nums[:-k]
    
    return nums

# Example usage:
nums = [1, 2, 3, 4, 5]
k = 2
print("Original array:", nums)
rotate_array(nums, k)
print("Rotated array:", nums)

# Additional example
nums = [1, 2, 3, 4, 5, 6, 7]
k = 3
print("Original array:", nums)
rotate_array(nums, k)
print("Rotated array:", nums)
```

### Explanation:
- `n = len(nums)` calculates the length of the array.
- `k %= n` ensures that `k` is within the bounds of the array size. For example, if `k` is 7 and `nums` has only 5 elements, it effectively becomes a rotation by 2 positions (`7 % 5 = 2`).
- `nums[-k:]` gives the last `k` elements.
- `nums[:-k]` gives all but the last `k` elements.
- Concatenating these two slices using `+` and assigning back to `nums[:]` performs the rotation in place.

### Example Outputs:
For the example usage, you would get:

```
Original array: [1, 2, 3, 4, 5]
Rotated array: [4, 5, 1, 2, 3]
Original array: [1, 2, 3, 4, 5, 6, 7]
Rotated array: [5, 6, 7, 1, 2, 3, 4]
```

This function modifies the list in place and returns it.
