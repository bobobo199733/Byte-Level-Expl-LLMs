Here's a Python function that implements Roman numeral conversion:

```python
def roman_to_int(s):
    """
    Converts a Roman numeral to an integer.

    Args:
        s (str): A string representing a Roman numeral.

    Returns:
        int: The integer value of the Roman numeral.

    Raises:
        ValueError: If the input string is not a valid Roman numeral.
    """

    if not s:
        raise ValueError("Input string cannot be empty")

    roman_numerals = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }

    total = 0

    for i in range(len(s)):
        # Check if the current numeral is valid
        if s[i] not in roman_numerals:
            raise ValueError("Invalid Roman numeral")

        # If this is not the last numeral and its value is less than the next one,
        # subtract it from the total (this handles cases like IV, IX etc.)
        if i < len(s) - 1 and roman_numerals[s[i]] < roman_numerals[s[i + 1]]:
            total -= roman_numerals[s[i]]
        else:
            total += roman_numerals[s[i]]

    return total
```

Here's a brief explanation of the code:

*   We define a dictionary `roman_numerals` that maps each Roman numeral to its corresponding integer value.
*   The function takes a string `s` as input and checks if it's empty. If so, it raises a `ValueError`.
*   It then iterates over each character in the input string. For each character:
    *   We check if the character is valid (i.e., it exists in the `roman_numerals` dictionary). If not, we raise a `ValueError`.
    *   If this isn't the last numeral and its value is less than the next one, we subtract its value from the total. This handles cases like IV, IX, XL, XC, CD, CM.
    *   Otherwise, we add its value to the total.
*   Finally, after processing all numerals, the function returns the total integer value.
