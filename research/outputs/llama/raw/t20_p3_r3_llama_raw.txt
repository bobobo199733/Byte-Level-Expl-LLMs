**Merging Multiple Sorted Lists**
=====================================

The `merge_k_sorted_lists` function takes in a list of sorted lists and returns a single sorted list.

```python
import heapq

def merge_k_sorted_lists(lists):
    """
    Merge multiple sorted lists into one sorted list.

    Args:
        lists (list): A list of sorted lists.

    Returns:
        list: A single sorted list.
    """
    # Initialize an empty list to store the result
    merged_list = []

    # Use a heap to keep track of the smallest element in each list
    min_heap = []

    # Iterate over each list and its index
    for i, lst in enumerate(lists):
        # If the list is not empty, push the first element and its index into the heap
        if lst:
            heapq.heappush(min_heap, (lst[0], i, 0))

    # While the heap is not empty
    while min_heap:
        # Pop the smallest element from the heap
        val, list_idx, elem_idx = heapq.heappop(min_heap)

        # Add the popped element to the merged list
        merged_list.append(val)

        # If there are more elements in the list, push the next one into the heap
        if elem_idx + 1 < len(lists[list_idx]):
            heapq.heappush(min_heap, (lists[list_idx][elem_idx + 1], list_idx, elem_idx + 1))

    return merged_list
```

**Example Use Case**
---------------------

```python
list1 = [1, 3, 5]
list2 = [2, 4, 6]
list3 = [0, 7, 8]

lists = [list1, list2, list3]
print(merge_k_sorted_lists(lists))  # Output: [0, 1, 2, 3, 4, 5, 6, 7, 8]
```

This function has a time complexity of O(N log k), where N is the total number of elements and k is the number of lists. This is because we use a heap to keep track of the smallest element in each list, which allows us to pop the smallest element in O(log k) time for each push operation.
