```python
def kth_largest(nums, k):
    """
    Finds the k-th largest element in the given list of numbers.

    Parameters:
        nums (list): A list of integers.
        k (int): The k-th position to find the largest element for.

    Returns:
        int: The k-th largest number in the list.
    """
    return sorted(nums, reverse=True)[k-1]
```

This function uses Python's built-in sorting capabilities to sort the list in descending order and then returns the k-th element from that sorted list. Note that list indices in Python are 0-based, so `k-1` is used to get the correct position.
