**N-Queens Problem Solution**
=====================================

The following Python function solves the classic N-Queens problem, where we need to place N queens on an NxN chessboard such that no two queens attack each other.

```python
def n_queens(n):
    """
    Returns all valid N-Queens solutions.

    :param n: The size of the chessboard (number of rows and columns).
    :return: A list of lists, where each inner list represents a solution.
             Each solution is represented as a list of column indices for each row.
    """

    def solve(queens):
        # If all queens are placed, add the current configuration to the result
        if len(queens) == n:
            return [queens[:]]

        result = []
        for col in range(n):
            # Check if it's safe to place a queen at this position
            if all(abs(col - q[0]) != abs(i - len(q)) and i < len(q) for i, q in enumerate(queens)):
                new_queens = queens + [col]
                result.extend(solve(new_queens))
        return result

    # Initialize the first row with the first queen
    return solve([0])
```

**Example Use Case**
--------------------

To get all valid 4-Queens solutions, call the function like this:

```python
n = 4
solutions = n_queens(n)
print(len(solutions))  # Output: 2
for i, solution in enumerate(solutions):
    print(f"Solutions {i+1}: {solution}")
```

This will output two valid solutions for placing four queens on a 4x4 chessboard.
