```python
from collections import Counter

def find_all_anagrams(s: str, p: str) -> list:
    """
    Finds all start indices in string s where an anagram of string p begins.
    
    Args:
        s (str): The input string to search for anagrams.
        p (str): The string whose anagrams we're looking for.

    Returns:
        list: A sorted list of starting indices where an anagram of p begins.
    """
    
    # Check if the pattern is longer than the input string
    if len(p) > len(s):
        return []
    
    # Create a counter to store the frequency of characters in the pattern
    p_count = Counter(p)
    
    # Initialize variables for the start and end indices, as well as the count of matching characters
    left = 0
    right = 0
    match_count = len(p)
    indices = []
    
    # Iterate over the input string to find all anagrams
    while right < len(s):
        # If the current character matches the pattern's character, decrement its count
        if s[right] in p_count:
            p_count[s[right]] -= 1
            
            # If the count becomes zero, increment the match count
            if p_count[s[right]] == 0:
                match_count += 1
        
        # Add the current index to the list of indices if it's a valid anagram
        if right - left + 1 == len(p) and match_count == len(p):
            indices.append(left)
        
        # If we've found all characters in the pattern, move the window forward
        if right - left + 1 == len(p):
            if s[left] in p_count:
                # If the first character of the pattern matches, decrement its count
                p_count[s[left]] += 1
                
                # If the count becomes positive again, decrement the match count
                if p_count[s[left]] > 0:
                    match_count -= 1
            
            left += 1
        
        right += 1
    
    return sorted(indices)
```

This function uses a sliding window approach to efficiently find all anagrams in the input string. It maintains two pointers, `left` and `right`, which represent the start and end indices of the current window, respectively. The function iterates over the input string using these two pointers and updates the counters for the characters in the pattern accordingly.
