```python
def heapq_kth_largest(nums, k):
    import heapq

    if len(nums) < k:
        raise ValueError("K must be smaller than the length of the list")

    heap = sorted(nums)[:k]
    return heapq.nlargest(1, heap)[0]
```

This implementation uses the built-in Python `heapq` module for efficient sorting and prioritization of elements. The function first checks if the specified k is valid, then it sorts the input list and takes the top k elements (which are the k largest numbers). Finally, it returns the largest of these k elements.
