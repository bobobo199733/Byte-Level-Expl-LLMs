**Edit Distance Function**
=========================

The following is an implementation of the edit distance algorithm in Python. This function uses dynamic programming to find the minimum number of operations (insertions, deletions, and substitutions) required to transform one word into another.

```python
def edit_distance(word1: str, word2: str) -> int:
    """
    Returns the minimum number of edits needed to transform one string into another.
    
    Args:
        word1 (str): The original word.
        word2 (str): The target word.
    
    Returns:
        int: The minimum edit distance between the two words.
    """

    # Initialize a matrix to store the edit distances between substrings of word1 and word2
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Initialize the base cases: transforming an empty string to a non-empty string requires insertions
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Fill in the rest of the matrix using dynamic programming
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if word1[i - 1] == word2[j - 1] else 1
            dp[i][j] = min(
                dp[i - 1][j] + 1,      # Deletion
                dp[i][j - 1] + 1,      # Insertion
                dp[i - 1][j - 1] + cost  # Substitution or no operation
            )

    return dp[m][n]
```

**Example Use Cases**
--------------------

```python
print(edit_distance("kitten", "sitting"))  # Output: 3 (delete 'k', substitute 'e' with 's', insert 'g')
print(edit_distance("", "hello"))           # Output: 5 (insert all characters)
print(edit_distance("hello", ""))           # Output: 5 (delete all characters)
```

This implementation assumes that the edit operations are weighted equally. If you need to assign different weights to the operations, you can modify the cost calculation accordingly.
