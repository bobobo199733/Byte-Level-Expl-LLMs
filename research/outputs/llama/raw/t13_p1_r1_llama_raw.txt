Here is the Python function `spiral_matrix` that returns all elements of a 2D matrix in spiral order:

```python
def spiral_matrix(matrix):
    """
    Returns all elements of a 2D matrix in spiral order.

    Args:
        matrix (list): A 2D list representing a square or rectangular matrix.

    Returns:
        list: A 1D list containing all elements of the input matrix in spiral order.
    """

    # Get the number of rows and columns in the matrix
    num_rows = len(matrix)
    if num_rows == 0:
        return []

    num_cols = len(matrix[0])

    # Initialize variables to keep track of the current position and bounds
    top = 0
    bottom = num_rows - 1
    left = 0
    right = num_cols - 1

    result = []
    while True:
        # Traverse from left to right along the top row
        for i in range(left, right + 1):
            result.append(matrix[top][i])
        top += 1
        if top > bottom or left > right:
            break

        # Traverse from top to bottom along the right column
        for i in range(top, bottom + 1):
            result.append(matrix[i][right])
        right -= 1
        if top > bottom or left > right:
            break

        # Traverse from right to left along the bottom row
        if top <= bottom:
            for i in range(right, left - 1, -1):
                result.append(matrix[bottom][i])
            bottom -= 1
            if top > bottom or left > right:
                break

        # Traverse from bottom to top along the left column
        if left <= right:
            for i in range(bottom, top - 1, -1):
                result.append(matrix[i][left])
            left += 1
            if top > bottom or left > right:
                break

    return result
```

Here's an example usage of this function:

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(spiral_matrix(matrix))  # Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
```

Note that this function assumes the input matrix is a list of lists in Python. The function first checks if the matrix has any rows. If it doesn't, an empty list is returned immediately. Then, it initializes variables to keep track of the top and bottom row indices, left and right column indices, and an empty result list.

The function then enters a loop that continues until all elements have been visited. In each iteration of the loop, four sections are traversed in order: from left to right along the top row, from top to bottom along the right column, from right to left along the bottom row, and from bottom to top along the left column. The result list is updated with each element encountered during traversal.

Finally, the function returns the result list after all elements have been visited.
