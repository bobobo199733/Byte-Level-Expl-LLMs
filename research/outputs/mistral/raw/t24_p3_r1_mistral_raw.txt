Here's a Python function that implements the solution for finding the kth largest element in an array (list). This implementation uses the quickselect algorithm which is an optimized version of quicksort. It has a time complexity of O(n) in the average and worst case scenarios, making it more efficient than other methods like heapsort or sorting the entire list.

```python
def kth_largest(nums, k):
    def quickselect(arr, low, high, k):
        if low < high:
            j = partition(arr, low, high)
            if j == k:
                return arr[j]
            elif j > k:
                return quickselect(arr, low, j - 1, k)
            else:
                return quickselect(arr, j + 1, high, k)

    def partition(arr, low, high):
        pivot = arr[high]
        i = low
        for j in range(low, high):
            if arr[j] >= pivot:
                arr[i], arr[j] = arr[j], arr[i]
                i += 1
        arr[i], arr[high] = arr[high], arr[i]
        return i

    return quickselect(nums, 0, len(nums) - 1, len(nums) - k)
```

Usage example:

```python
nums = [3, 5, 2, 6, 8, 7, 4]
k = 3
print(kth_largest(nums, k))  # Output: 7 (third largest number)
```
