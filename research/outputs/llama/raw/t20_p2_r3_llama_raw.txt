Here's the Python function to merge k sorted lists:

```python
import heapq

def merge_k_sorted_lists(lists):
    """
    Merges k sorted lists into a single sorted list.

    Args:
        lists (list): A list of sorted integer lists.

    Returns:
        list: A single sorted list containing all elements from the input lists.
    """

    # Initialize an empty list to store the result
    merged_list = []

    # Create a min heap and add the first element of each list along with its list index and element index
    min_heap = [(lst[0], i, 0) for i, lst in enumerate(lists) if lst]

    # Heapify the min heap
    heapq.heapify(min_heap)

    while min_heap:
        # Extract the smallest element from the min heap
        val, list_idx, elem_idx = heapq.heappop(min_heap)

        # Add the extracted value to the merged list
        merged_list.append(val)

        # If there are more elements in the list from which the value was extracted, add the next element to the min heap
        if elem_idx < len(lists[list_idx]) - 1:
            heapq.heappush(min_heap, (lists[list_idx][elem_idx + 1], list_idx, elem_idx + 1))

    return merged_list

# Example usage:
sorted_lists = [[1, 3, 5], [2, 4, 6], []]
print(merge_k_sorted_lists(sorted_lists))  # Output: [1, 2, 3, 4, 5, 6]

```

In this code:

*   We use Python's built-in `heapq` module to create a min heap and extract elements in ascending order.
*   The function takes in a list of sorted integer lists as input and returns a single sorted list containing all elements from the input lists.
*   It preserves duplicates, handles empty lists correctly, and does not rely on external libraries for efficient merging.
