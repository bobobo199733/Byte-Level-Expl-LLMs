```python
def generate_parentheses(n):
    def backtrack(s='', left=0, right=0):
        # If the length of s is 2 * n, a valid combination has been formed.
        if len(s) == 2 * n:
            result.append(s)
            return
        
        # Add '(' only when we have not used up all possible left parentheses
        if left < n:
            backtrack(s + '(', left + 1, right)
        
        # Add ')' only when there are more left parentheses than right ones
        if right < left:
            backtrack(s + ')', left, right + 1)

    result = []
    backtrack()
    return result

# Example usage:
n = 3
print(generate_parentheses(n))
```

### Explanation:

- **Function `generate_parentheses(n)`**:
  - This function initializes an empty list `result` to store the valid combinations.
  
- **Backtracking Function `backtrack(s, left, right)`**:
  - `s`: The current string being constructed (a combination of parentheses).
  - `left`: The count of unmatched opening parentheses ('(') used so far in `s`.
  - `right`: The count of unmatched closing parentheses (')') used so far in `s`.
  
- **Base Case**:
  - When the length of `s` is equal to `2 * n`, it means we have exactly `n` pairs of parentheses, and this combination is valid. We append `s` to `result`.

- **Recursive Cases**:
  - We can add an opening parenthesis '(' only if there are fewer than `n` unmatched left parentheses.
  - We can add a closing parenthesis ')' only if the number of unmatched left parentheses is greater than the number of unmatched right parentheses.

This approach ensures that we do not generate invalid combinations and avoids unnecessary intermediate states. The function correctly handles the case when `n = 0` by returning an empty list, as there are no valid combinations in this scenario.
