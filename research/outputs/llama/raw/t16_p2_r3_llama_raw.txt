**Sudoku Solver Function**
==========================

The following Python function solves a standard 9x9 Sudoku puzzle using backtracking.

```python
def sudoku_solver(board):
    """
    Solves a standard 9x9 Sudoku puzzle in-place.

    Args:
        board (list of lists): A 2D list representing the Sudoku board.
            Empty cells are represented by 0.

    Raises:
        ValueError: If the puzzle is invalid or unsolvable.
    """

    def is_valid(board, row, col, num):
        """
        Checks if a number can be placed in a given position on the board.

        Args:
            board (list of lists): The Sudoku board.
            row (int): The row index of the position.
            col (int): The column index of the position.
            num (int): The number to check.

        Returns:
            bool: True if the number can be placed, False otherwise.
        """
        # Check row and column
        for i in range(9):
            if board[row][i] == num or board[i][col] == num:
                return False

        # Check box
        start_row = row - row % 3
        start_col = col - col % 3
        for i in range(3):
            for j in range(3):
                if board[start_row + i][start_col + j] == num:
                    return False

        return True

    def solve_sudoku(board):
        """
        Solves the Sudoku puzzle using backtracking.

        Args:
            board (list of lists): The Sudoku board.
        """
        for i in range(9):
            for j in range(9):
                if board[i][j] == 0:
                    for num in range(1, 10):
                        if is_valid(board, i, j, num):
                            board[i][j] = num
                            solve_sudoku(board)
                            board[i][j] = 0
                    raise ValueError("Puzzle is unsolvable")
        return True

    try:
        solve_sudoku(board)
    except ValueError as e:
        raise ValueError(f"Error: {e}")

# Example usage:
board = [
    [5, 3, 0, 0, 7, 0, 0, 0, 0],
    [6, 0, 0, 1, 9, 5, 0, 0, 0],
    [0, 9, 8, 0, 0, 0, 0, 6, 0],
    [8, 0, 0, 0, 6, 0, 0, 0, 3],
    [4, 0, 0, 8, 0, 3, 0, 0, 1],
    [7, 0, 0, 0, 2, 0, 0, 0, 6],
    [0, 6, 0, 0, 0, 0, 2, 8, 0],
    [0, 0, 0, 4, 1, 9, 0, 0, 5],
    [0, 0, 0, 0, 8, 0, 0, 7, 9]
]

sudoku_solver(board)
print("Solved board:")
for row in board:
    print(row)
```

This function uses two helper functions: `is_valid` to check if a number can be placed at a given position on the board and `solve_sudoku` to recursively fill in the board using backtracking. If the puzzle is invalid or unsolvable, it raises a `ValueError`.
