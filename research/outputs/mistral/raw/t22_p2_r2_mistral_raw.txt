Here's the requested Python function `sieve_primes(n)` that finds all prime numbers up to and including `n` using a sieve-style approach:

```python
def sieve_primes(n):
    primes = [True] * (n + 1)
    primes[0] = primes[1] = False

    for i in range(2, int(n**0.5) + 1):
        if primes[i]:
            for j in range(i*i, n+1, i):
                primes[j] = False

    result = [i for i in range(2, len(primes)) if primes[i]]
    return result
```
