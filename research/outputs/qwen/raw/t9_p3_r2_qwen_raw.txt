```python
def merge_intervals(intervals):
    if not intervals:
        return []

    # Sort the intervals based on the start time
    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]

    for current_start, current_end in intervals[1:]:
        last_end = merged[-1][1]

        # If the current interval starts after the previous one ended, merge them
        if current_start <= last_end:
            merged[-1][1] = max(last_end, current_end)
        else:
            merged.append([current_start, current_end])

    return merged
```

This function takes a list of intervals (each represented as a pair `[start, end]`) and merges all the overlapping intervals into one. The result is a list of non-overlapping intervals that cover all the input intervals' range.
