Here's how you can write the function:

```python
def search_insert_position(nums, target):
    left, right = 0, len(nums) - 1
    
    # Perform binary search
    while left <= right:
        mid = (left + right) // 2
        
        if nums[mid] == target:
            return mid  # Target found at index mid
        elif nums[mid] < target:
            left = mid + 1  # Search in the right half
        else:
            right = mid - 1  # Search in the left half
    
    # If we exit the loop, left is the insertion position
    return left

# Example usage:
nums = [1, 3, 5, 6]
target = 5
print(search_insert_position(nums, target))  # Output: 2

target = 2
print(search_insert_position(nums, target))  # Output: 1

target = 7
print(search_insert_position(nums, target))  # Output: 4
```

### Explanation:
- **Binary Search**: The function uses binary search to find the correct position for `target` in the sorted list `nums`.
- **Edge Case Handling**: If `target` is not found in the array, the loop exits when `left > right`, and `left` will be the index where `target` should be inserted.
- **Return Statement**: The function returns `left` as it represents the correct insertion position.

This approach ensures that the function works efficiently with a time complexity of O(log n).
