```python
def bfs_shortest_path(graph, start, target):
    visited = set()
    queue = [(start, 0)]

    while queue:
        node, distance = queue.pop(0)
        if node in visited:
            continue  # Skip already visited nodes to handle cycles correctly

        visited.add(node)
        if node == target:
            return distance

        for neighbor in graph[node]:
            queue.append((neighbor, distance + 1))

    return -1  # Return -1 if no path exists between start and target
```

This function uses a breadth-first search (BFS) approach to find the shortest path between two nodes in an unweighted graph. The graph is represented as a dictionary of adjacency lists, where `graph[node]` returns a list containing the neighbors of each node. The function visits nodes by maintaining a queue and keeps track of visited nodes using the `visited` set. It handles cycles correctly by skipping already visited nodes when re-encountered during the search. If no path exists between `start` and `target`, it returns `-1`.

The function works efficiently for larger graphs due to its use of BFS, which has a time complexity of O(V+E), where V is the number of vertices (nodes) and E is the number of edges in the graph.
