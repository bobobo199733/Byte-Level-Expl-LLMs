Here's a simple Python function for parsing a CSV line using the built-in `csv` module:

```python
import csv

def parse_csv_line(line):
    reader = csv.reader(line.split(","))
    return next(reader, [])  # Return an empty list if the line is empty
```

This function takes a CSV line as a string and splits it based on commas using `csv.reader`. It then returns the first (and only) list returned by `next()`. If the line is empty, it will return an empty list.
