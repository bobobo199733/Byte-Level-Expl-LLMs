def text_justification(words, max_width):
    def justify_line(line_words, line_length, is_last_line=False):
        if len(line_words) == 1 or is_last_line:
            # Left-justify and pad with trailing spaces
            return ' '.join(line_words).ljust(max_width)
        
        num_gaps = len(line_words) - 1
        spaces_needed = max_width - line_length
        
        # Distribute the spaces as evenly as possible between words
        base_spaces, extra_spaces = divmod(spaces_needed, num_gaps)
        
        justified_line = []
        for i in range(len(line_words)):
            word = line_words[i]
            if i < extra_spaces:
                justified_line.append(word + ' ' * (base_spaces + 1))
            else:
                justified_line.append(word + ' ' * base_spaces)
        
        return ''.join(justified_line).rstrip().ljust(max_width)

    result = []
    current_line_words, line_length = [], 0
    
    for word in words:
        if line_length + len(word) + (len(current_line_words)) <= max_width:
            current_line_words.append(word)
            line_length += len(word)
        else:
            # Process the current line
            result.append(justify_line(current_line_words, line_length))
            # Start a new line with the current word
            current_line_words = [word]
            line_length = len(word)
    
    # Handle the last line
    if current_line_words:
        result.append(justify_line(current_line_words, line_length, is_last_line=True))
    
    return result

### Explanation:

1. **Function `justify_line`:**
   - This helper function is responsible for justifying a single line of text.
   - It handles the distribution of spaces between words as evenly as possible or left-justifies if it's the last line.
   
2. **Main Function `text_justification`**:
   - It processes each word in the input list, appending them to the current line until adding another word would exceed the maximum width (`max_width`).
   - Once a line is full (or we run out of words), it justifies and appends this line to the result.
   - After processing all lines, it handles any remaining words as the last line.

3. **Edge Cases**:
   - If there's only one word in a line or if it’s the last line, it left-justifies with trailing spaces.
   - Otherwise, it distributes extra spaces as evenly as possible between the words on each line.

For the example input `words = ["This", "is", "an", "example", "of", "text", "justification."]` and `max_width = 16`, the function will output a list of strings that represent fully justified lines.
