Here's the Python function `word_frequency` that meets the requirements you specified:

```python
def word_frequency(text):
    words = text.strip().replace('  ', ' ').lower().split()
    freq_dict = {}
    for word in words:
        if word not in freq_dict:
            freq_dict[word] = 1
        else:
            freq_dict[word] += 1
    return freq_dict
```

This function takes a string `text`, first strips leading and trailing spaces, then replaces consecutive spaces with a single space. After that, it converts the text to lowercase and splits it into words. It counts the occurrences of each word using a dictionary where keys are the unique words and values are their respective frequencies.

You can use this function like so:

```python
text = "   This is    a test sentence   with multiple extra spaces."
freq_dict = word_frequency(text)
print(freq_dict)  # Output: {'this': 1, 'is': 2, 'a': 2, 'test': 1, 'sentence': 1, 'with': 1, 'multiple': 1, 'extra': 1, 'spaces.': 1}
```
