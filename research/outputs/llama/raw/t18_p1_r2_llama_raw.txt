**Edit Distance Function**
==========================

The following is a Python implementation of the Levenshtein distance algorithm to calculate the minimum edit distance between two strings.

```python
def edit_distance(word1: str, word2: str) -> int:
    """
    Calculate the minimum edit distance (Levenshtein distance) between two strings.
    
    Args:
        word1 (str): The first string.
        word2 (str): The second string.
    
    Returns:
        int: The minimum edit distance between the two strings.
    """

    # Initialize a matrix to store the Levenshtein distances
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # Initialize base cases
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    # Fill the matrix using dynamic programming
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if word1[i - 1] == word2[j - 1] else 1
            dp[i][j] = min(dp[i - 1][j] + 1,     # Deletion
                           dp[i][j - 1] + 1,     # Insertion
                           dp[i - 1][j - 1] + cost)  # Substitution or no operation

    return dp[m][n]
```

**Example Use Case**
---------------------

```python
print(edit_distance("kitten", "sitting"))  # Output: 3
print(edit_distance("hello", "world"))     # Output: 4
print(edit_distance("", "hello"))           # Output: 5 (insert all characters)
print(edit_distance("hello", ""))           # Output: 5 (delete all characters)
```

This function uses dynamic programming to build a matrix that stores the Levenshtein distances between prefixes of `word1` and `word2`. The minimum edit distance is then obtained by accessing the bottom-right corner of this matrix.
