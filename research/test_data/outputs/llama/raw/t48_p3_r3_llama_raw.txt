```python
def median_of_two_sorted_arrays(nums1, nums2):
    """
    Find the median of two sorted arrays efficiently using binary search.

    Args:
        nums1 (list): The first sorted array.
        nums2 (list): The second sorted array.

    Returns:
        float: The median of the two arrays.

    Example:
        >>> median_of_two_sorted_arrays([1, 3], [2])
        2.0
    """

    # Make sure that nums1 is shorter than or equal to nums2 for simplicity
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    x, y = len(nums1), len(nums2)
    left, right = 0, x

    while left <= right:
        # Partition point in nums1
        i = (left + right) // 2

        # Partition point in nums2
        j = ((x + y + 1) // 2 - i)

        max_left_x = float('-inf') if i == 0 else nums1[i-1]
        min_right_x = float('inf') if i == x else nums1[i]

        max_left_y = float('-inf') if j == 0 else nums2[j-1]
        min_right_y = float('inf') if j == y else nums2[j]

        # Check if the partition is correct
        if max_left_x <= min_right_y and max_left_y <= min_right_x:
            # If the total length of both arrays is odd, return the max of left elements
            if (x + y) % 2 == 1:
                return max(max_left_x, max_left_y)
            # If the total length of both arrays is even, return the average of max and min
            else:
                return (max(max_left_x, max_left_y) + min(min_right_x, min_right_y)) / 2

        # Move the partition to the correct side
        elif max_left_x > min_right_y:
            right = i - 1
        else:
            left = i + 1
```

This function uses a binary search approach to efficiently find the median of two sorted arrays. It ensures that `nums1` is shorter than or equal to `nums2` for simplicity and partitions both arrays based on the current guess. If the partition is correct, it calculates the median accordingly; otherwise, it adjusts the partition and continues the process until a valid solution is found.
