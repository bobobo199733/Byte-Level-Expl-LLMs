Certainly! The problem you're describing is known as the "Edit Distance" or "Levenshtein Distance." It measures the minimum number of single-character edits (insertions, deletions, or substitutions) required to change one word into the other.

Here's a Python function that implements this:

```python
def edit_distance(word1: str, word2: str) -> int:
    # Create a 2D list to store the distances between substrings of both words
    dp = [[0] * (len(word2) + 1) for _ in range(len(word1) + 1)]
    
    # Initialize the first row and column of the matrix
    for i in range(len(word1) + 1):
        dp[i][0] = i
    for j in range(len(word2) + 1):
        dp[0][j] = j
    
    # Fill the DP table
    for i in range(1, len(word1) + 1):
        for j in range(1, len(word2) + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = min(dp[i - 1][j],      # Delete
                               dp[i][j - 1],      # Insert
                               dp[i - 1][j - 1])  # Replace
                dp[i][j] += 1
    
    return dp[len(word1)][len(word2)]

# Example usage:
word1 = "kitten"
word2 = "sitting"
print(edit_distance(word1, word2))  # Output: 3
```

### Explanation:

- **Initialization**: The `dp` matrix is a 2D list where `dp[i][j]` represents the minimum number of edits required to transform the first `i` characters of `word1` into the first `j` characters of `word2`.
  
- **Base Cases**:
  - If one string is empty, then the only operation needed is to insert (or delete) all characters from the other string. Hence, `dp[i][0] = i` and `dp[0][j] = j`.

- **Filling the DP Table**:
  - For each pair of characters `(word1[i-1], word2[j-1])`, we consider three possible operations: 
    - If the characters are equal, no operation is needed.
    - If they are different, we choose the minimum cost among deleting a character from `word1`, inserting a character into `word1`, or substituting one character for another.

- **Result**: The value at `dp[len(word1)][len(word2)]` will be the minimum number of edits required to transform `word1` into `word2`.

This function has a time complexity of O(m * n), where m and n are the lengths of `word1` and `word2`, respectively.
