Here's the Python function for finding the maximum sum of any contiguous subarray in a given list, also known as Maximum Subarray Problem:

```python
def max_subarray_sum(nums):
    if not nums:
        return 0

    max_so_far = nums[0]
    current_max = nums[0]

    for i in range(1, len(nums)):
        current_max = max(nums[i], current_max + nums[i])
        max_so_far = max(max_so_far, current_max)

    return max_so_far
```

This function uses Kadane's algorithm to solve the problem. It initializes `max_so_far` with the first element of the list and then iterates through each element in the list using a `current_max`. If the current element is positive or equal to the sum of the previous `current_max` plus the current element, it will update `current_max`; otherwise, it'll start a new subarray.

At the end, it returns the maximum sum found in any contiguous subarray of the input list `nums`.
