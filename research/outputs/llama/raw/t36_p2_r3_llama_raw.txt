Here is a Python function implementing Dijkstra's algorithm for finding shortest path distances in a weighted graph:

```python
import sys
from heapq import heappop, heappush

def dijkstra_shortest_path(graph, start):
    """
    Compute the shortest path distances from the start node to all other reachable nodes.

    Parameters:
    - graph: A dictionary where each key is a node and its value is another dictionary.
             The inner dictionary's keys are neighboring nodes, and its values are edge weights.
    - start: The starting node for the search.

    Returns:
    - distances (dict): A dictionary mapping every reachable node to its shortest distance from the start node.
                        If a node is unreachable, its value will be sys.maxsize.
    """

    # Initialize distances with infinity for all nodes
    distances = {node: sys.maxsize for node in graph}
    distances[start] = 0

    # Create a priority queue of nodes to visit, prioritized by their current shortest distance
    priority_queue = [(0, start)]

    while priority_queue:
        # Extract the node with the minimum distance from the priority queue
        (dist, current_node) = heappop(priority_queue)

        # If we've already found a shorter path to this node, skip it
        if dist > distances[current_node]:
            continue

        # Visit each neighbor of the current node and update their shortest distance if necessary
        for neighbor, weight in graph[current_node].items():
            new_distance = dist + weight
            if new_distance < distances[neighbor]:
                distances[neighbor] = new_distance
                heappush(priority_queue, (new_distance, neighbor))

    return distances
```

This function uses a priority queue to efficiently select the node with the shortest distance at each step. The time complexity of this implementation is O(|E| + |V|log|V|), where E is the number of edges and V is the number of vertices in the graph.

You can use the function like so:

```python
graph = {
    'A': {'B': 2, 'C': 4},
    'B': {'A': 2, 'C': 1, 'D': 7},
    'C': {'A': 4, 'B': 1, 'D': 3},
    'D': {'B': 7, 'C': 3}
}

start_node = 'A'

distances = dijkstra_shortest_path(graph, start_node)
print(distances)  # Example output: {'A': 0, 'B': 2, 'C': 4, 'D': 7}
```

Note that if a node is unreachable from the start node (i.e., it belongs to an isolated subgraph), its value in the `distances` dictionary will be `sys.maxsize`.
