Certainly! Below is a Python function `word_frequency` that meets your requirements. This function will split the text into words based on whitespace, count the occurrences of each word, and return a dictionary containing these counts.

```python
def word_frequency(text):
    # Split the text by one or more whitespace characters
    words = text.split()
    
    # Create an empty dictionary to store word frequencies
    frequency_dict = {}
    
    # Iterate over each word in the list of words
    for word in words:
        # Convert all words to lowercase to ensure case-insensitivity
        lower_word = word.lower()
        
        # Update the count of the current word in the dictionary
        if lower_word in frequency_dict:
            frequency_dict[lower_word] += 1
        else:
            frequency_dict[lower_word] = 1
    
    return frequency_dict

# Example usage:
text = "Hello world hello  World"
print(word_frequency(text))
```

### Explanation:

1. **Splitting the Text**: The `split()` method is used with no arguments, which splits the text at any whitespace (spaces, tabs, newlines) and returns a list of words.
2. **Dictionary for Frequency Counting**: An empty dictionary `frequency_dict` is initialized to keep track of word frequencies.
3. **Iterating Over Words**: The function iterates over each word in the list of split words.
4. **Case Insensitivity**: Each word is converted to lowercase using `lower()` to ensure that case differences are ignored (e.g., "Hello" and "hello" are treated as the same word).
5. **Updating Frequency**: For each word, it checks if the word already exists in the dictionary. If it does, it increments its count by 1; otherwise, it adds the word to the dictionary with a count of 1.

### Example Output:
For the input `text = "Hello world hello World"`, the output would be:

```python
{'hello': 2, 'world': 2}
```
