```python
def word_frequency(text):
    # Initialize an empty dictionary to store the frequency of words
    frequency_dict = {}

    # Split the text by whitespace, using regex to handle multiple spaces as well
    words = re.split(r'\s+', text)

    # Iterate over each word in the list and update its count in the dictionary
    for word in words:
        if word:  # Ignore empty strings resulting from consecutive spaces
            frequency_dict[word] = frequency_dict.get(word, 0) + 1

    return frequency_dict

# Importing the re module to use regular expressions for splitting text
import re

# Example usage

print(word_frequency(text))
```

### Explanation:
- **`re.split(r'\s+', text)`**: This function splits the `text` by one or more whitespace characters (`\s+`). It handles multiple consecutive spaces as well.
- **`frequency_dict[word] = frequency_dict.get(word, 0) + 1`**: For each word in the list of words, it either increments its count if the word is already in the dictionary, or adds it to the dictionary with a count of `1`.
- **`if word:`**: This condition ensures that empty strings (resulting from consecutive spaces) are ignored.

### Example Output:
For the input `"This is a test. This test is only a test."`, the output will be:

```python
{'This': 2, 'is': 2, 'a': 2, 'test.': 1, 'test.': 1, 'is': 2, 'only': 1, 'a': 2, 'test.': 1}
```

Note that the `.get(word, 0)` method is used to safely retrieve a word's count from the dictionary and return `0` if it does not exist yet. This avoids a potential `KeyError`.
