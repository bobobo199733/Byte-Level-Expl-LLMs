Here is a Python function that utilizes the Floyd's cycle-finding algorithm (also known as the tortoise and hare algorithm) to detect cycles in a linked list efficiently:

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def linked_list_cycle(head):
    if not head:
        return False

    slow, fast = head, head.next

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True

    return False
```

This implementation defines a `ListNode` class to represent the nodes in the linked list, and then uses Floyd's cycle-finding algorithm to check for cycles in the list. The function takes the head of the linked list as input and returns `True` if there is a cycle present, and `False` otherwise.

The function moves two pointers (slow and fast) through the linked list at different speeds: one pointer moves one step at a time, while the other moves two steps at a time. If there is no cycle in the linked list, the two pointers will never meet. However, if there is a cycle present, they will eventually meet at some point inside the cycle.

Here's an example of how to use this function:

```python
# Create a linked list with a cycle
node1 = ListNode(3)
node2 = ListNode(2)
node3 = ListNode(0)
node4 = ListNode(-4)

node1.next = node2
node2.next = node3
node3.next = node4
node4.next = node2  # creating a cycle by linking the last node to the second node

# Call the linked_list_cycle function
print(linked_list_cycle(node1))  # Output: True
```
