**Autocomplete System Function**
=====================================

Here is the Python function `autocomplete_system` that meets your requirements:

```python
def autocomplete_system(words, prefix):
    """
    Returns a list of words from the given list that match the provided prefix,
    sorted in ascending order.

    Args:
        words (list): List of words to search through.
        prefix (str): Prefix to search for.

    Returns:
        list: Sorted list of matching words.
    """

    # Handle empty input correctly
    if not words or not prefix:
        return []

    # Filter words that match the prefix and sort them in ascending order
    matching_words = sorted([word for word in words if word.startswith(prefix)])

    return matching_words
```

**Example Usage**
-----------------

```python
words = ["apple", "banana", "cherry", "date", "elderberry"]
prefix = "da"
print(autocomplete_system(words, prefix))  # Output: ['date']
```

This function uses list comprehension to filter the words that match the given prefix and then sorts them in ascending order using Python's built-in `sorted` function. It handles empty input correctly by returning an empty list when either `words` or `prefix` is empty.
