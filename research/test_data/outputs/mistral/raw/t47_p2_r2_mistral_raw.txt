Here's a Python function called `basic_calculator(s)` that evaluates a string math expression using a stack-based approach:

```python
def basic_calculator(s):
    operators = {'+': lambda x, y: x + y, '-': lambda x, y: x - y}
    stack = []

    for token in s:
        if token.isdigit():
            stack.append(int(token))
        elif token == '(':
            sub_expr_stack = []
            stack.append((token, sub_expr_stack))
        elif token == ')':
            operator, sub_expr_stack = stack.pop()
            right = sub_expr_stack.pop()
            left = sub_expr_stack.pop()
            result = operators[operator](left, right)
            stack.append(result)
        elif token in operators:
            right = stack.pop()
            left = stack.pop()
            result = operators[token](left, right)
            stack.append(result)

    return stack[0]
```

This function iterates through the given string and processes each token based on its type:

1. If the token is a digit, it pushes the integer value onto the stack.
2. If the token is an opening parenthesis, it creates a new sub-expression stack and pushes the parenthesis onto the main stack with the sub-expression stack as its value.
3. If the token is a closing parenthesis, it pops the latest operator from the main stack along with the sub-expression stack and calculates the result based on the operator. Then, it pushes the result back onto the main stack.
4. If the token is an operator, it pops two numbers from the main stack, applies the given operator to them, and pushes the result back onto the main stack.
