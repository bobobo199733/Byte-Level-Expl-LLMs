```python
def knapsack_01(weights, values, capacity):
    n = len(values)
    
    # Initialize a DP table where dp[i][w] represents the maximum value that can be achieved with first i items and weight w
    dp = [[0 for _ in range(capacity + 1)] for _ in range(n + 1)]
    
    # Fill the DP table
    for i in range(1, n + 1):
        for w in range(1, capacity + 1):
            if weights[i - 1] <= w:
                dp[i][w] = max(dp[i - 1][w], values[i - 1] + dp[i - 1][w - weights[i - 1]])
            else:
                dp[i][w] = dp[i - 1][w]
    
    # The answer will be in the bottom-right corner of the DP table
    return dp[n][capacity]

# Example usage:
weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
capacity = 5

print(knapsack_01(weights, values, capacity))  # Output: 7
```

This function works by iteratively building a table `dp` where each entry `dp[i][w]` represents the maximum value that can be achieved with the first `i` items and a maximum weight of `w`. The final answer is found in `dp[n][capacity]`, which gives the maximum achievable value given all items and the specified capacity.
