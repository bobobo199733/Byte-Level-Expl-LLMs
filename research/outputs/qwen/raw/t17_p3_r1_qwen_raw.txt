Certainly! The Least Recently Used (LRU) Cache is a commonly used data structure in computer science where the least recently used items are removed first when the cache reaches its capacity. Below is a Python implementation of the `lru_cache` function:

```python
from collections import OrderedDict

def lru_cache(operations, capacity):
    """
    Simulates an LRU Cache.

    :param operations: A list of operations where each operation is a string in the format "put key value" or "get key".
    :param capacity: The maximum number of items that the cache can hold.
    :return: A list containing the result of each 'get' operation, with -1 indicating that the key was not found.
    """
    cache = OrderedDict()
    
    def get(key):
        if key in cache:
            value = cache.pop(key)
            cache[key] = value  # Move the accessed key to the end
            return value
        else:
            return -1
    
    def put(key, value):
        if key in cache:
            cache.pop(key)  # Remove existing entry
        elif len(cache) == capacity:
            cache.popitem(last=False)  # Evict least recently used item
        cache[key] = value  # Insert the new key-value pair

    results = []
    
    for operation in operations:
        if 'get' in operation:
            _, key = operation.split()
            result = get(int(key))
            results.append(result)
        elif 'put' in operation:
            key, value = map(int, operation[5:].split())
            put(key, value)

    return results

# Example usage
operations = ["put 1 1", "put 2 2", "get 1", "put 3 3", "get 2", "get 3"]
capacity = 2
print(lru_cache(operations, capacity))
```

### Explanation:
- **OrderedDict**: Used to maintain the order of elements based on their access or insertion.
- **get(key)**: Retrieves the value for a given key and moves it to the end (most recently used) of the cache. If the key is not found, returns `-1`.
- **put(key, value)**: Adds an element with `key` and `value`. If the cache exceeds its capacity, the least recently used item is removed.
- **results**: A list that stores the results of each 'get' operation.

### Example:
For the given example:

```python
operations = ["put 1 1", "put 2 2", "get 1", "put 3 3", "get 2", "get 3"]
capacity = 2
```

The output will be `[1, -1, 3]` because:
- After `put 1 1`, the cache is `{1: 1}`.
- After `put 2 2`, the cache is `{1: 1, 2: 2}`.
- `get 1` returns `1` and makes it most recently used, so the cache remains `{1: 1, 2: 2}`.
- After `put 3 3`, the cache evicts `1` (the least recently used) to make space for `3`. The cache is now `{2: 2, 3: 3}`.
- `get 2` returns `-1` because `2` was not found in the cache.
- `get 3` returns `3`.

This demonstrates how the LRU Cache functions with the given operations and capacity.
