```python
def text_justification(words, max_width):
    """
    Fully justifies a list of words within a maximum width.

    Args:
        words (list): A list of words to justify.
        max_width (int): The maximum line width.

    Returns:
        list: A list of fully justified strings, each exactly max_width characters wide.
    """

    result = []
    current_line = []

    for word in words:
        if len(current_line) + len(word) + 1 <= max_width:
            # If the new word fits on this line, add it
            current_line.append(word)
        else:
            # Otherwise, process the current line and start a new one
            result.append(justify_line(current_line, max_width))
            current_line = [word]

    # Process the last line (left-justified with single spaces)
    if current_line:
        last_line = ' '.join(current_line) + ' ' * (max_width - len(' '.join(current_line)))
        result.append(last_line)

    return result


def justify_line(words, max_width):
    """
    Fully justifies a list of words within a maximum width.

    Args:
        words (list): A list of words to justify.
        max_width (int): The maximum line width.

    Returns:
        str: A fully justified string, exactly max_width characters wide.
    """

    word_count = len(words)
    total_spaces = max_width - sum(len(word) for word in words)

    if word_count == 1:
        # Single-word lines are left-justified with a single space
        return words[0] + ' ' * total_spaces

    base_spaces = total_spaces // (word_count - 1)
    extra_spaces = total_spaces % (word_count - 1)

    justified_line = ''
    for i, word in enumerate(words):
        justified_line += word + (' ' * base_spaces + ' ') * (i < extra_spaces)

    return justified_line
```
Here's an explanation of the code:

The `text_justification` function iterates over each word in the input list. If a new word fits on the current line, it adds the word to the line. Otherwise, it processes the current line using the `justify_line` function and starts a new line with the new word.

The `justify_line` function takes a list of words and a maximum width as input, and returns a fully justified string. It calculates the total number of spaces needed to fill the line, and then distributes these spaces evenly between the words (with extra spaces added from left to right). If there is only one word on the line, it simply adds a single space.

Example usage:
```python
words = ["This", "is", "an", "example", "sentence"]
max_width = 16

result = text_justification(words, max_width)
print(result)  # Output: ['This    is   an example sentence',
               '         This    is   a  sentence']
```
Note that the last line is left-justified with single spaces between words and padded with trailing spaces.
