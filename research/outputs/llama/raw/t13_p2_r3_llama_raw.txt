**Spiral Matrix Traversal**
==========================

Here's the implementation of the `spiral_matrix` function in Python:

```python
def spiral_matrix(matrix):
    """
    Traverse a matrix in spiral order and return visited elements as a list.

    Args:
        matrix (list): A 2D list representing the matrix to traverse.

    Returns:
        list: The elements visited during traversal, in spiral order.
    """

    # Handle empty matrices
    if not matrix or not any(matrix):
        return []

    rows, cols = len(matrix), len(matrix[0])
    visited = [[False] * cols for _ in range(rows)]
    result = []
    top, bottom, left, right = 0, rows - 1, 0, cols - 1

    while top <= bottom and left <= right:
        # Traverse from left to right
        for i in range(left, right + 1):
            if not visited[top][i]:
                result.append(matrix[top][i])
                visited[top][i] = True
        top += 1

        # Traverse from top to bottom
        for i in range(top, bottom + 1):
            if not visited[i][right]:
                result.append(matrix[i][right])
                visited[i][right] = True
        right -= 1

        # Traverse from right to left
        if top <= bottom:
            for i in range(right, left - 1, -1):
                if not visited[bottom][i]:
                    result.append(matrix[bottom][i])
                    visited[bottom][i] = True
            bottom -= 1

        # Traverse from bottom to top
        if left <= right:
            for i in range(bottom, top - 1, -1):
                if not visited[i][left]:
                    result.append(matrix[i][left])
                    visited[i][left] = True
            left += 1

    return result
```

**Example Usage**
-----------------

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(spiral_matrix(matrix))  # Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
```

This implementation uses a simple and efficient approach to traverse the matrix in spiral order. It keeps track of the visited elements using a boolean matrix (`visited`) and iterates over the rows and columns accordingly. The time complexity is O(n * m), where n and m are the number of rows and columns, respectively.
