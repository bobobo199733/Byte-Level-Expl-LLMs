def n_queens(n):

        for i in range(col):
            if board[row][i] == 'Q':
                return False

                return False

        for i, j in zip(range(row, n, 1), range(col, -1, -1)):
            if board[i][j] == 'Q':
                return False
        
        return True

    def solve_n_queens(board, col):

        if col >= n:

        for i in range(n):
            if is_safe(board, i, col):
                # Place this queen in board[i][col]
                board[i][col] = 'Q'
                
                # recur to place rest of the queens
                solve_n_queens(board, col + 1)
                
                # If placing queen in board[i][col] doesn't lead to a solution then remove queen from board[i][col]
                board[i][col] = '.'

    board = [['.' for _ in range(n)] for _ in range(n)]

This function works as follows:

1. **is_safe(board, row, col)**: This helper function checks if it is safe to place a queen at `board[row][col]` by ensuring that no other queens are in the same column or diagonal.

2. **solve_n_queens(board, col)**: This recursive function tries to solve the N-Queens problem for columns from 0 to n-1. If all queens are placed (i.e., `col >= n`), it adds the current board configuration to the result list.

3. For each column, we try placing a queen in every row and recursively attempt to place the rest of the queens. If placing a queen at `board[i][col]` leads to a solution, the function continues; otherwise, it backtracks by removing the queen from that position.

4. The main function initializes an n x n board with all dots ('.') and calls the recursive solver starting from column 0.
