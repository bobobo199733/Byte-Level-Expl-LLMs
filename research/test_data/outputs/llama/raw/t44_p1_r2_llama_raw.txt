**Rotate Array Function**
==========================

The following is a Python function that implements the rotation of an array to the right by `k` steps.

```python
def rotate_array(nums, k):
    """
    Rotate an array to the right by k steps.

    Args:
        nums (list): The input list to be rotated.
        k (int): The number of steps to rotate the array.

    Returns:
        list: The rotated array.
    """
    # Handle edge case where k is greater than length of nums
    k = k % len(nums)
    
    # Reverse the entire array
    nums.reverse()
    
    # Reverse the first k elements
    nums[:k] = nums[:k][::-1]
    
    # Reverse the remaining elements (from index k to end)
    nums[k:] = nums[k:][::-1]
    
    return nums
```

**Example Use Cases**
--------------------

Here are some examples of using the `rotate_array` function:

```python
# Example 1:
nums = [1, 2, 3, 4, 5]
k = 2
print(rotate_array(nums, k))  # Output: [4, 5, 1, 2, 3]

# Example 2:
nums = [1, 2, 3, 4, 5]
k = 7
print(rotate_array(nums, k))  # Output: [4, 5, 1, 2, 3] (since 7 % 5 = 2)

# Example 3:
nums = [1, 2, 3, 4, 5]
k = 0
print(rotate_array(nums, k))  # Output: [1, 2, 3, 4, 5] (no change)
```

Note that the function handles cases where `k` is greater than the length of the input list by taking the remainder of `k` divided by the length of the list. This ensures that the rotation operation wraps around to the beginning of the list when necessary.
