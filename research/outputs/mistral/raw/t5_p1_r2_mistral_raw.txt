```python
def remove_k_digits(num: str, k: int) -> str:
    def helper(stack, num):
        if not num:
            return ''.join(stack) or '0'

        top = stack[-1] if stack else None
        while num and top and int(top) > int(num[0]):
            stack.pop()
            k -= 1
            if not k:
                break
            if not num:
                return ''.join(stack)
            helper(stack, num[1:])

        if num:
            helper(stack + [num[0]], num[1:])

    helper([], list(num))
```

This function works by iterating through the number and removing the smallest digit that is greater than the current top of the stack (or adding it to the stack if there's no top). The helper function ensures that we don't exceed the `k` limit while processing each character. If there are remaining digits after processing, it recursively processes them with the updated stack.

The result is returned as a string without leading zeros and handles cases where the resulting number may be empty by returning "0". It doesn't convert the input to an integer directly nor does it print anything.
