**Edit Distance Function**
=========================

The following Python function calculates the minimum edit distance between two strings using dynamic programming.

```python
def edit_distance(word1, word2):
    """
    Calculate the minimum edit distance between two strings.

    Args:
        word1 (str): The first string.
        word2 (str): The second string.

    Returns:
        int: The minimum edit distance between the two strings.
    """

    m = len(word1) + 1
    n = len(word2) + 1

    # Create a matrix to store the edit distances between substrings of word1 and word2
    dp = [[0] * n for _ in range(m)]

    # Initialize the first row and column of the matrix
    for i in range(1, m):
        dp[i][0] = i

    for j in range(1, n):
        dp[0][j] = j

    # Fill in the rest of the matrix using dynamic programming
    for i in range(1, m):
        for j in range(1, n):
            cost = 0 if word1[i - 1] == word2[j - 1] else 1
            dp[i][j] = min(
                dp[i - 1][j] + 1,      # Deletion
                dp[i][j - 1] + 1,      # Insertion
                dp[i - 1][j - 1] + cost  # Substitution or no operation
            )

    return dp[m - 1][n - 1]
```

**Example Use Cases**
--------------------

```python
print(edit_distance("kitten", "sitting"))  # Output: 3
print(edit_distance("", "hello"))  # Output: 5
print(edit_distance("abc", ""))  # Output: 3
```

This function works by building a matrix where each cell `dp[i][j]` represents the minimum edit distance between the first `i` characters of `word1` and the first `j` characters of `word2`. The final result is stored in `dp[m - 1][n - 1]`, where `m` and `n` are the lengths of `word1` and `word2`, respectively.
