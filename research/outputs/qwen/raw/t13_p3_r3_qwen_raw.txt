Certainly! To create a function `spiral_matrix(matrix)` that returns the elements of a given matrix in spiral order, we can follow these steps:

1. Define the boundaries for moving through the matrix: `top`, `bottom`, `left`, and `right`.
2. Traverse the matrix by following the spiral path:
   - Move right along the top boundary.
   - Move down along the right boundary.
   - Move left along the bottom boundary.
   - Move up along the left boundary.
3. Decrease or increase the boundaries as you move through the matrix to avoid revisiting elements.

Here's the implementation in Python:

```python
def spiral_matrix(matrix):
    if not matrix:
        return []
    
    rows, cols = len(matrix), len(matrix[0])
    result = []
    top, bottom, left, right = 0, rows - 1, 0, cols - 1
    
    while top <= bottom and left <= right:
        # Traverse from left to right along the top boundary
        for col in range(left, right + 1):
            result.append(matrix[top][col])
        top += 1
        
        # Traverse from top to bottom along the right boundary
        for row in range(top, bottom + 1):
            result.append(matrix[row][right])
        right -= 1
        
        if top <= bottom:
            # Traverse from right to left along the bottom boundary
            for col in range(right, left - 1, -1):
                result.append(matrix[bottom][col])
            bottom -= 1
        
        if left <= right:
            # Traverse from bottom to top along the left boundary
            for row in range(bottom, top - 1, -1):
                result.append(matrix[row][left])
            left += 1
    
    return result

# Example usage:
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(spiral_matrix(matrix))  # Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
```

This function works by maintaining the boundaries of the matrix and traversing it in a spiral manner. The `result` list accumulates the elements as they are visited in order.
