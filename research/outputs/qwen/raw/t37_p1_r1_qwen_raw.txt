Certainly! To detect a cycle in a linked list, we can use Floyd's Tortoise and Hare algorithm. This algorithm uses two pointers: the slow pointer moves one step at a time while the fast pointer moves two steps at a time. If there is a cycle, the fast pointer will eventually meet the slow pointer within the loop; otherwise, the fast pointer will reach the end of the list.

Here's the Python function `linked_list_cycle` that implements this logic:

```python
class ListNode:
    def __init__(self, value=0, next=None):
        self.value = value
        self.next = next

def linked_list_cycle(head):
    if head is None or head.next is None:
        return False
    
    slow = head
    fast = head.next
    
    while slow != fast:
        if fast is None or fast.next is None:
            return False
        slow = slow.next
        fast = fast.next.next
        
    return True

# Example usage:
# Creating a linked list with a cycle: 1 -> 2 -> 3 -> 4 -> 5 -> 3 (cycle)
node1 = ListNode(1)
node2 = ListNode(2)
node3 = ListNode(3)
node4 = ListNode(4)
node5 = ListNode(5)

node1.next = node2
node2.next = node3
node3.next = node4
node4.next = node5
node5.next = node3  # Creating a cycle

print(linked_list_cycle(node1))  # Output: True

# Example of no cycle:
node6 = ListNode(1)
node7 = ListNode(2)

node6.next = node7
node7.next = None

print(linked_list_cycle(node6))  # Output: False
```

This function `linked_list_cycle` takes the head of a linked list as input and returns `True` if there is a cycle, or `False` otherwise. It uses two pointers to traverse the list efficiently.
