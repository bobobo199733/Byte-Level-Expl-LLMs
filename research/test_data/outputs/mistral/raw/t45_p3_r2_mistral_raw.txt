Here's a Python function called `search_insert_position` that finds the correct index for inserting a given target value into a sorted array `nums`. The function uses binary search to find the appropriate position:

```python
def search_insert_position(nums, target):
    left, right = 0, len(nums)

    while left < right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid

    return left  # If the target is not in the array, we insert it at 'left' position
```

This function works by repeatedly dividing the sorted array into two halves and comparing the middle element with the target value. The function then continues searching on either the left or right side based on whether the current element is less than (<) or greater than (>) the target value. If the target is not found, it returns the index where the target would be inserted to maintain the sorted order of the array.

Here's an example of how you can use the function:

```python
nums = [1, 3, 5, 6]
target = 2
print(search_insert_position(nums, target))  # Output: 1
```
