Here is a Python function named `matrix_multiply` for multiplying two matrices:

```python
def matrix_multiply(A, B):
    result = [[0]*len(B[0]) for _ in range(len(A))]

    for i in range(len(A)):
        for j in range(len(B[0])):
            for k in range(len(B)):
                result[i][j] += A[i][k] * B[k][j]

    return result
```
This function takes two matrices as input, `A` and `B`, and returns their product as a new matrix. It first initializes an empty matrix of the correct dimensions to store the result. Then it calculates each element in the result matrix by iterating through the corresponding elements of the original matrices using nested loops.
