```python
def count_set_bits(n):
    if n < 0:
        raise ValueError("Input should be non-negative")

    count = 0
    while n > 0:
        n &= (n - 1)  # Clears the least significant bit set to 1 in n
        count += 1
    return count
```

This function counts the number of set bits by repeatedly ANDing a number with one less than itself, which clears the least significant set bit. The process continues until all bits are cleared and the count of set bits is returned.
