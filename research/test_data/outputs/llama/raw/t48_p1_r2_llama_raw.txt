Here is a Python function to find the median of two sorted arrays:

```python
def median_of_two_sorted_arrays(nums1, nums2):
    """
    Finds the median of two sorted arrays.

    Args:
        nums1 (list): The first sorted array.
        nums2 (list): The second sorted array.

    Returns:
        float: The median of the combined arrays.
    """

    # Make sure both arrays are lists
    nums1 = list(nums1)
    nums2 = list(nums2)

    # Merge the two arrays and sort them in O(m+n) time
    merged_array = merge_sorted_arrays(nums1, nums2)
    
    # Calculate the median of the merged array
    n = len(merged_array)
    if n % 2 == 0:  # If n is even
        return (merged_array[n//2 - 1] + merged_array[n//2]) / 2.0
    else:
        return float(merged_array[n // 2])  # Return the middle element


def merge_sorted_arrays(nums1, nums2):
    """
    Merges two sorted arrays into one.

    Args:
        nums1 (list): The first sorted array.
        nums2 (list): The second sorted array.

    Returns:
        list: A new sorted array containing all elements from both input arrays.
    """

    # Initialize the result array
    result = []
    
    # Merge smaller elements first
    while nums1 and nums2:
        if nums1[0] < nums2[0]:
            result.append(nums1.pop(0))
        else:
            result.append(nums2.pop(0))

    # Add any remaining elements
    result.extend(nums1)
    result.extend(nums2)

    return result

# Example usage
nums1 = [1, 3]
nums2 = [2]
print(median_of_two_sorted_arrays(nums1, nums2))  # Output: 2.0

nums1 = [1, 2]
nums2 = [3, 4]
print(median_of_two_sorted_arrays(nums1, nums2))  # Output: 2.5
```

In this code:

- We first merge the two sorted arrays into one in `merge_sorted_arrays`, which runs in O(m+n) time.
- Then we calculate the median of the merged array in `median_of_two_sorted_arrays`. If n (the length of the merged array) is even, we return the average of the two middle elements. If n is odd, we simply return the middle element.

Note that this code assumes both input arrays are sorted in ascending order. The overall time complexity of this solution is O(m+n) due to the sorting step when merging the arrays and O(log(min(m,n))) when finding the median, resulting in an effective time complexity of O(log(min(m,n)) + m+n).
