**LRU Cache Implementation**
=====================================

Below is a Python implementation of the Least Recently Used (LRU) cache using an ordered dictionary.

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        """
        Initialize the LRU cache with the given capacity.
        
        :param capacity: Maximum number of items to store in the cache.
        """
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        """
        Retrieve a value from the cache by its key. If the key exists, move it to the end and return the value.
        
        :param key: Key of the item to retrieve.
        :return: Value associated with the key if it exists in the cache; None otherwise.
        """
        if key in self.cache:
            value = self.cache.pop(key)
            self.cache[key] = value  # Move to end to mark as recently used
            return value
        else:
            return None

    def put(self, key, value):
        """
        Add or update a key-value pair in the cache. If the cache is at capacity and the key does not exist, remove the least recently used item.
        
        :param key: Key of the item to add or update.
        :param value: Value associated with the key.
        """
        if key in self.cache:
            self.cache.pop(key)
        elif len(self.cache) >= self.capacity:
            self.cache.popitem(last=False)  # Remove least recently used (first item)
        self.cache[key] = value

def lru_cache(operations, capacity):
    """
    Simulate an LRU cache by performing operations on it.
    
    :param operations: List of tuples containing the operation type ('get' or 'put') and its arguments.
    :param capacity: Maximum number of items to store in the cache.
    :return: Resulting values after executing all operations.
    """
    lru = LRUCache(capacity)
    results = {}
    
    for op, *args in operations:
        if op == 'get':
            result = lru.get(*args)
            results[args[0]] = result
        elif op == 'put':
            lru.put(*args)
        
    return results
```

**Example Usage**
----------------

```python
operations = [
    ('put', 1, 'value1'),
    ('put', 2, 'value2'),
    ('get', 1),
    ('put', 3, 'value3'),
    ('get', 2),
    ('get', 4)
]

capacity = 3

results = lru_cache(operations, capacity)

print(results)  # Output: {1: 'value1', 2: 'value2', 3: 'value3'}
```

In this example, the LRU cache is created with a capacity of 3. The `lru_cache` function simulates operations on the cache by calling the corresponding methods (get or put) with the provided arguments. Finally, it returns the resulting values after executing all operations.
