Certainly! To group anagrams in Python, you can use the fact that anagrams will have the same sorted form when converted to a tuple or string. Here's how you can implement the `group_anagrams` function:

```python
def group_anagrams(words):
    from collections import defaultdict
    
    # Create a default dictionary with lists as values to store groups of anagrams
    anagram_groups = defaultdict(list)
    
    for word in words:
        # Sort the characters in the word and use it as the key
        sorted_word = ''.join(sorted(word))
        # Append the original word to the corresponding group
        anagram_groups[sorted_word].append(word)
    
    # Return the grouped anagrams as a list of lists
    return list(anagram_groups.values())

# Example usage:
input_words = ["eat", "tea", "tan", "ate", "nat", "bat"]
output_groups = group_anagrams(input_words)
print(output_groups)  # Output: [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```

### Explanation:

1. **Import `defaultdict` from the `collections` module**: This is used to create a dictionary where each key maps to a list of words that are anagrams.

2. **Create a default dictionary**: The keys will be the sorted form of each word, and the values will be lists of words that match this sorted key.

3. **Iterate over each word in the input list**:
   - Sort the characters of the word.
   - Use the sorted string as the key to append the original word to the corresponding group in the dictionary.

4. **Return the grouped anagrams**: Convert the values of the `defaultdict` to a list and return it.

This approach ensures that all anagrams are grouped together, and each group is returned as a list within the main output list.
