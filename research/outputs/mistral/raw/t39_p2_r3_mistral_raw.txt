Here's a Python function named `knapsack_01` that solves the 0/1 knapsack problem using dynamic programming approach:

```python
def knapsack_01(weights, values, capacity):
    n = len(weights)

    # Create a table for storing solutions of subproblems
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    # Base case: If weight or capacity is zero, only an empty knapsack has value 0
    for i in range(n + 1):
        dp[i][0] = 0
    for j in range(capacity + 1):
        dp[0][j] = 0

    # Fill the dynamic programming table using bottom-up approach
    for i in range(1, n + 1):
        for w in range(1, capacity + 1):
            if weights[i - 1] <= w:
                dp[i][w] = max(values[i - 1] + dp[i - 1][w - weights[i - 1]], dp[i - 1][w])
            else:
                dp[i][w] = dp[i - 1][w]

    # The optimal value is stored at the bottom-right corner of the table
    return dp[-1][-1]
```

This function accepts three parameters: `weights`, `values`, and `capacity`. It uses a dynamic programming approach to compute the maximum total value that can be obtained from the items without exceeding the given capacity. The empty input lists are handled correctly, returning 0 if no items are present.
