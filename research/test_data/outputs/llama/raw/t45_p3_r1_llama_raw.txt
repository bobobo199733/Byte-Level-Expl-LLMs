```python
def search_insert_position(nums, target):
    """
    Returns the correct index or insertion position in a sorted array.

    Args:
        nums (list): A sorted list of integers.
        target (int): The target value to be searched.

    Returns:
        int: The index where the target should be inserted to maintain sorted order.
    """

    # Handle edge case when input list is empty
    if not nums:
        raise ValueError("Input list cannot be empty")

    # Initialize two pointers for binary search
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2

        # If target is found at mid index, return it
        if nums[mid] == target:
            return mid

        # If target is less than mid value, move left pointer to mid - 1
        elif nums[mid] > target:
            right = mid - 1

        # If target is greater than mid value, move right pointer to mid + 1
        else:
            left = mid + 1

    # If target is not found, return the correct index for insertion
    return left
```
Here's an explanation of how this function works:

1. We first handle the edge case when the input list `nums` is empty.
2. We initialize two pointers: `left` to point at the start of the array and `right` to point at the end of the array.
3. We then enter a binary search loop that continues until `left <= right`.
4. Within each iteration, we calculate the midpoint index `mid = (left + right) // 2`.
5. If the value at the midpoint index is equal to the target value, we return the midpoint index since it's where the target should be inserted.
6. If the midpoint value is greater than the target, we move the `right` pointer to `mid - 1` because all values in the range [left, mid) are already sorted and cannot contain our target.
7. Conversely, if the midpoint value is less than the target, we move the `left` pointer to `mid + 1`.
8. If the loop ends without finding the target, it means the target should be inserted at the index pointed by the final `left` pointer.
