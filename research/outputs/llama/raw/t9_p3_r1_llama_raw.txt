Here is the Python function to merge intervals:
```python
def merge_intervals(intervals):
    """
    Merge overlapping intervals.

    Args:
        intervals (list[tuple[int, int]]): List of intervals in the form [(start, end), ...]

    Returns:
        list[tuple[int, int]]: Merged intervals
    """
    # Sort intervals by start value
    intervals.sort(key=lambda x: x[0])

    merged = []
    for interval in intervals:
        # If merged is empty or current interval does not overlap with the previous one,
        # append it to the list
        if not merged or merged[-1][1] < interval[0]:
            merged.append(interval)
        else:
            # Otherwise, there is overlap, so merge the two intervals
            merged[-1] = (merged[-1][0], max(merged[-1][1], interval[1]))

    return merged
```
Example use case:
```python
intervals = [(1, 3), (2, 4), (5, 7)]
print(merge_intervals(intervals))  # Output: [(1, 4), (5, 7)]
```
