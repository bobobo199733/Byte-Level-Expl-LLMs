Here's a Python function called `autocomplete_system` that meets the requirements you've specified:

```python
def autocomplete_system(words, prefix):
    if not words or not prefix:
        return []

    suggestions = [word for word in words if word.startswith(prefix)]
    sorted_suggestions = sorted(suggestions)

    return sorted_suggestions
```

This function takes two arguments, `words` (a list of strings) and `prefix` (a string). It first checks whether the input lists are empty and returns an empty list if either is the case. The main logic of the function is in the comprehension expression that generates a list containing all words starting with the given prefix from the provided list of words. Finally, the sorted() function sorts the suggestions in alphabetical order before returning them as a result.
