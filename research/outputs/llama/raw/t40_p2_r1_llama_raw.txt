```python
def autocomplete_system(words, prefix):
    """
    Returns all words from the given list that start with the provided prefix.

    Args:
        words (list): A list of strings to be searched.
        prefix (str): The starting characters for the search.

    Returns:
        list: A sorted list of words matching the prefix.

    Example usage:
        >>> autocomplete_system(['apple', 'banana', 'apricot'], 'a')
        ['apple', 'apricot']
    """
    # Handle edge case where words or prefix is empty
    if not words or not prefix:
        return []

    # Use list comprehension to filter and sort the results
    matching_words = sorted([word for word in words if word.startswith(prefix)])

    return matching_words
```

This function handles the following cases:

- Empty input lists: `words` can be empty, and it will correctly return an empty list.
- Empty prefixes: If `prefix` is empty, it will also return an empty list as per the requirements.

The sorting of results happens directly within the list comprehension to maintain efficiency.
