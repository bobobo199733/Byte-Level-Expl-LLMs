Here's a Python function named `search_insert_position` that takes a sorted list `nums` and a `target` value as input, and returns the index where the `target` should be inserted to maintain the sorting order of the list:

```python
def search_insert_position(nums, target):
    left, right = 0, len(nums)
    while left < right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

This function uses a binary search algorithm to find the correct position where `target` should be inserted in the sorted list. The time complexity is O(log n) on average, making it quite efficient for large lists.
