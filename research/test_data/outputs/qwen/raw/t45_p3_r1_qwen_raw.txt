def search_insert_position(nums, target):
    left, right = 0, len(nums) - 1
    
    # Perform binary search
    while left <= right:
        mid = (left + right) // 2
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
            
    # At this point, `left` is the correct insertion position
    return left

# Example usage:
nums = [1, 3, 5, 6]

- It uses binary search to find the correct index where `target` should be inserted.
- If `target` is found at any point, it returns the index immediately.
- If `target` is not found, after exiting the loop, `left` will indicate the position where `target` should be inserted to keep the array sorted.
