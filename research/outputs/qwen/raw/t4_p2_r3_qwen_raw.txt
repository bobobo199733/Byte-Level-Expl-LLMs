```python
def decode_string(s: str) -> str:
    stack = []
    current_num = 0
    current_str = ''
    
    for char in s:
        if char.isdigit():
            current_num = current_num * 10 + int(char)
        elif char == '[':
            # Push the current string and number to the stack
            stack.append((current_str, current_num))
            current_str = ''  # Reset current string
            current_num = 0   # Reset current number
        elif char == ']':
            # Pop the last string and number from the stack
            prev_str, num = stack.pop()
            current_str = prev_str + num * current_str
        else:
            # Normal character, just add to current string
            current_str += char
    
    return current_str

# Example usage:
print(decode_string("3[a]"))  # Output: "aaa"
print(decode_string("2[a2[b]]"))  # Output: "abbbabbb"
```

### Explanation:

1. **Stack Usage**: We use a stack to keep track of the state before encountering a nested pattern. Each time we encounter an opening bracket `[`, we push the current string and number onto the stack, reset them, and start building the new substring.

2. **Number Handling**: When a digit is encountered, it's part of a repeated sequence. We build up this number by continuously multiplying by 10 and adding the next digit.

3. **Brackets Handling**:
   - When we see an opening bracket `[`, we push the current string and number onto the stack.
   - When we see a closing bracket `]`, we pop the last string and number from the stack, append the repeated substring to it, and set that as the new current string.

4. **Character Handling**: For all other characters, they are directly appended to the current string.

This approach ensures that nested patterns can be handled correctly by managing the state using a stack.
