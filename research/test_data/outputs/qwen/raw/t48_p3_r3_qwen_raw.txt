To find the median of two sorted arrays efficiently using binary search, we can use a method inspired by the "divide and conquer" technique. This approach ensures that both arrays are effectively divided in such a way that we only need to consider parts of the arrays that could possibly contain the median.

Here's a Python function `median_of_two_sorted_arrays`:

```python
def find_kth_element(A, B, k):
    if len(A) > len(B):
        A, B = B, A
    
    if not A:
        return B[k]
    
    m, n = len(A), len(B)
    i = 0
    j = k - (m - i)
    
    # If we have reached the beginning of one array,
    # return from the other array.
    if i == m:
        return B[j]

    # If j is less than zero, it means that j is out of bounds in B.
    # So use A's index instead.
    if j >= n:
        return A[i]
    
    a = A[i]
    b = B[j]
    
    # Since the arrays are sorted, if a < b, then we know that
    # all elements before i in A cannot be part of the first kth smallest element.
    # Similarly for b.
    if a > b:
        return find_kth_element(A, B[j+1:], k - (j + 1))
    else:
        return find_kth_element(A[i+1:], B, k - (i + 1))

def median_of_two_sorted_arrays(nums1, nums2):
    total_length = len(nums1) + len(nums2)
    
    # If the combined length is odd, we can directly get the middle element.
    if total_length % 2 == 1:
        return find_kth_element(nums1, nums2, (total_length // 2) + 1)
    else:
        # For even lengths, we need to find the average of the two middle elements.
        mid1 = find_kth_element(nums1, nums2, total_length // 2)
        mid2 = find_kth_element(nums1, nums2, (total_length // 2) + 1)
        return (mid1 + mid2) / 2.0

# Example usage:
nums1 = [1, 3]
nums2 = [2]

print(median_of_two_sorted_arrays(nums1, nums2))  # Output: 2.0
```

### Explanation:

1. **find_kth_element** Function:
   - This function finds the k-th smallest element in two sorted arrays combined.
   - It uses a recursive approach where we reduce the problem size by half at each step.
   - The base cases handle when one of the subarrays is empty or when the desired `k` index is out of bounds.

2. **median_of_two_sorted_arrays** Function:
   - First, it determines if the total length of both arrays is odd or even to decide how many elements to find.
   - It calls `find_kth_element` twice for the middle positions and computes their average for an even-length combined array.

This approach ensures that we avoid merging and sorting the entire arrays, making it efficient with a time complexity of O(log(min(m, n))).
