Here's a Python function that meets all your requirements using Depth-First Search (DFS):

```python
def count_islands(grid):
    """
    Counts connected groups of land cells in a grid.

    Args:
        grid: A 2D list containing "1" for land and "0" for water.

    Returns:
        An integer representing the total number of islands.
    """

    # Handle edge cases
    if not grid or not grid[0]:
        return 0

    rows, cols = len(grid), len(grid[0])
    count = 0

    def dfs(r, c):
        """
        Performs DFS from a given cell.

        Args:
            r: The row index of the current cell.
            c: The column index of the current cell.
        """

        # Check if the cell is within bounds and is land
        if (0 <= r < rows) and (0 <= c < cols) and grid[r][c] == "1":
            # Mark the cell as visited by setting its value to "0"
            grid[r][c] = "0"

            # Recursively visit neighboring cells
            dfs(r - 1, c)
            dfs(r + 1, c)
            dfs(r, c - 1)
            dfs(r, c + 1)

    # Iterate over each cell in the grid
    for r in range(rows):
        for c in range(cols):
            # If a land cell is found and has not been visited yet (i.e., its value is "1")
            if grid[r][c] == "1":
                # Perform DFS from this cell
                dfs(r, c)
                # Increment the island count after each DFS traversal
                count += 1

    return count
```

Example use cases:

```python
grid = [
    ["1", "1", "0"],
    ["0", "0", "1"],
    ["1", "0", "0"]
]
print(count_islands(grid))  # Output: 2

grid = [
    ["1", "1", "1"],
    ["0", "0", "0"],
    ["1", "1", "1"]
]
print(count_islands(grid))  # Output: 3
```

This code counts the number of islands by iterating over each cell in the grid and performing DFS from unvisited land cells. The `dfs` function recursively marks visited cells as "0" to avoid revisiting them, effectively tracing an island's boundaries.
