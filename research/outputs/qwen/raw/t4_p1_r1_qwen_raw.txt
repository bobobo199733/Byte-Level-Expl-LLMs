```python
def decode_string(s: str) -> str:
    stack = []
    current_num = 0
    current_str = ""
    
    for char in s:
        if char.isdigit():
            # Multi-digit numbers are possible, so we keep appending digits to current_num
            current_num = current_num * 10 + int(char)
        elif char == '[':
            # Push the current string and number to stack
            stack.append((current_str, current_num))
            current_str = ""
            current_num = 0
        elif char == ']':
            # Pop from stack to get the previous string and number
            prev_str, num = stack.pop()
            current_str = prev_str + current_str * num
        else:
            # Regular character, just add it to current string
            current_str += char
    
    return current_str

print(decode_string("3[a2[c]]"))   # Output: "accaccacc"
print(decode_string("2[abc]3[cd]ef"))  # Output: "abcabccdcdcdef"
```

This function `decode_string` takes a string `s` and returns the decoded string following the specified rules. It uses a stack to handle nested patterns and supports multi-digit numbers. The test cases demonstrate its correctness for various inputs.
