Here is a Python function to find the median of two sorted arrays in O(log(m+n)) time:

```python
def median_of_two_sorted_arrays(nums1, nums2):
    """
    Find the median of two sorted arrays.

    Args:
        nums1 (list): First sorted array.
        nums2 (list): Second sorted array.

    Returns:
        float: The median of the combined array.
    """

    # Make sure that nums1 is the smaller array
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    # Calculate the total length and half of it
    total_length = len(nums1) + len(nums2)
    half_length = total_length // 2

    # Initialize pointers for both arrays
    left, right = 0, len(nums1) - 1

    while True:
        i = (left + right) // 2
        j = half_length - i - 2

        # Calculate the values at the current partitions
        nums1_left = float('-inf') if i < 0 else nums1[i]
        nums1_right = float('inf') if i >= len(nums1) - 1 else nums1[i + 1]
        nums2_left = float('-inf') if j < 0 else nums2[j]
        nums2_right = float('inf') if j >= len(nums2) - 1 else nums2[j + 1]

        # Check if the partition is correct
        if nums1_left <= nums2_right and nums2_left <= nums1_right:
            # If the total length is odd, return the middle element
            if total_length % 2 == 1:
                return float(min(nums1_right, nums2_right))
            # If the total length is even, return the average of the two middle elements
            else:
                return (max(nums1_left, nums2_left) + min(nums1_right, nums2_right)) / 2

        # Adjust the partition based on whether there are more elements in the left or right partitions
        elif nums1_left > nums2_right:
            right = i - 1
        else:
            left = i + 1
```

Here is an example use case:

```python
print(median_of_two_sorted_arrays([1, 3], [2])) # Output: 2.0
print(median_of_two_sorted_arrays([1, 2], [3, 4])) # Output: 2.5
print(median_of_two_sorted_arrays([1, 3, 5, 7], [2, 4, 6, 8])) # Output: 4.0
```

This function works by using a binary search approach to find the median of the combined array in O(log(m+n)) time. It takes advantage of the fact that both arrays are sorted and adjusts its partition accordingly based on whether there are more elements in the left or right partitions.
