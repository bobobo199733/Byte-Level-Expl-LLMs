Here's a Python function that implements a basic calculator using a stack-based approach:
```python
def basic_calculator(s):
    """
    Evaluates a string math expression containing non-negative integers, 
    operators + and -, parentheses ( and ), and spaces.

    Args:
        s (str): The input string expression

    Returns:
        int: The result of the evaluated expression
    """

    # Remove leading/trailing whitespace and split into tokens
    tokens = s.split()

    # Initialize a stack to store intermediate results
    stack = []

    # Iterate through the tokens
    for token in tokens:
        if token == '(':
            # Push opening parenthesis onto stack
            stack.append(token)
        elif token == ')':
            # Evaluate expression inside parentheses when closing parenthesis is encountered
            value, operator = pop_and_get_operator(stack)
            intermediate_result, _ = evaluate_expression(value, operator, stack)
            stack.pop()  # Remove opening parenthesis from stack
            stack.append(intermediate_result)  # Store result on stack
        elif token == '+':
            # Push operator onto stack for later use
            stack.append(token)
        elif token == '-':
            # Pop previous value and operator, evaluate expression, and push new result onto stack
            value, prev_operator = pop_and_get_operator(stack)
            intermediate_result = evaluate_expression(value, prev_operator, stack)
            stack.pop()  # Remove operator from stack
            stack.append(intermediate_result)  # Store result on stack
        else:
            # Token is a number, convert and store it on stack
            value = int(token)
            stack.append(value)

    # Final evaluation: pop the last value and operator, evaluate expression, and return result
    final_value, _ = pop_and_get_operator(stack)
    return final_value


def pop_and_get_operator(stack):
    """
    Pops a value and operator from the top of the stack.

    Args:
        stack (list): The input stack

    Returns:
        tuple: A pair containing the popped value and operator
    """

    # Pop two items from the stack (value and operator)
    value = stack.pop()
    operator = stack.pop()

    return value, operator


def evaluate_expression(value, operator, stack):
    """
    Evaluates an expression by popping numbers and operators from the stack.

    Args:
        value (int): The current intermediate result
        operator (str): The operator (+ or -)
        stack (list): The input stack

    Returns:
        tuple: A pair containing the final result and the next operator
    """

    # Pop numbers from the stack until an operator is found
    while True:
        if stack[-1] == '+':
            value += stack.pop()
        elif stack[-1] == '-':
            value -= stack.pop()

        # If no more operators are left, break the loop
        else:
            break

    return value, operator


# Example usage
print(basic_calculator("(3+2)-4"))  # Output: -5
```
This solution defines a `basic_calculator` function that uses two helper functions, `pop_and_get_operator` and `evaluate_expression`, to handle the evaluation logic. It iterates through the input tokens, processes each token based on its type (operator or number), and stores intermediate results on a stack. When closing parentheses are encountered, it evaluates the expression inside and pushes the result onto the stack. Finally, it performs the last evaluation by popping the final value and operator from the stack and returns the result as an integer.
