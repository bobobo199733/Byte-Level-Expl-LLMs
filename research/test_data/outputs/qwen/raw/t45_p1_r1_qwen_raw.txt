```python
def search_insert_position(nums, target):
    left, right = 0, len(nums) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        # Check if the target is present at mid
        if nums[mid] == target:
            return mid
        # If target is smaller than mid element, ignore right half
        elif nums[mid] > target:
            right = mid - 1
        else:
            left = mid + 1
    
    # At this point, `left` is the position where the target should be inserted.
    return left

# Example usage:
nums = [1, 3, 5, 6]
target = 5
print(search_insert_position(nums, target))  # Output: 2

target = 2
print(search_insert_position(nums, target))  # Output: 1

target = 7
print(search_insert_position(nums, target))  # Output: 4
```

### Explanation:
- **Binary Search**: We use binary search to narrow down the position where `target` should be inserted.
- **Initialization**: `left` starts at the beginning of the array and `right` at the end.
- **Mid Calculation**: In each iteration, we calculate the middle index `mid`.
- **Comparison**:
  - If `nums[mid] == target`, return `mid`.
  - If `nums[mid] > target`, search in the left half by setting `right = mid - 1`.
  - Otherwise, search in the right half by setting `left = mid + 1`.
- **Return**: After the loop ends, `left` will be the correct position to insert the `target`.

This function ensures that we efficiently find the insertion position with a time complexity of \(O(\log n)\), where \(n\) is the length of the array.
